# Signed coalition voting on development sources

Use all six legacy prepared tasks at seed 42 in the first screen. All are previously opened development sources. On each task use the native 100-round XGBoost policy, CPU thread 12, original fit split, separate voting and validation partitions, and refit the final model on all development rows. The direct comparator uses native mean split Gain, with its usual decreasing order. Give all three selectors the same cutoff fractions, same four-at-most proposal evaluations including the full reference, and same validation guard: accept the first (narrowest) support whose validation AUC or R² lies within .005 of the full reference. Each positive evidence distribution nominates widths at half, three quarters and nine tenths of its mass, deduplicated, plus full width. The exploratory controls differ only by the supplied score vector. Keep accuracy/MAE and actual individual timing information.

The first supervised game uses small, medium and intact randomly restricted decision trees. Features can be substitutes in one subspace and complements in another. For each split, the vote is the signed improvement in squared score on disjoint vote rows from replacing its parent's fitted response by its child's. Average by feature inclusion opportunities at that size and normalize by the total absolute stratum weight. The minimum and the mean aggregate exactly the same signed scores. For the control, apply the identical support-mass rule to the fitted XGBoost Gain. Record all diagnostic tree fits separately from downstream refits; a cheap refit is still a fit. Never use outer utility to steer any individual job.

For each comparator the decision counts a source when both held primary losses ≤.01, and (a) strictly fewer features, or (b) fewer actual fits and faster whole pipeline with width within max(1,.05 × baseline width). Also give stricter speed+width, corresponding accuracy/MAE and true times without claiming help from timing noise alone. Subsequent prespecified changes to the game and the widths remain exploratory. A repeated win on any opened dataset is not independent replication.
