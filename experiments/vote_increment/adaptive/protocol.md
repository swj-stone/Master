# Native refits from size-consistent feature votes

The six original seed-42 folds are previously explored development data. The criterion compares MinPI against two controls on each same fold: a mean of exactly the same size votes and native XGBoost Gain. Do not use test outcomes to choose a candidate within any run. Success requires primary AUC or R² at most .01 below *each* control. Report separate accuracy / scaled MAE differences as secondary guards. Count a win only if the selected subset is strictly narrower or if both true fit count and measured end-to-end time are strictly lower without increasing control width beyond max(1,5%). Report a further 5% time-savings and no-width-increase sensitivity. Equal widths and equal fits cannot win on stopwatch noise.

Each standalone CPU arm runs the archived 100-tree, depth-four, single-thread native learner. Fit one full model on the training partition. For the two voting arms, form each feature's nonnegative share at each size, obtaining a threshold scale with arithmetic mean one over features at each size. A feature receives one quota of voting credit when its fractional contribution equals the uniform per-feature allocation. Apply the minimum or mean to the same shares. For direct Gain, normalize the native gain vector by its arithmetic mean as in default mean-importance selection. All arms propose the features earning one quota. Check the native validation primary score against full minus .005. On failure, try progressively lower quota thresholds (1/2, 1/4, 1/8) and fall back to full. On a successful initial proposal, check a two-quota proposal once. Cache repeated supports only within one arm. Select the narrowest checked support reaching the same full-model floor and deploy with one fit on all development rows. Five unique validation models maximum, including the full model, plus final deployment. Measure from the independent full fit to final test prediction before reading held responses.

Iteration 1 uses a held-row squared-loss game of the fitted booster. Decompose its raw margin by inexpensive native path contributions, reconstruct probability contributions for classification and evaluate against the true voting targets. For squared-loss utility, the expected gain of adding one column to a random size-k set is affine in k. The empty, middle and full-minus-one size votes therefore require two endpoint dot products per feature. The predictive refits are independent of this surrogate. Report all controls, including a scale-preserving mean normalized to the same total as the minimum as a diagnostic of whether a generic narrower threshold explains the change.
