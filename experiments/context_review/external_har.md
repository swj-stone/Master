# Transfer to previously unseen participants on UCI HAR

The original Human Activity Recognition Using Smartphones task has 561 supplier-provided time- and frequency-domain features. It has 7,352 training windows from 21 people and 2,947 test windows from nine other people. Each 2.56-second window overlaps its neighbor by 50%. The study uses the published fixed representation, which is already normalized. It does not reconstruct the supplier's signal processing or infer the cost of obtaining a feature from the physical sensors. The source describes the task, subjects, recording device, sampling, official participant split and CC BY 4.0 license. Reyes-Ortiz, Anguita, Ghio, Oneto and Parra, 2013. [UCI dataset and DOI](https://doi.org/10.24432/C54S4K)

This one external cohort was chosen from its metadata before running local models. The earlier PMLB and NIPS outcomes had already been observed. The protocol is a local design file. The public labels are available from the archive to anyone. In this execution, the selection and prediction worker reads training outcomes, official predictor tables and subject IDs. It writes each support, test probability array, execution times and digests. Only after all methods finish does the scoring stage read the archived official test outcomes. [Locked protocol](../../configs/context_review/external_har.json)

The inner fitting, ranking and external assessment groups contain 15, six and nine distinct people, respectively. A 100-round CPU XGBoost model with depth four supplies the common final predictor. Compact Gain and the voting methods use the existing ranking allowance, three-percent classification tolerances, four window-weight panels, and the existing block/singleton search. The panels reweight windows on the six ranking people. The test estimand is the mean of nine within-person accuracies. Thus ranking and evaluation need not favor identical supports. The nine people provide nine paired readouts from a single set of trained models. They supply limited evidence for transfer to new populations, devices, or daily-life recordings.

Full and Compact Gain select their own widths. The Gain prefix at the separating width uses the same fitted inner ranking as MinPI. The native RFE comparator at this width uses all 21 development subjects, XGBoost split gain, and a 20%-of-original-width elimination step. At 1%, 10%, 25% and 50% of the original width, independent Gain and RFE may select any input columns using the full official training data. The budget is rounded upward and selected before outcomes. RFE uses its standard internal estimator fit, then receives the common independent final refit. The three random mask families use the same endpoints and mask sizes as the separating design. Random family seeds vary independently of the fixed bootstrap panel seed.

The recorded seconds sum two in-process clocks: selection, and the common final fit plus prediction. Each arm separately pays for the initial fits it actually needs. Reading and checking the public archive, process startup, saving predictions and scoring outcomes are outside these clocks. Same-width controls receive their width from the separating arm; their own times exclude that decision. The implementation uses a one-hour worker limit for the entire cohort and saves each finished arm for restart.

From the thesis checkout, these commands use the shared environment and the local checkout's source.

```powershell
.\thesis-python.ps1 -m experiments.context_review.external_har --stage fetch
.\thesis-python.ps1 -m experiments.context_review.external_har
.\thesis-python.ps1 -m experiments.context_review.external_har_audit
```

The [output directory](../../results/context_review/external-har-locked-r1/) includes primary and secondary scores, each participant's paired accuracy differences, per-arm probabilities, support identities, model-search traces, component times, source and protocol digests, and the verification table. Archive acquisition checks the full upstream zip SHA-256 before model input. The audit rebuilds the subject partition, several conventional supports including recursive elimination, the outer predictor on each distinct kept set and all reported outcome scores. It computes macro AUC by ranking each class's scores against the other classes. Locally reproducing the recorded predictions checks arithmetic and implementation only.

Two implementation details affect interpretation. The original matched Gain path redundantly computes the ordinary anchor size before returning its supplied width. The audit measures the simpler prefix operation independently and saves its time in `timing-conditional-gain.csv`; both implementations must give identical predictions. The upstream archive distributes normalized predictors, but does not supply the exact sample scope of all normalization constants. The participant boundaries can be verified for model fitting, voting, and final testing, conditional on this supplied representation.

The optional outcome-free command `.\thesis-python.ps1 -m experiments.context_review.external_har_signals` maps the selected column names to the acceleration and gyroscope sources described in the supplier's `features_info.txt`. Angles relative to the gravity vector require acceleration; angles of gyroscope quantities against gravity use both sensors. The resulting `sensor-columns.csv` and `sensor-modalities.csv` identify sensor requirements and the number of frequency-domain columns in each selected support. They do not give signal-processing, power or inference-time savings.

## What the held-out people showed

Mean participant accuracy was 93.59% using all 561 inputs, 89.89% for the 35-column Gain anchor, and 89.40% for the separating rule at 22 columns. A Gain prefix at 22 columns scored 87.25%; RFE at 22 scored 90.68%. Separating exceeded same-width Gain on seven participants, tied on one and lost on one. It exceeded same-width RFE on two and lost on seven. Their respective mean paired differences were +2.16 and −1.27 percentage points. All 22-column comparisons use the same donated width, test participants and final model specification. The separating support requires both source sensors and 11 frequency-domain features.

A supplementary control froze 40 specific column sets at the training-derived width of 22 while the primary worker was still fitting its last RFE comparison. Its code and support file were fixed before scoring the primary cohort. The subsequent refits and scores were computed after the primary results. Twenty uniform draws from all 561 columns reached a mean participant accuracy of 80.22% (range 72.60–86.82%). Twenty draws restricted to the 35-column anchor reached 87.87% (85.19–90.26%). Five of those 20 equaled or exceeded the separating support's accuracy. The advantage over random columns drawn from the original table can reflect the quality of the initial anchor.
