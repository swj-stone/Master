# Sampled votes for refittable feature subsets

This is a development experiment on the six original prepared sources and eight previously opened UCI sources, seed 42. Hold out the existing voting, acceptance and scoring rows. All algorithms use the same unmodified input matrices. Use a fixed XGBoost histogram learner for the real refits (64 depth-four rounds, learning rate .12, same seed, one CPU thread). Report it as a matched direct gain comparator. The stronger archived 100-tree GPU/full-development Gain is a different pipeline and is reported separately on the original six.

Compare two games. In the first, each named feature supplies class-conditional binned likelihood evidence. A subset uses all its members to predict held voting labels. In the second, score each voting row by its distance to labeled training landmarks in the current subset. The posterior class distribution or response estimate changes when the neighbors change. The two games use the same disjoint blocks, four seeded partitions into four blocks, and base sizes approximately 1/4, 1/2 and 3/4. For each excluded feature measure its change in proper labeled loss when added. Average within strata and keep features by greatest minimum improvement. Compare pooling the same stratum means, singleton-only scores, direct Gain, and a seeded random order. Growth in average loss is a vote against retention. Continuous votes preserve information lost under a binary quota.

Real refits try every distinct width in {p, ceil(p/2), ceil(p/4), ceil(p/8), 1}, always training solely on the original fitting rows. On acceptance rows choose the narrowest width whose macro OVR AUC and accuracy both lose at most .01 relative to the complete learner; for regression use R² loss .02 and scaled MAE increase .02 (training standard deviation). No acceptance decision uses the outer labels. A predeclared limited-refit policy tries only a single candidate at ceil(p/2) for each order in addition to the full model. Compare width, AUC/accuracy or R²/scaled MAE, standalone fit-through-selection time, and number of fits. Cache identical supports between arms but charge all standalone fit, selection, ranking, and final inference time independently. Limit the two voting games to 384 fitting labels per class collectively with a minimum of one per class, 192 voting rows, and up to 64 labeled landmarks. Full nonlinear fits see all original fitting rows. Analyze paired source-level differences; these previously seen sources do not provide prospective performance evidence. Commit the frozen forecasts before comparing actual held labels.
