# Early vetoes on a real boosted-tree refit

The first development round found substantially narrower landmark proposals and slower selection. This second test changes the use of the votes. Keep the actual competitive direct Gain order fixed. Visit widths in increasing size after obtaining the full reference, stopping at the first candidate that passes independent acceptance. This is equivalent to the exhaustive width decision and can be cheaper. At boosting iteration eight, a native training callback measures the candidate's Brier/squared loss on previously reserved voting rows. The reference predictions come from the first eight rounds of the original full forest. Every comparison is paired on the same rows and same available measurements. Missing columns follow the booster's native absent-value default branches. At three sizes (25%, 50%, intact), use four seeded size-exact masks each except at intact size. Their mean row losses are conditional performance votes. Reject the candidate early if a size's excess loss exceeds .01 times null loss plus one estimated paired standard error (stratified voting sample of up to 256). A veto's sign is fixed for this test but does not prove the final candidate would fail. On a veto keep searching larger supports. Compare direct refit without any callback, a checkpoint on intact features, and pooling the size votes against the minimum. A secondary sensitivity uses zero or two standard errors. The final width and scientific acceptance still use the full 64-iteration fit and previously registered independent AUC/accuracy or R²/scaled-MAE criteria. Charge all callbacks, ranking, masks, early rejected and fully trained fits, and outer prediction. The scientific unit is the dataset, all 14 prior sources. Track the number of paired width+speed+quality successes; every failure remains in the denominator. Formal transfer is a separate registration if this development test succeeds.
