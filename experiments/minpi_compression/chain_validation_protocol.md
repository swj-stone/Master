# External comparison of chain search and individual marginal sampling

Fixed on November 17, 2026 before fitting or scoring these four sources. Test shared-ridge MinPI against MinPI with chain bisection, ridge coefficient norms, pooled ANOVA F (regression F for continuous responses), pooled unit-step ridge RFE and full ridge. Include a matched random query control if implemented and report its budget. Freeze the engine before predictions, hold alpha at .95 and run four rounds with ridge penalty 1. Each ranker faces the same held-out width guard, width grid and downstream ridge refit in benchmark.py. The main and zero-loss width rules from earlier work are distinct. This panel uses the main rule only.

Use seeds 42 through 46. Group identical descriptor vectors in every partition. Split non-Landsat groups into 80% development and 20% outer test. Divide development groups 60/20/20 for fitting, voting and width selection. Stratify by class for classification. Assess new measurements from the same source. QSAR splits do not hold out chemical scaffolds and Power Plant does not measure temporal extrapolation. Seal all predictions before calculating outer metrics. Three rotated-order repeats use one CPU and one BLAS thread. Record the median time for ranking, complete selection and the pipeline through outer prediction. Record wall time per job and ETA on the terminal.

The main comparison is chain vs the previous sampler. Assess each domain separately. Define a useful speed improvement as geometric mean selection-time ratio at most .90, geometric mean width ratio at most 1, and paired source-mean changes in both AUC and accuracy no worse than −.01, or in R² no worse than −.02 and in standardized MAE no worse than +.02. For a smaller-model result require at least 10% fewer retained columns applying the same predictive margins; report the measured time alongside. Apply the identical tests against the coefficient ranker and RFE. Against full ridge, the prespecified target is a retained fraction at most .85 under the predictive margins. Report every comparator and source irrespective of signs. Average seeds within each source then give the two sources equal weight in each domain, using paired log ratios for time and width. Two sources per domain are inadequate for population noninferiority or significance. Paired source-specific results are the primary uncertainty disclosure.
