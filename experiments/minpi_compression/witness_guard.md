# A single deletion after coefficient selection

This retrospective experiment was specified on 2026-11-17 for the eight original UCI confirmation sources and the four subsequent chain-validation sources. Their earlier outcomes had already been examined. Use their published fit, vote, width-validation and test partitions and seeds 42–46. Keep ridge, the six candidate widths, quota, independent permutations and both predictive floors from the original protocol. Do not tune or add tasks.

First choose the smallest accepted prefix of the full ridge coefficient ranking. Compute four rounds of sampled MinPI with the shared-coalition voting schedule and closure over observed adjacent endpoints. Let h count features inside the chosen coefficient prefix with a witnessed −1. When 0 < h < prefix size, make one proposal. The witness arm removes precisely those h features. The coefficient-tail control removes the lowest h coefficient-ranked members of the same prefix. The uniform control removes a simple random h-subset using seed + 307. All three compute the same votes to obtain h. Each proposal is fitted exactly once on fit plus vote, compared against the original full-width model on the width-validation partition using both original tolerances, and accepted only if both pass. If there is no nonempty proposal or it fails, retain the common coefficient prefix. Include the original coefficient selector on its own and the full model. Record identical proposed and delivered sets.

Measure three interleaved single-threaded runs of each policy per split on the same CPU. Time from its own preprocessing through selection, then final refitting and prediction. Reuse the full ridge coefficient scores made available by the voting calculation. Charge those models and all optional validation fits to each of the three matched policies. Report actual work counts, support-only opportunities, resulting acceptance rates, paired width ratios and prediction differences for all comparisons. Check measured coefficient supports and outer predictions against archived baselines. Freeze predictions before new outer scoring. The analysis gives each of six sources per domain equal weight after averaging its five splits. Use paired geometric ratios for widths and times. Against the coefficient baseline report whether the new rule saves at least 10% of columns under the original predictive margins, and whether any extra savings depend on targeting the identities of witnessed columns rather than the same number of alternative columns.
