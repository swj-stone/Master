# Matched cost of the sampled MinPI ranking

This comparison isolates computation at a fixed seed. Both implementations use the identical ridge game, order of proposed coalitions, quota, stopping decisions and coefficient tie order. The reference caches every previously visited support. It fits the full, base and extended ridge systems using centered cross-products and an intercept; it does not form a matrix inverse or refit a data transform at every edge. The new ranker reuses the common base factorization for multiple features. Validation loss is always evaluated on the same vote rows. Candidate width selection and final predictive fits are shared by both methods and are outside the ranking clock.

Use the first seed on every fixed confirmation source. Run both rankers three times on one pinned logical CPU, interleaving order. Record the feature order, sampled ternary scores, first negative witnesses, fit counts and source-specific median seconds. Report disagreements and every source, including slowdowns. Primary computational outcome is whether the geometric mean paired ranking time is lower at identical output. This comparison estimates the cost of the specified sampled ridge game. The full-pipeline comparison with conventional selectors is a separate outcome.

For a fixed wider-input timing stratum, repeat the same comparison on fold 0 of each of the six historical wide UCI panels, using its pre-existing training and proposal rows. Use the first 100 original columns (or all columns if fewer), impute and standardize from the training rows alone, and never open outer labels. This cap fixes the scope and bounds the cost of the direct-fit control. Report the two panels separately.
