# Transfer to the original six prepared datasets

The 30 held-out splits were previously used for conference and thesis experiments. This transfer measures the frozen ridge procedure on familiar data. It cannot provide an independent replication on new sources.

Use all five archived seeds (42, 123, 456, 789, 1024) and all six eligible datasets (Abalone, Credit Card Fraud, Gisette, ISOLET, Madelon, Spambase). Verify the archived train, validation and test CSV hashes. Preserve each split's selected columns and original training and test rows. Split the original validation rows in half with random seed 701 plus split seed (stratified on classes) for voting and width validation. Freeze predicted outer scores for all methods and tasks before reading test targets. The original preparation and random row splits set this experiment's information boundary. The secondary split makes no claim about new speakers, future credit transactions, or independence of repeated rows.

Fit the direct Gain ranker on the original training rows using the original CUDA histogram XGBoost configuration (100 trees, depth 4, learning rate .1, one CPU thread, split seed). Rank by mean split gain, with unused features scored zero and larger original indices breaking ties, as in the archived direct Gain implementation. Verify its order against the archived PIv1 comparison. Ridge MinPI and the coefficient control use the same original training rows; only MinPI reads vote outcomes. Use the frozen four-round ridge game and width grid from protocol.json. For all ranked methods train ridge on training plus vote rows to score each width; select the smallest eligible width on the reserved width rows. Refit on all development rows for test predictions. Include full-width ridge as a reference.

Compare AUC and accuracy (classification), R² and MAE (Abalone) and report rank, complete selection, and full deployment times. For time, take the median of three executions with seeded rotating method order, all using one host core and one BLAS thread. Gain uses the GPU, as in the original study. Timing excludes CSV input, split preparation and final metric computation. Set a one-hour watchdog per dataset/seed. Estimate paired metric differences arithmetically, width and time ratios geometrically, giving each seed equal weight within each dataset and each dataset equal weight within its domain. Report task outcomes and numbers of distinct supports against coefficients. Claim a practical advantage over Gain only if both outer metric losses are within .01 for classification or .02 for R² and scaled MAE in regression, and width ratio <=.90 or both paired time ratio <=.90 and width ratio <=1. Report the actual size/time trade-off also when these criteria fail. Keep these diagnostic criteria fixed across all six datasets. Scores from the older full-prefix XGBoost downstream pipeline remain a separate historical result.
