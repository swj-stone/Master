# Additional regularized least-squares wrapper control

On the four already scored chain-validation sources (all 20 splits), compare chain search to greedy forward regularized least squares at lambda 1. Select the next feature by minimizing pooled training leave-one-row-out squared loss with an intercept, fixing the fitted feature scale within each ranking. For classification use one-hot responses. Resolve ties by column order. Use the rank-one update of the ridge smoother and explicit leave-one-out residuals, as in Pahikkala, Airola and Salakoski (2010). Require agreement on small test problems with explicit refits after leaving each observation out. For the outer experiment use exactly the registered six-or-fewer widths, partitions, standardization, width guard, deployment procedure and source-level summaries. Three rotated timings per ranker. Retain worse outcomes. This is a retrospective comparison, and the measured time concerns the local Python/NumPy implementation.
