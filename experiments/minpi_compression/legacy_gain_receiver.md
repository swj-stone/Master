The primary comparison showed an advantage over the original Gain ranking when every method used ridge downstream. Historical XGBoost deployments scored substantially higher on Madelon and ISOLET. This retrospective transfer changes only the final prediction algorithm. Use exactly the 120 supports already sealed, including full, the coefficient control, Gain and MinPI. Fit the original 100-tree CUDA estimator on all development rows, and predict on the original test rows. No width retuning, voting adjustment or outer-outcome model selection is permitted. Preserve all 30 splits, including cases where ridge selected a width that transfers poorly. Seal all predictions prior to computing transfer scores; these outer data have already been used to evaluate the ridge analysis and earlier studies.

Compare matched fixed-support XGBoost versus ridge and compare each fixed-support XGBoost pipeline with the archived, full-width-grid, direct Gain XGBoost pipeline. Compute AUC, accuracy, R² and MAE with the primary metrics. Compare equal-weighted source means for the five classification sources, and report Abalone separately. Report ranking/width costs from the existing repeated timing study and the newly measured receiving model fit/predict cost separately. Their sum is not a new cold-process timing run. Include paired source-resampling ranges for classification and do not infer a population interval for a single regression source.
