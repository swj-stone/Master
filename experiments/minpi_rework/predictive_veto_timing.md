# Matched timing of an exact minimum veto

Use all 18 previous development sources and all seven external sources at seeds 42–46. Fit the registered 100-tree RF on fitting rows and reconstruct the predictive game on voting rows. Do not read stored test predictions, metrics or held-out targets. Verify every computed full deletion order against the production implementation and each available archived min-ranking/guard support and check count. All methods visit the same greedy candidate set until the empty support. The primary comparison is actual early veto versus native exhaustive Numba using the same candidate and coalition-size order, dot accumulation, tolerance, tie resolution, and union updates. The only material change in the exhaustive loop is removal of the incumbent-based early break. Also run the existing all-size NumPy/BLAS implementation. Compare the number of distinct size queries per candidate with the exhaustive total p²(p+1)/2. Every requested endpoint visit counts. Test p=1, two sizes and tied scores explicitly.

Warm kernels, restrict the process to one logical CPU and BLAS to one thread, and run three interleaved repetitions for all three methods. Time full ranking (including the incremental union updates), and separately the decision cores on identical cached step inputs. For each repeat, cycle through max(1, ceil(512/p)) full paths when timing just the cores to stabilize measurements on narrow data. Keep the production Python dispatch for all three core implementations, and also measure a compiled batched timing for both native cores, with identical setup, to expose dispatch effects. Exclude model fitting, construction of the path dictionary, construction of linear/quadratic coefficients, snapshot construction and JIT compilation from the rank-only clock, and report measured setup separately. Retain those costs for a full construction-plus-ranking comparison. A one-hour split watchdog applies.

Analyze the median of the three repeats within a split, then mean paired log-ratios within each source and across sources with whole-source percentile bootstrap intervals. Show development, external, and pooled estimates, every individual source and width stratum (p≤20, 21–50, p>50) regardless of signal. These are compute-only measurements; all three paths and their resulting forecasts remain fixed.
