# Signed utility votes for a coalition-mean predictor

Use the six historical prepared sources, initially seed 42. Use the original 100-tree archived teacher, the original data partitions, and the path-increment game. Fix backgrounds of size 0, floor((p−1)/2), p−1. For each feature and size compute the expected margin of the random panel conditional on excluding the feature and after including it. The signed utility vote is the reduction in squared distance from the full teacher after adding the candidate to those mean predictions. This is the loss of the mean; all randomness is integrated before applying the square. The last size equals exact full single-feature ablation. Compare static order by lowest signed vote, arithmetic mean, terminal/full ablation and native Gain. Apply the identical ascending-rank deletion sweep or exact greedy control with a 0.20 full margin tolerance. Record native metrics, compression and cost and the fraction of negative scores.

Secondary deployment objective: preserve the centered mean tree margin at panel sizes ceil(.25p), ceil(.50p) and p. For a fixed support S a path group P survives an independent uniform q-column outage mask with probability C(q,|P|)/C(p,|P|) if P is contained in S. Require all three normalized calibration margin distortions to be ≤.20, compare pooled root-mean-squared distortion and full-only. Exact greedy picks the least risk among all immediate deletions. Compare minimum-vote, pooled-vote and static full ablation ranking under the same three guards. Evaluate the fully observed test performance plus expected-margin deployment and performance for a single missing-sensor realization (16 common masks of each size, independently assigned to rows). Old sources are development data. Absolute margin tolerance does not guarantee label accuracy. Retain all available results, including failures.
