# Independent wide-source test of exact minimum-vote stopping

The primary contrast is full deletion-path ranking time with an exact size veto versus the fastest measured exhaustive, same-output control. Use depth-four, 100-tree sklearn RF, all supplied predictor columns listed below, seeds 42–46, one CPU thread, warmed functions, three interleaved repetitions. Compute complete proper-loss paths with the original count p of input columns and the established deterministic tie break. Evaluate the fused native scalar exhaustive loop and single-threaded vectorized dense all-size calculation. Each competes with veto using the same optimized union update. Include matched versions that coalesce the never-used columns while preserving their original IDs, path and all p cardinalities. Compare the best implementation of either family within a job as a conservative performance envelope, report matched pairs separately, measure common RF fit, calibration, ranking, prediction and full procedure, and describe missing results. Claim material ranking savings if the geometric ratio is at most .90 and a paired source-resampling interval excludes 1. A fit-to-forecast speed claim must meet the same criterion for that entire procedure. Resample whole sources after averaging paired log ratios over seeds; show all four individual results. Count labels/targets and score only after all supports, native predictions and split indices are sealed.

Use independent fitting, voting, acceptance and evaluation rows. For each MinPI deletion path, compare the single-path rules and the MDI control. The returned primary model uses the smallest width on the union of the MinPI and MDI paths satisfying the same all-size .02 squared-loss quota against the full masked forest and the existing clean calibration floors (.01 AUC/accuracy, .02 R²/scaled MAE). Break tied eligible widths in favor of the MDI path. The identical gate applied to the MDI path alone is the compressed comparator. Follow the full and selected forest predictions on the outer test. Accuracy and AUC or R² and raw MAE are mandatory; publish failures by source. These tests do not assert reversal of conclusions on the earlier panels or generalization of the artificial uniform availability law to an actual deployment network.

The four new sources were selected by width and retrievability before training. Previous project manifests already include Musk, Multiple Features, Libras, Ozone, SECOM, Semeion, Urban Land Cover and other UCI sources; none was reused. Official UCI archives are hashed in `wide_veto_sources.json`. All are real data and carry UCI's CC BY 4.0 terms.
