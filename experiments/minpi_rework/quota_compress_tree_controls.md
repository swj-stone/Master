# Single-voter control for boosted tree compression

The first seed showed similar widths for adaptive directional voting and exact all-candidate greedy deletion, with an 11.8% source-geometric reduction relative to Gain sweeps. The original six-source forecasts were scored, and collection of the other four planned seeds has started. Before computing this ablation, fix all 30 existing splits and compare two controls. The single-voter control keeps the same starting full-margin direction, scores candidates by their absolute projected error, and tests them in that order until a feasible deletion is found or every admissible singleton has been checked. It does not append rejected-residual directions. The second control is a Gain sweep that directly traverses sparse calibration inputs for each tested deletion, foregoing the path cache. This measures how much the cache helps or costs the simple control. No outer test scores will be opened until the 30 control forecasts are fixed. The five-seed study remains historical.
