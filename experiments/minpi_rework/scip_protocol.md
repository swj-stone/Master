# Matched fixed-width solver comparison

Frozen before the first solve. This experiment measures optimization of the fitted validation game. No fresh sources, outer outcomes or prediction claims enter its design. Use seed 42 on eight previously used sources chosen to span input dimension: Glass (9), Forest Fires (12), Wall Following (24), Credit Card Fraud (29), Landsat (36), QSAR Biodegradation (41), Leaves (64), Madelon (100). Read original fit/vote partitions. Fit the existing linear additive teacher on fit rows, then compute its centered Gram and single contributions on vote rows using the squared validation loss. Choose width ceil(p/2) and the existing energy-rank boundary region of min(28,p) columns. For larger sources the leading columns are fixed in and trailing columns are fixed out. Every arm optimizes the same region.

Compare direct, width-unrestricted dominance, and fixed-width dominance on three backends. The first backend uses the existing warmed Numba exact enumerator. The others use SCIP default presolve, default cuts and heuristics, one thread, ten optimization seconds per solve, and the same normalized regional objective. The RLT formulation has pair variables, McCormick rows and cardinality product equalities. The convex epigraph formulation uses a spectral square root of the positive semidefinite Gram, bounded auxiliary coordinates, and one squared-norm constraint. Record factorization error. Each screened backend fixes the certified variables and enforces all remaining certified precedence inequalities. Native modes share a deterministic single-exchange local optimum warm start, verified to meet the screen. Enumerators use their implemented traversal. If the screen resolves the problem, record its measured time and zero native solve time.

Use three independently timed repetitions with deterministic shuffled arm order per source/repetition. Each arm refits the teacher and recomputes the Gram and search region. Exclude input file loading and JIT compilation, include preprocessing, warm start where used, screening, model construction, solve and extraction. Record SCIP-reported optimizer time, wall time, nodes, native gap, incumbent, dual bound, support and status (including capped solves). Verify solutions against independently run direct enumeration in original objective units under a disclosed numerical tolerance. Keep capped runs in all timing summaries, identify certification failures, compare each backend to itself first, and report the best unscreened methods alongside the best screened methods instead of presenting a slow solver as the sole baseline.
