# Five-source exchange-panel registration

The first 13 held-out sources had already been scored before this panel was assembled. These five new sources were chosen for public availability, bounded data sizes, interpretable measured inputs and the availability of a defined prediction target. We checked prior project configurations, data inventories and archived method descriptions for their names and aliases. None had previously been evaluated in this project. No forecast, fitted model, outcome contrast or performance-based eligibility screen was used to choose the panel. This registration fixes the source population and data partitions. The separate blinded forecasting protocol must identify the algorithms, endpoints and decision criteria before any new predictions are scored.

| Key | Unit and target | Eligible columns and exclusions | Original source |
|---|---|---|---|
| ctg | Fetal state (normal, suspect, pathologic) per cardiotocogram segment | All 21 published numeric FHR/contraction measurements. Use the separately recorded source filename to group all segments of the same trace. Exclude segment coordinates, identifiers, expert morphology labels and indicators. Distinct recordings may come from one patient, whose identifier is unavailable. | [Campos and Bernardes, UCI](https://archive.ics.uci.edu/dataset/193/cardiotocography) |
| taiwan | Default on next month's payment per credit client | Credit limit, age, six repayment status codes, six balances and six previous payments. Exclude the ID and the three nominal demographic codes. Choose whole exact-input groups up to 4,000 records with a fixed label-blind permutation (seed 71117). | [Yeh, UCI](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients) |
| telemonitor | Motor UPDRS estimate per voice recording from 42 people in a six-month study | Use 16 voice measures plus age and sex. Exclude subject ID, total UPDRS and time since recruitment. Partition by patient, using all recordings. The motor score was interpolated between clinical visits in the original study. This is a different cohort and target from the earlier Turkish diagnostic voice study. | [Tsanas et al., UCI](https://archive.ics.uci.edu/dataset/189/parkinsons+telemonitoring) |
| studentmath | Final mathematics grade per student in two Portuguese schools | Use only the mathematics file. Drop all grade fields, absences and the multi-category job, choice-reason and guardian fields from X. Encode the 25 remaining numeric, ordinal or binary fields as one column each according to their published coding. This measures within-school-population prediction. | [Cortez, UCI](https://archive.ics.uci.edu/dataset/320/student+performance) |
| tecator | Fat percentage of each finely chopped meat specimen on the Tecator Infratec Food and Feed Analyzer | Use all 100 original near-infrared absorbance channels. Exclude 22 supplied principal components and all three chemistry assays from X. Retain the original interpolation benchmark of 215 samples. Omit the 25 designated extrapolation cases. Test samples are the original one-based positions 173–215. | [Original StatLib file, with the Tecator permission and publication-credit notice](https://lib.stat.cmu.edu/datasets/tecator) |

Use seeds 42–46 and the disjoint fit, vote, width and outer test APIs from the prior project. For every source except Tecator, partition distinct units approximately 48/16/16/20%. Group CTG by recording, Telemonitoring by patient, and other records by exact input vector. Link exact duplicates across declared units. Use task-independent group randomization for CTG and Telemonitoring. Stratify credit groups by the representative record's label. For Tecator, reserve its published test, then split the 172 development rows 60/20/20%. The outer test is identical across its five seeds. Report it as one source in source-level analyses. Within each partition every classification class must be represented. Freeze the complete row-membership digests, shapes and counts before fitting. All declared sources must appear in reports of completeness and failures. For CTG and Telemonitoring report equal-recording and equal-patient sensitivity alongside ordinary equal-row performance. No broader patient-level split is possible on CTG. These are five convenience samples.

Use `split(name, seed)` for selection. It supplies all X and disjoint index arrays, with all outer labels masked. `score(name, seed, forecast_path, frozen_sha256)` verifies a stored prediction digest before reading protected outcomes. Only use it once predictions are frozen and release is authorized. Raw data stay in the ignored data directory. The four UCI archives are credited at the linked UCI records under CC BY 4.0. For Tecator retain the original permission notice on any data redistribution; the original document includes a request for instrument credit and a publication preprint. The shared environment needs `xlrd==2.0.2` for the two legacy Excel workbooks.

## Predictor-only partition audit

The Tecator input audit detected 22 pairs of identical spectra among the 215 interpolation records. Seven pairs straddled the published boundary. Before any forecast was permitted, we retained the 43 published test records, excluded the seven matching development records and split the other 165 development records by exact spectrum. Thus the analytic table contains 208 rows and 193 unique spectra. The released test stays fixed at all five seeds. This amendment supersedes only the earlier count of 172 development records. It uses no outcome information.
