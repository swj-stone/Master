# Fixed-forest acquisition cost on the historical Cleveland fee schedule

Use UCI Heart Disease (45) and Peter Turney's original Canadian-dollar charges. The official archive SHA-256 is `b17cd273da9ce1caa4710fce80227ea454d4dbf9fcbc8e6a9121672751563adc`. Read `cleve.mod` with the supplied binary “buff/sick” endpoint. Omit its redundant severity code. Use the 296 complete records from the original 303, as in Turney. The primary panel excludes the fluoroscopic vessel count (ca) because it comes from angiographic workup and is adjacent to the angiographic target. The archival 13-feature version is a paired sensitivity. They share patients and outer splits. Use five deterministic stratified group splits, seeds 42–46, fractions .48/.16/.16/.20 for forest fit, voting, acceptance and outer score. Keep all exact duplicate 12-feature inputs in the same group. Preserve published numeric coding for categorical variables. [UCI data and donor costs](https://archive.ics.uci.edu/dataset/45/heart+disease) · [Turney, Appendix A.2 and Table 17](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume2/turney95a.pdf)

Read full and discounted prices and shared test groups from the archive, using integer cents. For a panel charge the discount price for each test plus one common setup cost per nonempty group. Verify that the group-specific difference between the two prices is constant. Report the one-time bundled cost of all structurally reachable tests and the mean per-patient charge for distinct tests traversed across all trees on intact outer inputs. This historical proxy uses Ontario's 1992 fee schedule and Turney's documented nominal prices for inexpensive items. It measures neither current billing nor clinical benefit or time delays.

Use the established 100-tree depth-four forest, unmodified MDI, minimum and pooled voting paths, the all-size .02 proper-loss quota and clean AUC/accuracy guards (both .01 relative to full on acceptance). The ordinary width choice minimizes nominal width then worst acceptance loss; use MDI first for a tie on both. Report standalone paths and MDI-plus-partner portfolios. A cost-aware terminal choice on the very same path(s) minimizes the quoted cost of the reachable support then worst loss, physical width and fixed input order. Compare both policies to matched forward benefit/cost paths. Follow Jagdhuber et al. Algorithm 1, incrementally maximizing improvement per extra unit of cost and stopping at nonpositive improvement, adding the full frozen model as fallback to all candidate families. For AIC use a binomial model with one coefficient per published feature code on forest-fit and voting rows. For the frozen-model Brier variant use clean two-coordinate Brier benefit on voting rows. The paper's cost addition is generalized to the actual marginal group fee; this is our adaptation to the historical charge table. Add the exhaustive optimal feasible panel using the same validation checks on all 4,096/8,192 subsets. This oracle estimates attainable *acceptance-sample* cost only. [cFS, Algorithm 1](https://eldorado.tu-dortmund.de/server/api/core/bitstreams/3e6902fe-a461-48d0-be4e-8174a513f8e9/content)

Freeze all ten paired forecast arrays, row assignments and cost selections before opening outer scores. Report every seed, the five-seed means in each panel, and held worst-size quota failures. Neither overlapping splits nor the two feature universes create independent sources. No inferential claim on costs beyond the single schedule. These tests give no indication for ordering tests for individual patients.
