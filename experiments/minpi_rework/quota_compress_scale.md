# Fixed-offset, one-parameter calibration of truncated tree margins

This development study uses only the nineteen previously opened sources. The four newly proposed sources remain untouched. In each archived split train the original 100-tree teacher on the pooled fit/vote partitions. Let F be its calibration raw margin minus the empty-forest raw margin E and H(S) the restricted teacher minus this same E. Fit one scalar λ in [0.5,2] to the pooled coordinates of all outputs and disjoint calibration rows, with no fitted intercept. Deploy E+λH(S) using only retained columns. The empty forest and degenerate H use λ=1. The full support has λ=1. The unscaled version uses λ=1 on every support.

Choose the smallest fidelity-feasible endpoint on each of four matched search procedures: descending Gain, fixed initial singleton ablation and authentic mean absolute native TreeSHAP use ascending-score feasible deletion sweeps to closure; exact greedy selects the globally least squared-loss viable singleton at each step. The exact path performs local deletions and does not certify minimum width. All methods refit λ for every contemplated support by the same clipped least-squares formula and check relative outer-independent calibration margin error ≤0.20. As an exact-search compute control evaluate lower bounds from disjoint coordinate partial sums: minimization over λ for a partial sum lower bounds the eventual optimal scalar loss. Timing includes support-dependent scalar calculations. Comparisons include the matched unscaled methods, full native scores and all outer losses/exceptions.

Begin with seed 42 on all 19 opened tasks. Extend to the existing five seeds if scaling reduces the source-geometric width of exact greedy or fixed singleton-ablation by at least 3% with source-average predictive quality within .01 classification and .02 regression margins relative to the respective unscaled procedure. This is model development with reused sources. A new confirmation is separately registered before touching new-source outcomes or forecasts.
