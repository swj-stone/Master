# Returning omitted variables during frozen tree compression

This exploratory study follows the already-opened historical and 13-source panels. Retain the original 0.20 centered-margin radius and training/calibration partition. For a support S, an inactive path with exactly one omitted variable a becomes active if a returns. Missing counts therefore provide exact add-back margins and exact changes in each competing retained variable's loss. Prioritize at most eight omitted variables with the smallest residual norm after restoration. For each include its four cheapest singleton deletions according to the exact augmented margin loss, then check every second retained variable. The singleton is a shortlist and may itself violate the quota; only the completed two-deletion move must satisfy feasibility. Choose the feasible one-restored/two-deleted move of lowest residual error. If none is found, allow the best one-for-one swap only if it strictly lowers squared fidelity by at least 1e−10 times the centered squared norm. Run ordinary feasible single deletions to closure after an accepted move; allow at most four accepted swaps. Ties use column identifier.

A failed vote can reject an exact norm computation; it cannot change winners or supports. Both implementations also include the same early cutoff for partial sums of squared residual coordinates.
