# Final external panel for supervised coalition votes

This panel was specified after the older 13-source and five-source studies. Its seven UCI collections were selected from application domains with measured responses, retrievable primary records, at least 150 cases, and inputs available when making the specified prediction. Source identity, predictor construction, sampling cap and split rules were set before any model fit. The panel is a purposive replication across seven new applications. No minimum effect or result-based replacement rule applies. Include every failed or inconclusive task in the denominator. The model protocol must freeze the competing selectors separately.

| Source | Prediction and partition unit | Predictor construction and scope |
|---|---|---|
| [Congressional Voting Records, 105](https://archive.ics.uci.edu/dataset/105/congressional+voting+records) | Recorded party of a 1984 US House member | The 16 roll calls are the only predictors. Encode no, the source's other disposition, and yes as −1, 0 and +1. This is retrospective party classification for one Congress. No party identifier enters X. |
| [Iranian Churn, 563](https://archive.ics.uci.edu/dataset/563/iranian+churn) | Customer churn at month 12, using months 1–9 | Exclude service status, calculated customer value, and the duplicate age-group encoding. Retain age, usage, plan, charges, tenure, failures and complaints. The source identifies each row as a different customer. |
| [Indian Liver Patient Dataset, 225](https://archive.ics.uci.edu/dataset/225/ilpd) | Source-recorded classification of a patient | Use the ten demographic and biochemical measurements, including binary sex. Use complete records. No patient or time identifier is released. This is a record-level retrospective label, with no independent diagnostic adjudication. |
| [South German Credit, 573](https://archive.ics.uci.edu/dataset/573/south+german+credit+update) | Repayment compliance on a historical loan | Use the quantitative, ordinal and binary fields in the corrected UCI codebook. Exclude the eight unordered multi-level factors: account status, credit history, purpose, savings, personal status, guarantor, other installment plans, housing. Keep one column per remaining original field. The sample oversampled bad loans and contains no per-loan origination date or borrower ID. |
| [Seoul Bike Sharing Demand, 560](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand) | Next-hour rentals in Seoul, by date | At 00, 06, 12 and 18 local hours use the current eight weather readings and the target's known hour, weekday and month. Exclude rentals from X and omit functioning-day status. Retain all available next-hour responses. Only hourly forecasts within the same city and calendar period are assessed. |
| [Beijing Multi-Site Air Quality, 501](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data) | PM2.5 at noon on the next day, by forecast date | Use Aotizhongxin, the first station alphabetically, to avoid treating stations as independent replications. Use the present noon's PM10, SO2, NO2, CO, O3, temperature, pressure, dewpoint, rain, wind speed and sine/cosine of wind direction. Exclude current PM2.5, future weather, row IDs and future pollution from X. Require complete origin inputs and an observed target exactly 24 hours later. Only read the named station inside the original PRSA archive. |
| [SGEMM GPU Kernel Performance, 440](https://archive.ics.uci.edu/dataset/440/sgemm+gpu+kernel+performance) | Log median runtime of a kernel configuration | Use the 14 pre-execution integer tuning parameters. Combine the four repeated timings into one response. Configuration is the split unit. Results concern unseen feasible configurations on the published GPU and matrix size. |

Use seeds 42–46 and a 2,000-row cap per source. For non-temporal sources, keep all rows when possible, otherwise take whole groups in label-blind seed-71117 permutation order up to the cap. Group exact predictor matches. Where a repeated person identifier is unavailable, exact grouping does not establish patient- or borrower-disjoint partitions. Split groups into approximately 48/16/16/20 percent for fitting, label-based voting, width selection and outer scoring. Stratify classification groups by their first source-row label. Test all declared classes occur in each partition.

For Seoul and Beijing keep contiguous chronological blocks in these proportions of forecast dates. Remove any origin whose response date reaches the start of the next block. If identical input vectors span dates, remove those ambiguous records before forming blocks. Repeats reuse the same chronological partition and count as one source. Source-level (paired five-seed average) is the unit for panel comparisons. Rows and neighboring dates are dependent. Separate the seven-source result from older development evidence and avoid interpreting a bootstrap over seven convenience sources as a guarantee for further applications.

The source names, parent aliases and file names were checked against the repository's prior dataset configs, evaluation scripts and evidence tables. ILPD and German Credit are established OpenML-CC18 source families. We use the original UCI ILPD and the corrected German Credit archive. The benchmark does not claim the CC18 sampling frame or folds. The literal archived URLs and SHA-256 digests appear in the [manifest](validation_predictive_sources.json). Data stay in the ignored local directory. Each UCI catalog entry provides attribution and CC BY 4.0 licensing. Chronological joins, missingness exclusions, subsetting, encoding and derived regression endpoints are transformations performed here.

Use `experiments.minpi_rework.validation_predictive.split(name, seed)` during training. The held-out labels returned there are masked. Release the separate scorer only after the complete forecast files and hashes have been sealed. No model runtime was measured during panel assembly.
