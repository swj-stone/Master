# Truncating a boosted teacher at unavailable features

Before computing tree-compression outcomes, fix the original six prepared datasets and seed 42. Fit the archived 100-round depth-four XGBoost CUDA configuration on the pooled training and voting rows. Use only the disjoint width rows for support selection. At an unavailable split stop and use that node's descendant mean leaf margin, weighted by the native training Hessian covers. At an available split follow the native threshold/default direction. Every deployment must receive only the retained input matrix. Verify full raw margins and probabilities against the native teacher and verify each restricted calibration prediction against direct restricted traversal.

Use a 0.20 budget relative to the norm of the full raw calibration margins minus the empty-support margins. A tree path contributes its child-minus-parent increment only if all distinct features required to reach the child are available. Group increments with identical required feature sets across trees. A directional vote is a lower bound on the norm of the omitted contributions. Start with the centered full teacher direction and test the minimum signed slack across both orientations of all accumulated directions. Try the admissible single deletion with the largest minimum slack; check its exact calibration norm, accept if feasible, otherwise add the normalized rejected residual as another voter. Stop when every remaining deletion fails a vote. This certifies a single-deletion local endpoint, not minimum cardinality. The fixed rule is assessed against (i) the fastest efficient calculation of the all-candidate exact greedy deletion path available here, (ii) ascending-order Gain deletion with an exact check, and (iii) the shortest individually feasible prefix of the descending Gain order. Retain the frozen full teacher and the existing true refitted Gain pipeline as external reference.
