# Post-release nominated refits on wearable devices

This exploratory control follows the negative frozen-forest result in the two already evaluated datasets. Freeze the following before training or timing nominated refits. No new test participants are available.

Reuse the same 18 leave-one-participant-out partitions, five-second windows, forests, quotas, intact metrics, masks and subject labels. Fit the full receiver once per algorithm. On voting participants, derive the original minimum device path and an arithmetic mean across the same rate-normalized device-size excesses. MDI sums full-forest impurity importances by device. For each of these three paths, refit exactly one support per nontrivial width on the original fitting rows, independently of acceptance performance. Include the union of MDI + minimum and the union of MDI + pooled, deduplicating identical supports before fitting. The empty predictor is the fitting prior; the all-device forest is shared with ranking. Apply the original joint refit guard on separate acceptance participants, breaking ties by worst excess then mask. Compare every path and every union with enumeration and refitting of all device subsets.

Also test a one-step nomination for each individual ranking: train just the proposed p−1-device forest, keep it if it passes the joint acceptance guard, otherwise retain the full receiver. Report its forced-subset acceptance, output width, actual fits and held metrics. The existing frozen choices and exhaustive supervised benchmark remain available.

Run each algorithm as a separate end-to-end workload with no cross-method model cache, using the same one-thread libraries and warmed kernels. Interleave methods in a seeded random order on each subject. Measure once per subject and method to limit cost; the blocks repeat across 18 held participants. Charge fitting, derivative or pooled voting when used, device-state predictions on acceptance, selection, and intact held-input forecast. Store held-outage predictions outside the timed region. Verify every fitted support's acceptance metrics against its original exhaustive receipt; use fresh forecasts. Lock all new supports, predictions, elapsed times, and actual model counts for both sources before scoring these controls. Compare the same-subject scores, widths and clocks against matched MDI, pooled and exhaustive methods. This analysis cannot provide an independent out-of-sample confirmation of a method motivated by the released results.
