# Five wider sources for fixed-width exchange screening

This extension tests the part of the feature search where direct enumeration can become expensive. Its five sources were selected from UCI for their measurement width and distinct application settings before fitting any candidate on them. Analyze this purposive panel separately from the earlier eight-source panel. The earlier registration stays intact. Five seeded runs on each source use the same learner, receiver, declared constraints and paired contrasts as the locked comparison. The five outcomes on the chronological news split share the same test articles.

The source inventory excluded Smartphone HAR and its revised dataset, Libras, SPECTF, Semeion, Urban Land Cover and optical handwritten digits because project records already contained them. The source names, common aliases and input filenames of the selected five were checked against earlier project designs and archives. The datasets below use UCI's CC BY 4.0 licenses. The exact original archive hashes are in [the source manifest](validation_wide_sources.json).

| Key | Rows × columns | Output and sampling unit |
|---|---:|---|
| derma | 366 × 34 | Psoriasis (original class 1) versus the other five recorded erythemato-squamous diagnoses. Use the 34 supplied clinical and histological observations, including age and binary family history. The authors removed patient identifiers. This evaluates record-level discrimination among the listed diagnoses. [Ilter and Guvenir, Dermatology](https://doi.org/10.24432/C5FK5P) |
| arrhy | 430 × 72 | Normal ECG (class 1) versus a recorded arrhythmia (classes 2–15). The raw file contains 452 rows. Exclude its 22 unclassified ECGs (class 16). Use the JJ, Q, R, S, P and T wave amplitudes in the original 12-lead order. Original one-based column indices for lead index L from zero are 160, 161, 162, 163, 166 and 167 plus 10L. Patient IDs were removed. Results concern ECG records. [Guvenir et al., Arrhythmia](https://doi.org/10.24432/C5BS32) |
| robotlp | 88 × 90 | Predict the four released approach-to-grasp outcomes for LP1. Use all 15 consecutive six-axis force/torque samples as one vector, kept together in every split. A sample here is a whole recorded event. The five LP tasks describe different physical operations. Only the first task enters this panel. The small outer set of 18 events makes the accuracy comparison coarse. [Lopes and Camarinha-Matos, Robot Execution Failures](https://archive.ics.uci.edu/dataset/138/robot+execution+failures) |
| ctloc | 4,656 × 96 | Predict location on the axial body axis using separate-input histogram bins. Starting at bin zero, take every fourth of the 240 bone-structure bins and every fourth of the 144 air-inclusion bins. Preserve the published outside-image sentinel. Each recorded patient contributes up to 48 equally spaced original row positions, selected without response values. Hold out whole patient IDs. The archived table has 97 distinct IDs, whereas the catalogue describes 74 patients. Report held-out recorded IDs as the unit. Exclude patient ID from X. [Graf et al., Relative location of CT slices on axial axis](https://doi.org/10.24432/C5CP6G) |
| news | 4,344 × 46 | Predict log(1 + social shares) for a news article. From the released descriptors exclude all nine keyword-popularity summaries and all three self-reference share summaries, whose temporal availability is uncertain. Exclude URL and publication age from X. Within each publication day retain the first six ascending SHA-256 hashes of article URL, then partition the 724 distinct days chronologically. Predicts shares counted at collection, so later articles have shorter observation windows. One source, one publisher. [Fernandes, Vinagre and Cortez, Online News Popularity](https://doi.org/10.24432/C5NS3V) |

For the classification tasks group exact duplicate input vectors and stratify groups by class. CT groups by recorded patient and news groups by publication day. Remove any duplicate input vector that crosses distinct declared IDs or days before splitting. None of the final 25 source/seed splits had any shared group or exact input row across a pair of partitions. The input is numeric. Models fit each imputer and scaler on the training rows allowed for that operation.

For split seeds 42–46 the group fractions are approximately 48%, 16%, 16% and 20% for fitting, within-game voting, width validation and held-out measurement. In classification, test splits contain all released analysis classes. News uses this partition by chronological days for each seed. The closed prediction API masks the test labels. Tie-breaking, baseline identities, feature counts/limits, timing, numerical tolerances and the forecast manifest must be fixed upstream before an independent scoring pass. Conditional exactness inside a candidate window is only credited on that window.

Run `.\thesis-python.ps1 -m experiments.minpi_rework.validation_wide --fetch` to retrieve the pinned archives or verify existing copies and check all 25 partitions. The selector uses `validation_wide.split(name,seed)`. After sealing all forecasts, the scoring driver compares the committed manifest digests and complete method/source/seed grid before calling `validation_wide.score(name,seed,path,digest)`.
