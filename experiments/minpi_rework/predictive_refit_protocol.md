# A matched random-forest refitting alternative

Use all seven previously scored transfer sources at seeds 42–46. Test the same fixed recipe at seed 42 on all four wide sources named in the external timing protocol (Tehran, UJI, oral toxicity and internet ads). The wide outcomes have not been scored at registration. This is a secondary comparison. All fits use the same rows, seed, bootstrap forest and maximum depth as the parent. No held-out prediction can choose a support. A one-hour per-job watchdog applies.

The first alternative orders inputs once by the original forest's impurity importance and refits a forest at geometric widths, dropping 20% of the remaining inputs (at least one) until one remains. This follows the backward-elimination idea of Díaz-Uriarte and Alvarez de Andrés (2006), with the frozen forest's impurity ranking and the same independent quota and intact-metric criteria used by MinPI. The authors used permutation importance and out-of-bag error for their application. A second, cheaper comparator uses only half-width steps. Both directly refit; no performance interpolation between widths is allowed. A third comparator refits only the MDI-selected width, and a fourth refits only the MinPI-selected width. A one-refit replacement must pass both checks and improve the worst-size acceptance loss at the same width, otherwise return the previously selected stopped forest.

For every refitted model compare to the original full forest under exactly the same hypothetical mask of the original p inputs, including unused inputs. Extend each refitted path union into the original input names. Calculate each model's proper-score improvement over its own empty prediction with the original p in the size coefficients. The difference of those improvements plus the empty-prediction loss difference gives the desired relative risk. Test against direct enumeration on a small binary and regression example. Measure fit and evaluation for all unique refit widths, charge shared work once per usable standalone policy, and report both native scores and held risk. Report benefits and failures against both geometric alternatives; compare the best support over each predeclared grid regardless of nonmonotonic feasibility.
