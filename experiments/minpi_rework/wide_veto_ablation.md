# Post-release mechanism test on the four wide sources

The four wide-source MinPI and MDI outcomes, including structural support and outer prediction, have been released. This analysis is retrospective. Before calculating additional outcomes, fix the same 20 source/seed jobs, original raw features, fitted RF, voting rows, held acceptance, availability normalization and both guard thresholds. Compare the all-size minimum, arithmetic mean over all sizes (pooled), intact size only, one-shot individual full-input ablation, and MDI. For every path search all widths under the original common all-size quota of .02 and clean-metric guard; use the deepest accepted depth. The primary structural-width contrast compares MDI + MinPI against MDI + each alternative. Within every pair choose smaller structural width, then smaller normalized worst-size acceptance risk, then MDI. Report each path separately, physical widths, held clean metrics and the held worst-size proper-loss excess under the originally specified availability model. Retain a nominal comparison with the original MDI-first tie rule.

Also compare the five rankings at a fixed nominal width taken from the MDI-only guarded selection on that source/seed. This isolates ranking from width choices and asks whether taking the minimum over sizes improves the held worst-size proper loss at the same feature budget. Publish source-level paired effects for every arm, including ties and adverse cases. Fit and select without outer labels, then verify all 20 frozen choices before evaluating. The study estimates sensitivity for four specific sources. It cannot add prospective support for the specificity of the minimum. No thresholds or methods will be chosen using these secondary results.
