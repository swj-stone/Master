# Predictive MinPI with uncertain access to measurements

This final transfer panel concerns conditional prediction risk and uses genuinely new applications. The original six, the 13-source frozen tree panel and the five-source repair panel are development data for this objective; report them separately. Register the new source inventory, inputs, split groups and target definitions before invoking the selector on any new source. Use seeds 42–46. Acquisition masks are uniformly random conditional on their size and common to the full and compressed forest. Training-set median imputation handles missing entries of an available input; a globally unavailable feature stops its tree path. The experiment models hypothetical acquisition patterns. It cannot identify the distribution of missing sensors in a particular practice.

Fit the same sklearn random forest on fitting rows for all arms, 100 trees of maximum depth four, one native CPU thread, training median imputation, native probability vectors or regression values. On the independent voting partition, trace greedy paths for minimum over all nonempty coalition sizes, uniform pooling of their normalized excess losses and intact-only loss. The signed score is excess expected Brier or squared loss per fraction of available inputs, normalized by the squared error of the empty predictor. Compute its expectation over all individual masks at each size. This differs from evaluating a single averaged prediction. Controls include fixed impurity ranking (MDI) and signed full-model single-column ablation. Collect the entire width path to zero using training/vote information only.

On independent acceptance rows, seek the fewest columns among each supplied path, with gain/MDI, static ablation and greedy paths each receiving identical checks. The primary MinPI selector searches the union of the native MDI and MinPI paths. At every nonempty size require normalized excess squared loss no greater than .02 times the fraction of available inputs (equivalently normalized per-fraction excess ≤.02). Also require intact AUC/accuracy within .01, or R² and development-scaled MAE within .02 of the uncompressed teacher on the acceptance sample. Ties use the smaller empirical value for the active guard then method name. Never use an outer score for a tie. Compare that two-path procedure to MDI alone and MDI plus static ablation, intact greedy or pooled greedy, all subject to the same acceptance guard. Also retain the predicted result of the same candidate family under intact-only, pooled and native-score-only acceptance. Inferences about voting concern changes in conditional loss or exact candidate-evaluation work isolated from changes due to expanding the candidate family.

The primary practical contrast is paired width vs MDI with the identical acceptance rule and corresponding clean outer quality. Target a source-average saving of 10% with ≤.01 loss in classification or ≤.02 R²/scaled-MAE loss in regression. For zero-width cases report the paired fraction of the original input dimension and raw column differences for every source; geometric width ratios with zeros are undefined. When sizes are positive, report geometric ratios as secondary. Report the strongest MDI-plus-static/two-path competitor even if it wins. The acquisition endpoint is worst positive held-out per-fraction excess loss over all positive sizes and the fraction of jobs whose value exceeds .02. Report intact always, both winning and failing sources, the benefit of the minimum against the same pooled acceptance rule, and paired costs. This is an empirical quota and carries no population coverage guarantee. All-case raw MAE/R² or AUC/accuracy and source-macro differences accompany it; no pooled raw MAE across units.

For the exact computation separately benchmark against precomputed shared antithetic permutation weights (8/32/128) and a direct native recount on already opened sources. Count setup as well as search. Cover direct masked predictions where feasible. Interval estimates must aggregate seeds before resampling sources. Calibration timing is one seeded job per half of the comparison; software and shared-component accounting will be disclosed. Use the existing one-hour per-source/seed watchdog for stalled experiments; record failed jobs. Seal all outer prediction arrays, each selected support, raw path-game arrays needed to reconstruct the outer conditional losses, split indices and implementation digests, before first scoring.
