# MinPI 分值筛选与旧版子集的比较（seed 42）

本次沿用提交 `d6840bf` 的六个预处理数据集、划分、XGBoost 参数和效用指标。
393 个输入特征中，6 列观测到 −1，385 列的采样最小值为 0，2 列为 +1。
两轮配对实验使用同一批采样记录。每个数据集的 900 秒硬截止均计入原始采样耗时。

| 方法 | 删除数 / 393 | 删除率 | 测试下降超出容差的数据集数 |
|---|---:|---:|---:|
| 原默认策略 `structured` | 154 | 39.19% | 0/6 |
| 分值筛选 `sign_worst` | 237 | 60.31% | 1/6 |
| 额外训练分区复核 `confirmed` | 237 | 60.31% | 1/6 |
| 事后提出的 `guarded` 规则 | 216 | 54.96% | 0/6 |
| 同删除配额与评分的 Gain | 215 | 54.71% | 0/6 |
| 同删除配额与评分的 TreeSHAP | 235 | 59.80% | 1/6 |

第一轮固定两条 MinPI 排序路径。其一先放入负见证，再按训练集 Gain 和平均绝对
TreeSHAP 的平均名次排列采样零分列；其二在负见证与零分列中按 Gain 排序。+1 和
未采样的列受到保护。每条路径尝试同一组删除数量，最高约 87.5%。通过整体验证集和
两个半集门槛后，主策略按删除比例扣除最差半集所消耗的容差比例来选择子集。
使用整体验证损失的备选策略在本轮选出了相同子集。对照方法各用一条排序路径。

第二轮在训练分区内另划出 25% 的行复核 `structured` 和 `sign_worst` 的候选，
六组的最终子集均与 `sign_worst` 相同。Credit Card Fraud 删除 22 列后，测试
AUC 下降 0.006810，超过分类容差 0.005。额外复核中的 AUC 仅下降 0.001455。
训练分区也参与了最初的特征排序，这次复核衡量的是对训练样本变化的敏感性。

最后考察一个保留旧版子集的规则。新候选必须在删除数、整体验证效用和两个半集
效用上均不劣于旧候选，而且至少一项严格改善。下表为固定六个选择后，与已实测的
同一子集逐一匹配得到的结果。测试变化以各自的全特征模型为参照。

| 数据集 | 旧版删除 | guarded 删除 / 输入 | 测试变化 | 两轮配对计时（分值筛选 / 复核，秒） |
|---|---:|---:|---:|---:|
| Abalone | 0 | 0 / 8 | 0 | 14.61 / 15.96 |
| Spambase | 28 | 28 / 56 | +0.000550 | 96.53 / 99.12 |
| Madelon | 25 | 87 / 100 | +0.076317 | 163.08 / 163.32 |
| Gisette | 50 | 50 / 100 | −0.002435 | 221.67 / 221.93 |
| Credit Card Fraud | 1 | 1 / 29 | −0.001237 | 187.77 / 189.13 |
| ISOLET | 50 | 50 / 100 | −0.000605 | 869.59 / 860.33 |

新增的 62 个删除列全部来自 Madelon。同样删除 87 列时，Madelon 上 Gain、MinPI、
TreeSHAP 的测试 AUC 分别提高 0.080281、0.076317、0.067855。ISOLET 的删除数仍
为 50，测试 AUC 降幅由 0.001103 缩小为 0.000605。其他四组沿用旧版子集。
这条规则是在观察前两轮 seed 42 的结果后提出的，其表现属于探索性结果。

Madelon 另以 `guarded` 从头采样、拟合和测试，用时 153.106 秒，复现了相同的
13 列保留子集及测试 AUC 0.865636。冷启动记录为 `seed42-guarded-20261110-192134-444036`。
