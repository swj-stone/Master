# 同规模联盟下的相对投票试验

这项试验保留三个标签和对不利情景取最小值的做法，将比较对象改为同样特征预算下的平均加列贡献。它回答的是特征的相对选用价值。原 MinPI 的负见证仍有单独的定义，即同一真实重训联盟加入该特征时从达标变成不达标。

## 游戏、代价与选列

在训练集上拟合一个全特征 XGBoost。以其在验证行上的有符号 TreeSHAP 贡献为输入，联盟代理分数为保留列贡献之和。空联盟的 AUC 为 0.5，全联盟的 AUC 与全模型验证 AUC 一致。中间子集分数是近似值，因为保留列的 SHAP 贡献也可能依赖被移除列。真实部署和外部测试使用仅含所选列、在训练集与验证集上重训的模型。

1. 对 96 个随机排列计算所有前缀的代理 AUC。加入列时，取得 AUC 增量，再减去 96 条路径在相同位置上的平均增量。这个参照量衡量在该规模随机加入一列的平均收益。
2. 超额增量大于 0.005 投 +1 票，小于 −0.005 投 −1 票，其余为平票。将排列位置分为小、中、大三个规模层，计算每列各层的净票率，即正票比例减负票比例。
3. 取三个净票率的最小值。小于 −1/3 为相对负，大于 +1/3 为相对正，其余为 0。容差、分档与轨迹数是事先固定的研究设置。所有联盟效用相同的极限下，各票为 0。
4. 保护相对正列，先提名相对负列，再从零组补充。组内按最差层净票率升序排列，同分取三层平均。对多个删除规模及单独的负组重训，整体验证集与两个固定半集的 AUC 均须达到对应全模型分数减 0.005 才有资格被选。先冻结选集，再读取测试集。

与全局二值最小值有重要区别。原游戏的精确 +1 必须出现在每个赢联盟里并缺席于每个输联盟，至多一个。相对游戏允许多个特征在各规模层都优于同预算参照，也允许没有这种特征。边际低于同宽平均的列仍可能提高原始 AUC。

## 平坦与无信号的检查

- 在 Abalone 的五个划分上逐一枚举 256 个真实联盟。原 α=.95 二值 min 对应 22 / 18 / 0 个负 / 零 / 正。以同规模联盟的平均效用作参照，对真实边际的层内均值取最小值，在 ±0.01 R² 容差下为 28 / 9 / 3。这是连续边际的精确对照，与分类原型的离散净票规则不同。若直接把相对负列全删，五个划分的验证 R² 都跌破 0.01 容差。[精确枚举与删列诊断](../../../results/test/thesis_sampling/abalone-stratified-exact-20261111-134548-337267/)
- 对 Madelon 的快速代理固定模型和 96 个排列，将验证标签随机打乱 256 次。无关联时，各 seed 平均仍产生约 14–19 个负标签。各真实划分的负标签总数和正标签总数均高于各自置换的 95% 区间。该检验针对标签总数；它不能确认每一列。Spambase 的两个真实正标签数均处于相应置换区间内。[Madelon 置换结果](../../../results/test/thesis_sampling/madelon-relative-votes-20261111-135137-410847/validation-label-shuffle.json) · [Spambase 置换结果](../../../results/test/thesis_sampling/spambase-relative-votes-20261111-135503-499433/validation-label-shuffle.json)
- 使用旧独立采样器在 Madelon 的两个划分各保存的 65 对真实重训端点，比较同一加盟边的原始代理 AUC 差与实际 AUC 差。Spearman 相关分别为 0.318、0.172。按 ±0.005 判边际符号，匹配率分别为 50.8%、49.2%。此处核对的是单次绝对加盟边，不是最终的同宽相对标签。[原始端点忠实度检查](../../../results/test/thesis_sampling/madelon-contribution-vote-20261111-134723-075837/proxy-edge-fidelity.json)

## 相同宽度的真实替换验证

在 Madelon 的 seed 42 和 123 上，只用第一个验证半集的标签计算相对分值，冻结要比较的列和共同上下文。分别在 12、50、83 列的上下文中，固定其余特征，相同宽度下替换一列，在训练分区重新拟合两份 XGBoost，并在另一验证半集比较 AUC。每次变化超过 0.005 计胜，低于 −0.005 计负，其余计平。每种比较、每种上下文大小、每个 seed 随机抽三对。

| 加入哪类特征 | 胜 / 平 / 负 | 第二半集平均 AUC 差 |
|---|---|---:|
| +1 相对 −1 | 12 / 4 / 2 | +0.02651 |
| +1 相对 0 | 15 / 2 / 1 | +0.04408 |
| 0 相对 −1 | 6 / 7 / 5 | +0.00116 |

本次复核中正类表现出替换价值，负与零的分界较弱。每个 seed 的多个配对共享评估样本，54 对不能当作 54 个独立实验。额外的 108 次重训只用于验证标签含义，未计入常规选列成本。[冻结的配对、预测与汇总](../../../results/test/thesis_sampling/madelon-halfheldout-exchange-20261111-140125-788619/)

## 能够严格节省的拟合

现有候选评分为删除率减去非负的验证损失惩罚。因而删除率本身是该候选能获得的评分上界。按删除规模递减评估，当所有剩余候选的上界严格小于当前最优可行分数，即可结束，平分仍按原次序比较。在 Madelon 和 Spambase 的 14 组“方法 × 划分”档案上，剪枝前后的最终掩码逐列相同。Madelon seed 456 的实测中，新方法与 Gain 都只需 4 次拟合，分别用时 5.83、3.96 秒。相同掩码的逐行预测也相同。[剪枝回放与真实计时](../../../results/test/thesis_sampling/madelon-spambase-exact-pruning-20261111-135742-554359/)
