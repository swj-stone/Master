# MinPI 特征选择与预测器的稳定性实验（seed 42）

参照方法为 `guarded`，在六个冻结的预处理数据集上合计删除 216/393 列。实验前
固定了实际改善的判断标准。相对参照的测试效用至少提高原容差的十分之一，记为
一组改善；下降超过该幅度，记为一组退步。分类的幅度为 0.0005 AUC，回归为
0.001 R²。至少两组改善、无实质退步、压缩不减且所有结果均在原全特征容差内，
才计为达到跨数据集目标。以下实验沿用同一 seed 和预处理数据。

## 改动特征选择，固定预测器

残差排序先用训练留出样本识别与当前预测误差相关的已删除零分列；另一方案在两个
互补训练半集分别训练，用对侧训练样本的 TreeSHAP 与训练 Gain 排序。两者都保护
+1、未观测列及已删除负见证，且新子集在整体验证集和两个验证半集上都须至少持平。

| 改动 | 删除列数 | 实质改善 / 退步组数 | Madelon 测试 AUC 变化 | Gisette 测试 AUC 变化 |
|---|---:|---:|---:|---:|
| 残差排序后的局部交换或删除 | 217 | 0 / 2 | −0.013536 | −0.000768 |
| 两个训练半集的重要性排序 | 216 | 1 / 1 | −0.012855 | +0.001399 |

两种方法在 Abalone、Spambase 和 Credit Card Fraud 上都选择了与参照相同的测试预测。
在 ISOLET 上，局部调整与半集排序分别下降 0.000112 和 0.000012。局部调整受
时间预留约束，在 ISOLET 上完成了 8 个计划候选中的 6 个；半集排序完成全部计划。

## 固定特征选择，改动预测器

列采样实验将原模型与每个节点可用一半特征的同参数模型等权平均。轮数实验在同一
条 XGBoost 提升序列中比较原来的 100 轮预测与 150、200 轮预测的等权平均。
每个特征集单独做决定，只有整个验证集及两个半集均无损失、半集平均改善为正时
才采用替代预测，否则保留原预测。另行记录始终使用替代预测时的结果。所有决策
均先冻结，然后评估正式测试分区。全特征模型和压缩模型都按同一规则处理。

| 数据集 | guarded 删除 / 总数 | 列采样方案的测试变化 | 延长轮数方案的测试变化 | 延长轮数相对原预测的配对 95% 区间 |
|---|---:|---:|---:|---:|
| Abalone | 0 / 8 | 0 | 0 | [0, 0] |
| Spambase | 28 / 56 | 0 | +0.000496 | [−0.000514, +0.001548] |
| Madelon | 87 / 100 | 0 | 0 | [0, 0] |
| Gisette | 50 / 100 | 0 | +0.001333 | [+0.000483, +0.002180] |
| Credit Card Fraud | 1 / 29 | −0.000637 | 0 | [0, 0] |
| ISOLET | 50 / 100 | +0.000209 | +0.000474 | [+0.000198, +0.000743] |

区间来自 500 次固定模型下的测试行配对重采样，分类按类别分层。轮数实验的三组零变化均是
验证阶段保留了原预测。延长轮数后的预测中，仅 Gisette 越过事先确定的实际提升
门槛。相同轮数规则用于 Madelon 的全特征模型时，验证阶段采用了替代预测，但测试
AUC 下降 0.008861；固定特征子集上的结论不能直接外推到全特征模型。

## 在原训练分区内复核轮数方案

复核固定相同的 216 列删除结果，仅使用原训练分区。按 seed 42 划成 60% 拟合、
20% 验证、20% 评估，分类按标签分层。在内部验证集冻结轮数选择后，以前 80% 重训，
在最后的 20% 上计算配对差值。六组均在 15 分钟内完成，最大计费耗时为 867.91 秒。

| 数据集 | 内部评估相对原预测器的变化 | 内部配对 95% 区间 |
|---|---:|---:|
| Abalone | 0 | [0, 0] |
| Spambase | 0 | [0, 0] |
| Madelon | 0 | [0, 0] |
| Gisette | +0.001729 | [+0.000760, +0.002967] |
| Credit Card Fraud | +0.000829 | [−0.000048, +0.002162] |
| ISOLET | +0.000570 | [+0.000165, +0.000979] |

三个数据集达到内部实际提升门槛，其他三组沿用原预测。Gisette 和 ISOLET 在正式
测试和此次复核中均提高，Gisette 两次都达到 0.0005 的实际改善门槛。此复核考察
固定特征后的预测器；原训练行曾参与特征排序，因此它不能独立验证选列流程。

两组特征实验及两组正式预测器实验的最长单数据集计费时间分别为 880.67、876.77、
889.71 和 882.52 秒。预测器实验计入从既有日志核验的选列准备耗时上界和本轮的
模型实测耗时。原正式测试分区在此前研究中已被评估过。
