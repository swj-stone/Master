# 相对投票的在线停止与单席保护

本试验沿用 Madelon 和 Spambase 的相同冻结分区、100 棵树预测器、三种联盟规模及同规模随机加列参照。实际 AUC 死区为 ±0.005，取消上一版用来划分净票率的 ±1/3。本页数字均来自探索性 test。

## 确定的有限票流

先用独立的 96 条随机排列冻结每个位置的平均加列贡献，同时得到每列的校准分数，即三层净票率中的最小值。随后另取 96 条主投票路径。两批路径使用同一固定模型和验证数据，统计含义是条件于这份数据的随机联盟证据。校准计算也计入成本。

对列 i 的某一层，设计划有 N 票，已读票的总和为 s，未读票数为 r。该层最终净票率必定介于 (s−r)/N 和 (s+r)/N。分别对三层的下界、上界取最小值得 L_i、U_i。即使这一列余下全获正票，也无法突破 U_i。如果某一对手已有 L_j > U_i，就永久取消 i 的冠军资格。终局时最差层得分最高的一列获得保护；并列按事先固定的归档列顺序打破。这定义了一个政策席位。Madelon 的五个划分都有多个最高分并列，获席者不能据此解读为唯一具有正贡献。

进入负类有两个额外条件。校准阶段必须有超过总列数一半的其他列校准分数严格更高，才给该列负向提名资格。主票流中，至少一层的连续负向证据必须达到界限。对该层非平票的负票数 a、正票数 b，采用负票概率 q>1/2 的均匀混合似然比，E = 2∫[1/2,1] (2q)^a (2−2q)^b dq。若该层从未偏向负方，在固定参照及独立随机路径假设下，可以在任意一轮查看 E。设单列误提名容许概率为 5%，三层中的任一层曾达到 3/0.05 = 60 便满足证据条件。只有负向资格、永久失去保护资格、证据过界三个条件齐备才吸收为 −1。这里的 5% 约束针对逐列、条件于固定模型和校准参照的提名误差；它不能直接控制删列后的测试损失。

暂态 0 已经退出冠军竞争，还可能因后续证据变成 −1。若它没有负向提名资格，或者余下投票即使全部为负也不可能使负向证据过界，则可以锁定为终局 0。真正全平时，所有列校准得分相同，负类为空；程序仍按平分规则保留一个代表。

## 选集与泛化

+1 获得保护。−1 是优先验证的候选，使用冻结的校准分数排序，因此无需补读其未采票数。接着用主票流终局得分排列 0 类并补入不同删除规模，同时复核只删负组的方案。选集经真实重训模型的三个验证分数决定，再评估冻结测试集。

|---|---:|---:|---:|---:|
| Madelon 42 | 48 / 39 | 13 / 13 | 0.84917 / 0.86960 | 6.98 / 5.57 |
| Madelon 123 | 49 / 38 | 13 / 13 | 0.87112 / 0.85250 | 5.32 / 4.56 |

本法每组用 9 次真实拟合，Gain 用 8 次。每组的墙钟读数均为冷启动一次。Madelon 两组 AUC 差分别为 −0.02043 与 +0.01862。Spambase 有 13 个已获负向证据的候选最终保留。有限路径的提前停止具有分组一致性；泛化收益和端到端提速是另外的实证问题。[冻结选集和全流程结果](../../../results/test/thesis_sampling/hybrid-class-subsets-20261111-144839-251033/comparison.csv)

按候选评分上界提前结束子集搜索，在三组的本法与 Gain 上均复现完整搜索掩码。Madelon seed 42 的两种方法各只需 4 次真实拟合，对应 6.07 与 4.02 秒，AUC 仍为 0.84917 与 0.86960。[剪枝回放与冷启动核对](../../../results/test/thesis_sampling/hybrid-C-gain-exact-pruning-20261111-145342-768139/)

## 取消正组豁免的二元对照

二元版保留独立校准、负向资格及负证据界限，达到界限即停止该列的负向投票。其余列共享后续筛选，不设豁免代表。8 个划分上的 303 个负列身份均与单席方案一致。最早的负向确认从第 41–54 轮提前到第 14–22 轮。若余列仍按完整主票流的最差层分数排序，含校准的投票 CPU 时间平均从 0.343 秒变为 0.335 秒；若仅需确认负列，余列交给独立筛选器，计票平均为 0.249 秒。两者都不含模型训练。[在线成本](../../../results/test/thesis_sampling/binary-negative-replay-20261111-152949-894864/aggregate.json)

按原有次序合并 0 和 +1，8 个划分的全部网格候选集合与原三分类逐一相同。原保护列在 Madelon 的删除顺序中排第 97–99 位，候选最多删 87 列；在 Spambase 中排在最后。三组真实重训也复现了对应选集和逐行预测。[候选掩码核对](../../../results/test/thesis_sampling/binary-negative-replay-20261111-152949-894864/candidate-mask-comparison.csv)

三个划分的整负组删除均通过三处验证。Spambase 的 27 个负候选中只删 14 个时，压缩与较差半集损失的综合评分高于删完负组的方案。以上比较固定同一候选删除规模网格；固定所有方案后再评分，重复的测试拟合只计一次。[三种决策及计时](../../../results/test/thesis_sampling/binary-nomination-20261111-152743-057454/comparison.csv)

另一次两阶段试验只对负候选计主票，随后删除整负组，在剩余列上重训全新的 Gain 排序模型，沿用原验证门槛。这一版可省去其余列的排序票。Madelon 五个划分两阶段法平均保留 15.4 列，测试 AUC 为 0.83324，冷启动平均 5.47 秒；单独 Gain 分别为 13 列、0.83109、4.86 秒。两阶段法每组拟合 7 次，Gain 每组 8 次，逐 seed 的 AUC 为两胜三负。Spambase seed 42 保留 29 列、测试 AUC 0.98774、耗时 4.70 秒，单独 Gain 保留 28 列、AUC 0.98809、耗时 4.51 秒。[Madelon 五个 seed](../../../results/test/thesis_sampling/binary-hard-then-gain-extension-20261111-153700-791073/madelon-five-seeds-vs-gain.csv) · [两阶段拟合与计时细目](../../../results/test/thesis_sampling/binary-hard-then-gain-20261111-153403-927107/comparison.csv)

## 理论来源

在最差情景下选择最优行动、利用上下界依次淘汰竞争者的思想见 [Garivier、Kaufmann 与 Koolen，COLT 2016](https://proceedings.mlr.press/v49/garivier16b.html)。此处的票流界是对剩余有限选票的确定性界。序贯负向证据的依据见 [Waudby-Smith 与 Ramdas，JRSS B](https://academic.oup.com/jrsssb/article/86/1/1/7043257)；可参考[作者维护的 confseq 工具](https://github.com/gostevehoward/confseq)。多数校准资格、单个代表席位及下游规则是本试验的设计选择。
