# 固定留列数，只交换一列

这项探索把 Kaur 等人的局部搜索思想用于现有低维岭选列器。测试信号仍是预测得分。所有选择都使用训练数据，交换门槛使用当前算法的惩罚训练损失。[参考论文，算法 1](https://arxiv.org/html/2606.18867v1#S5)

## 比较设置

评估前固定使用原[同伴消融的完整 31 个配置](../../../research/lowdim/peer_evidence/cases.csv)。每组使用原始单同伴内核选择的列数 K，以三种方式初始化：单同伴规则、同一行子样本上的空同伴评分、全训练集的同宽 F 检验。每种初始化都尝试全部 K(p−K) 个单换列组合（本批为 16–209 个），保留当前集合或接受损失最低的一次交换。列号零起算，同等损失按列集字典序决定。

对行抽样、标准化及目标编码沿用原方法。令 A = ZᵀZ + √m I、B = ZᵀY，候选集 S 的最小化岭目标为 ‖Y‖² − tr(Bₛᵀ Aₛₛ⁻¹ Bₛ)，m 为采样行数。只有损失减少超过 10⁻¹² × max(1, |原损失|) 才接受。三个候选均确定后，按各组原协议用完整训练集重新训练同一岭预测器，计算留出集指标。脚本逐组核对两层原始投票、三种初始列集及其原始测试得分。相同得分的判定容差为 10⁻¹²。

## 预测结果

单同伴初始化后有 26/31 组接受了交换。下表的差值为换列后的留出得分减去同一初始化的原得分。每种指标均为绝对单位。Abalone 的 9 组来自 3 个不同的测试划分，每个划分使用 3 个选列种子。

| 数据与协议 | 指标 | 组数 | 换列 | 升 / 平 / 降 | 得分变化范围 |
|---|---|---:|---:|---|---|
| Abalone，原始 | R² | 9 | 4 | 1 / 5 / 3 | −0.000118 至 +0.000323 |
| Diabetes，原始 | R² | 3 | 3 | 3 / 0 / 0 | +0.01353 至 +0.02062 |
| Diabetes，重复留出 | R² | 5 | 5 | 5 / 0 / 0 | +0.00143 至 +0.03557 |
| Breast Cancer，额外划分 | 平衡准确率 | 3 | 3 | 0 / 3 / 0 | 0 |
| Breast Cancer，重复留出 | ROC AUC | 5 | 5 | 1 / 2 / 2 | −0.00147 至 +0.00231 |
| Wine，额外划分 | 平衡准确率 | 3 | 3 | 0 / 3 / 0 | 0 |
| US Macro GDP，时间划分 | R² | 3 | 3 | 2 / 0 / 1 | −0.25262 至 +1.25413 |

单同伴加交换相对原单同伴为 12 胜、13 平、6 负。F 和空同伴在这 31 组的初始集合和交换后集合均相同，交换相对各自原始分数均为 13 胜、10 平、8 负。单同伴加交换相对 F 加交换为 4 胜、27 平、0 负。四个严格胜出的场景分别为：

| 场景 | 单同伴原始 → 换列 | F 原始 → 换列 | 指标 |
|---|---|---|---|
| Breast Cancer 额外划分 3 | 0.93662 → 0.93662 | 0.93662 → 0.92958 | 平衡准确率 |
| Wine 额外划分 1 | 1.00000 → 1.00000 | 1.00000 → 0.98611 | 平衡准确率 |
| US Macro GDP 划分 2 | −0.41777 → −0.67040 | −0.37116 → −1.23013 | R² |
| Breast Cancer 重复留出 5 | 0.99371 → 0.99602 | 0.99287 → 0.99455 | ROC AUC |

Diabetes 八组的三种起点均选出相同列，交换带来的改善亦相同。GDP 上看似很大的 R² 增益对应较低的原始预测水平，三个划分交换后的 R² 均为负。这些是五个已用于算法开发的数据来源，适合发现问题，并不构成新来源上的外部验证。[93 条逐配置、逐初始化明细](cases.csv)

## 实际付费的端到端计时

只测原始 Abalone 三折（选列种子均 1129）和 Diabetes 三折（各自原始种子）。两个新 Python 进程依次运行，每个方法先预热一次；随后五轮轮转，每种方法在五个执行位置各出现一次。单数值线程，从已准备好的训练及测试矩阵开始，重新选列、切片、标准化、训练并输出测试预测。归档核验、数据载入和测试打分在计时之外。F 按原协议获得相同的 K；单同伴在每次计时中自行选择 K。
