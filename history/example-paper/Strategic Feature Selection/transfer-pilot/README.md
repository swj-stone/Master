# 固定两列的机制试验：冗余、抑制与组合评分

这是本项目为研究条件岭收益选列所做的原创模拟。Kaur 等在《Strategic Feature Selection》第 4 节图 2、3 中控制成本与相关结构，比较不同子集。这里借鉴逐项改变机制并对照所有候选子集的做法；预测对象为静态连续响应，评价指标为独立测试集上的普通回归 R²。[参考论文](https://arxiv.org/abs/2606.18867v1)

## 数据与比较方法

各列从独立标准正态潜变量构造。记 X₀=z，X₁=ρz+√(1−ρ²)u，X₂=v，X₃ 至 X₇ 为独立噪声列。响应误差 ε 独立且服从标准正态分布。

- **冗余机制**取 Y=z+0.4v+0.6ε。X₁ 单独可以预测 z，尤其是在 ρ 较大时；已经观察 X₀ 后，X₁ 对响应的额外总体线性预测价值为零。X₂ 提供另一份独立信号。
- **抑制机制**取 Y=u+0.4v+0.6ε。总体上 X₀ 和 Y 的协方差为零，但用 X₁−ρX₀ 可恢复 √(1−ρ²)u。调高 ρ 会削弱 X₁ 的边际信号，并加重对这对列求解时的共线性。

ρ 取 0、0.8、0.98。每格 24 个种子，训练 256 行，独立测试 2,048 行；六格使用相同的基础随机数做成对比较，每格内的 24 次抽样各自独立。固定从八列中选两列。所有标准化统计取自训练集。最终模型均为带截距的岭回归，惩罚系数为 1。完整特征模型保留八列，供判断两列预算相对全特征的损失。

1. **现行单同伴规则**直接使用项目原生内核输出的逐列分数，在本试验中固定取前两列。256 行均参与评分。空同伴消融仅用独立增益；同宽 F 使用 scikit-learn 的单变量回归 F 检验。这两个排序在本试验中选出了相同的列。
2. **均匀随机选两列**的参考分布来自全部 28 个等可能组合。每个组合独立拟合岭回归，记录测试得分，汇报该离散分布的期望。逐次 CSV 还给出四分位数与中位数。其他方法依据训练数据选定组合后，才读取该组合对应的测试得分。
3. **前向补一列**先取边际增益最高的一列，再挑给定该列后条件增益最大的另一列。**训练目标最优对**枚举全部 28 对，在标准化训练矩阵上最大化联合岭目标下降。二者沿用选列惩罚 λ=√256=16。设 A=ZᵀZ+λI、b=Zᵀy（y 在训练集标准化），组合 S 的训练增益为 bₛᵀAₛₛ⁻¹bₛ。脚本用二元线性方程独立核对原生内核的每一层得分。这两个方法是本项目的诊断对照，均在测试评分前决定选列。
4. **仅同伴均值**是一项事后追加的消融：给定每个单同伴的增益先求平均，按均值排前两列，去掉与空同伴得分取最小值的步骤。其他设置和种子与预设方法相同。

## 结果

每格为 24 个独立测试集 R² 的算术平均。随机列对应上述每次抽样的全部 28 个子集期望。

ρ=0.8 时，现行规则在冗余机制下每次都保留 X₀、X₁，在抑制机制下每次都保留 X₁、X₂。前向方法在两个机制下分别选中 X₀、X₂ 和 X₀、X₁，各 24 次均改善测试分数。去掉取最小值的步骤，两个机制下仍选择同样的组合。现行规则与 F 在全部 144 个配置中有 143 个选出相同的列。

ρ=0.98 的抑制机制给出了前向法的反例。23/24 次边际排序首列为 X₂，一旦把它固定下来，剩余的一个位置无法保留 X₀ 和 X₁ 两列。相较现行规则，前向法在 2 次上升、20 次持平、2 次下降。训练目标最优对在 22 次选中 X₀、X₁，测试分数相较现行规则为 22 胜、1 平、1 负。八列模型能够同时使用 X₀、X₁ 和提供独立信号的第三列 X₂。两列预算本身限制了能保留的信息。

## 与现有研究的衔接

低维内核已经计算每个单同伴下的条件增益。可以用“单列增益 + 给定该列的条件增益”在同一次成对遍历里记录训练增益最高的两列。固定 K=2 时便可选出最优训练组合。前向法更便宜的潜力和完整成对评分的运行成本，都需要用实际内核计时来检验；此处的脚本以独立二元求解和枚举核验正确性，未测速度。K>2 时，仅找出最佳二列也不足以确定最终子集。下一项可检验的比较是保持原有训练样本、λ 和 K，对照原排序与二列起始组合，在预先留出的真实数据上同时报告选列变化、测试得分与含选列的总时间。
