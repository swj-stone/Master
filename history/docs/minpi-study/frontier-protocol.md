# Prospective cost and arithmetic checks

The unit for a timing comparison is one generated vote matrix. These matrices have no test outcomes and do not measure prediction. Fix the public scorer's sizes at 0, 4, and 16. Cross widths 128, 4096 and 16384 with 32 or 192 witnesses and abstention probabilities 0 or 0.75. Use independent generators for each combination and seeds 34123, 34127 and 34129. Generate each feature's location and each row's location independently from standard normals, make a positive ballot if a standard logistic draw is below their sum, then abstain independently. Compare retained fractions 0.02, 0.10 and 0.50 on each matrix. Fractions are repeated measurements of that matrix.

Compare the released exhaustive minimum, its certificate and the largest layer alone, including validation, row counting, weight calculation, scoring and stable support ordering in each call. Order the three calls at random in each of five measurement rounds after one warm-up, limiting numerical libraries to one thread. Save all elapsed wall times. Report median paired ratios and absolute times, the extra candidate count above the budget, the number of bounds equal to the actual first-pass cutoff outside the initial budget, and support agreement. Also measure the tally, layer weights and exhaustive column scoring separately, outside the primary timing loop. Use the existing raw-training and downstream experiments for the cost of obtaining votes and using the support.

Arithmetic checks use exact integer binomial counts and rational aggregation across witnesses. Test the three-row budget reversal at width 20, the balanced equal-composition case at width 20 and the following near-tie case at widths 128, 512 and 4096. In the near-tie case the first two rows coincide and are positive on the first half of the columns. The last row has precisely eight negative votes, in the first and last seven columns. Use budget one. This makes a small, strictly positive size-16 pivot probability distinguish two columns with the same dominant contribution. Record the exact gap and both double-precision supports, including disagreement. Include an all-zero boundary and direct enumeration of size-conditioned coalitions on the width-20 reversal. Float pruning is judged against exhaustive evaluation under identical arithmetic. These checks separately assess its agreement with the mathematically ordered objective.
