# Choice of the first layer

This retrospective operation-count study compares the anchors of the exact single-layer pruning rule. The default largest size was selected after earlier observations of frequent support agreement. Use every archived training panel and its original ten-percent budget, keeping Madelon separate when summarizing observed data. Compute every layer in exact rational units once. For each possible first layer, seed the candidate set with its first h columns in stable order, obtain the minimum over all layers on that seed and count every outside column whose first-layer upper bound reaches the smallest seeded minimum. Such columns must be examined under strict-score pruning. Verify that ranking only the retained columns gives the exhaustive support. Report the number examined divided by p for each anchor. This compares secondary-layer column work on the same mathematical game; it excludes the cost of computing the anchor and does not estimate elapsed time. No change to the default is selected from these results.
