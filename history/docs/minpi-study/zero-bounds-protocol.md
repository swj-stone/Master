# Point bounds for columns whose votes are all zero

Replicate the forced-dyadic precision study on its eight fixed matrices (six observed and two constructed). Its six peer-count sets, budgets and four grid precisions define 552 configurations. All-zero columns remain in the peer population. Their own signed increment vanishes on every row and layer. Set their initial endpoint pair to zero and reuse this value if another column sends a mixed boundary to arbitrary-precision comparison.

Run the original row-wide bound and the new zero-point rule on each target and precision. Generate a single randomized order of the eight policy/precision calls per round, with seed 44317 to make the interleaving repeatable. Use one warm-up and three measured rounds as in the original precision study. Each timed call starts with the same already constructed ballot matrix and ends with selected indices. It includes validation, row counts, rounding, candidate refinement and any exact column sums. Exclude the independent oracle, allocation of training ballots, and downstream fitting. Set numerical libraries to one thread.

Check each returned support against independent integer enumeration by peer composition; also compare the enumerated support with the archived target. Check the original implementation's candidate and fallback counts against every archived configuration. Record both implementations' actual counts, the original targeting scheme, per-call times and within-target ratios of the two three-call medians. Zero-point identification can reduce unnecessary calculations on one selected high-abstention panel. The sample deliberately includes tied and narrow cutoffs and provides no population estimate of that frequency.

The original kernel is the archived `src/minppi_mofs/integer_minpi.py` member of `rowwide-source-snapshot.zip`; the replay enforces its digest from the original precision study. The same archive includes the original verified-proposal and figure sources, each under its repository-relative path. Run `python -m experiments.minpi_study_zero_bounds --output fresh-zero-bounds` from a replication directory with its `src` on `PYTHONPATH`, or use the thesis PowerShell launcher. Figure 1c/d use only the zero-point rows of the resulting counts. Timing panels 1a/b retain their original inputs.
