# Locked MHEALTH wrist–ankle transfer

The controlled polarity experiment motivated a test on two body locations. This protocol was fixed after the simulations and before opening any MHEALTH observations or running any selector on this source. Source: Oresti Banos, Rafael Garcia and Alejandro Saez (2014), MHEALTH, UCI Machine Learning Repository, DOI 10.24432/C5TW22, CC BY 4.0. Use official recordings, 50 Hz. A is the right wrist (one-based columns 15–17) and B the left ankle (6–8). No alternate sensor pair, budget, learner or partition will be tried.

By participant, take nonoverlapping 100-sample windows starting at each contiguous run of one of activities 1–12. Discard partial windows and null activity. For each device separately, use x, y, z and instantaneous acceleration norm in that order. For each series compute mean, population SD, minimum, maximum, first quartile, median, third quartile, RMS, mean absolute first difference and mean absolute value (40 coordinates). Split participants 1–5 for development and 6–10 for testing. An individual window always remains wholly in one partition. Index each derived row by participant, activity and original recording offset.

For the training ballot, split windows at random within each participant and activity into disjoint reference and query banks of roughly equal size; choose at most 16 wrist queries from each activity across training people. Stratify queries by activity and take two ankle-reference queries per wrist-reference query, randomly permuting these reference-device assignments. Search standardized features of the assigned reference device for the closest same-activity and different-activity reference using unweighted Euclidean distance across all 40 coordinates. Exclude the query person's references. Compute scaling statistics on the pooled training reference bank, both devices with equal weights. Ties in distance follow bank order. Witness votes use signed per-coordinate absolute miss-minus-hit distances. The same resulting ballots feed mean sign, exact size 16 and the minimum over 0,4,16. Board membership and both raw window IDs of every triplet are archived. Each selector returns four columns with input-order tie breaking.

Fit one standardized multinomial logistic model (C=1, L2, lbfgs, max_iter=2000) on all development windows, using one device per window (independent ankle probability 2/3, label-blind). Include matched-width F computed only on these fitting windows, one seeded uniform subset of four columns, and the full 40-column model. Use the same fitting rows and labels for each method. For each of five test people, compute balanced accuracy (BA) separately on wrist and ankle using all their windows; calculate the smaller BA, then average equally across people. This is a prospective transfer check. The conditional simulation prediction is that minimum improves over size 16; evidence for a practical transfer additionally requires a mean gain greater than 0.01 and an increase for at least four people. Apply the same criterion against signs to assess incremental benefit. Report all six methods, subject-level paired differences and support identities whether or not this succeeds; no assumption of independent windows or AUC-to-BA equivalence.

For a secondary assessment of the game, split each test person's windows into disjoint query/reference banks within activity, build up to four queries per activity on that person's data only, and compute the selected columns' mean coordinatewise minimum of assessment layers. Use training scaling. Test labels used to construct this secondary ballot never inform selection or model fitting. Report cohort means and raw subject-level endpoints. Fix all random streams via SeedSequence entropy 20261123. Left ankle and right wrist differ biologically and in orientation; a measured polarity flip or the simulated nuisance-match probability is not assumed. No real-world performance was consulted to set the protocol.
