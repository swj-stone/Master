# Fixed-ballot correction cost and a full-width boundary

The two correction targets were identified before timing. The first uses the saved `train_votes` of the gas sensor panel (seed 1129), the peer counts 0, 1, 4 and 16, and 64 places among 128 columns. The second uses the three-row, 4,096-column unique-winner construction, peer counts 0, 4 and 16, and one place. These are deliberate examples of different failures in binary64. The gas target has three equal exact scores across the cutoff. The synthetic target has a strictly positive gap that rounds away. The selected cases cannot estimate discrepancy frequencies.

For each target enumerate the feasible compositions of peer subsets to obtain exact signed numerators for every column at every requested layer. Rank the rational minima with original column order for ties. Check both exact implementations against that reference after each call and save the omitted and added columns relative to the unverified binary64 proposal. The timed direct method is the public exact selector (both cases exceed its common-denominator word bound). The timed verifier includes a fresh float-pruned proposal, exact bounds, all refinement, exact boundary scoring when necessary and index-based selection. Neither timed path receives the oracle, earlier proposals, weights or scores. Record the number of columns refined and those passed to arbitrary-precision boundary scoring separately.

Fix the validated ballot contents across calls and limit numerical libraries to one thread. Start the clock immediately before calling a selector and stop it when it returns the support and diagnostics. Loading or constructing the ballots, computing the independent reference, and validating the returned arrays are outside this clock. Warm each method once. Measure 32 paired rounds per target, with each method in first position exactly 16 times. Shuffle the balanced orders with seed 12816 (chosen solely to replay the schedule). Thirty-two pairs give multiple observations in each quartile; store the median and empirical 25th/75th percentiles in milliseconds, together with all individual timings and the within-round ratio. These summaries characterize variation in repeated calls on one computer.

Separately construct a 2-by-128 matrix with 64 positive and 64 negative votes on the first row and its complement on the second. With one place and peer counts 0, 4 and 16, every exact layer mean is zero by cancellation. Check the even-peer tie probability against the hypergeometric formula and the exact integer oracle. For each precision permitted by the dyadic implementation at two rows, inspect the bounds it returns and the actual number of columns passed to its arbitrary-precision scorer. This tests a narrow-budget worst case for this implementation. A solver exploiting complementary rows could handle this matrix separately. Also record the released floating and native-aware exact selections.
