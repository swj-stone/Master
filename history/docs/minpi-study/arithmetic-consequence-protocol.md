# Arithmetic at the Gas cutoff and machine-word feasibility

Use the archived Gas witness matrix for seed 1129 and the expanded four-layer, half-width target from the rounding replay. This post hoc case is selected because the exact and floating-point supports differ at one column. It cannot estimate how often that happens. Fit the existing standardized ridge classifier on the two supports without changing its settings. Use the same rows and labels as the chronological Gas study (train on batches 1–7, test on 8–10). Report the balanced accuracy within each test batch and the equally weighted mean, exact minus floating-point. Retain row-level predictions, supports and disagreements so both the endpoint and pairing can be checked. The objective is to measure the consequence of this observed substitution for one fixed model. A deployment decision requires a loss tolerance chosen for that application and appropriate independent evaluation.

For the 42 original panel dimensions and tier sets, compute both the common-denominator and per-layer worst-case bounds with Python integers. Count panels whose separate layer sums would be safe in signed 64-bit arithmetic even though the common-denominator bound fails. Record the full integers for each input and whether each bound fits. This arithmetic feasibility calculation does not time a per-layer implementation.

Run from the study root with `python -m experiments.minpi_study_arithmetic_consequence --output fresh-consequence` in an environment with `src` on the Python path. On the thesis workstation use the study's PowerShell Python wrapper.
