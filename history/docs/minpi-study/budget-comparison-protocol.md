# Exact selection at three feature budgets

This extension uses the 42 observed training panels in the signed-word study, seven benchmark sources with five splits each, two cohorts with three training witness seeds each, and one wrist/ankle panel. The five Madelon panels are synthetic and excluded. No test features, labels, or prediction metrics enter the comparison. Each nominal budget retains the ceiling of 2%, 10%, or 50% of the columns, respectively. These correspond to narrow screening, the previous operating point, and retaining half the features. Two nominal fractions may select the same integer width on a narrow source. Keep both in their original budget strata and identify repeated targets. The layer set remains the released default, 0, 4, and 16 peers capped at the available peer count.

Run three policies for the same rational top set, using smaller original indices for exact ties. Dispatch uses signed 64-bit anchor pruning when the scaled sum fits and bounded dyadic scores with unresolved-boundary fallback otherwise. The exact anchor control uses the identical native path when safe and arbitrary-precision anchor pruning otherwise. The third policy proposes a support with the released floating-point pruner, then checks membership using rigorous bounds, resolving any remaining ambiguity exactly. Its time includes proposal, verification, and correction. All policies include tally construction and sorting. Time shared native execution only once per round and reuse that observation for both methods.

For each source and seed, reconstruct its training ballot matrix with the original preprocessing, training rows, and witness seed, then compute a reference order outside the timed loop. The reference explicitly sums payoff changes over every feasible combination of positive and negative peer counts, scales to an exact common denominator, and stably sorts all columns. Record support, exact boundary gap, the ballot SHA-256, and any differences between the raw floating proposal and this order. Verify every timed ballot and returned support against the reference. For dispatch and the verified proposal record the number of unresolved columns actually sent to arbitrary-precision rescoring. Separately count columns evaluated by an exact anchor, which uses its arithmetic from the outset. A direct native calculation is not a fallback.

Use a single BLAS/OpenMP thread. Per panel, run one warm-up and five measured rounds. In each round randomly permute distinct (budget, executed policy) calls, with one fixed schedule seed (73139) to reproduce interleaving. Each call begins with the panel's in-memory training arrays, constructs fresh ballots, and ends upon return of the support. Report ballot construction, scoring, and their total in milliseconds, excluding input disk access, oracle calculation, verification of the run, and downstream prediction. The five repeats characterize machine costs for each panel, not independent datasets. No timing threshold changes the selected implementation.

Compute the median total and score-only time of each policy within each panel and budget, then ratios of these paired medians (dispatch divided by comparator). Summarize ratios by their median across the 21 panels in each arithmetic range at each budget. Retain source-specific results, the median across source medians, absolute milliseconds, tie counts, and correction counts for interpreting concentration or near-unity ratios. No statistical model of timing or independent source sampling is assumed.
