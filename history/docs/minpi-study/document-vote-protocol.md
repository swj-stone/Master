# 变化词项上的自适应 minPI 投票

在检查本轮文本测试结果前固定五个词项预测任务：UCI SMS Spam Collection、UCI YouTube Spam Collection 和 UCI Sentiment Labelled Sentences 的 Amazon、IMDb、Yelp 三个来源。垃圾内容检测和情感分类分别报告。YouTube 以整段视频为单位留出，测试视频的评论不参加该折训练；其余来源分别对文档作三折分层检验。共 17 个外层划分。同一语料内的模型共用训练行和测试行。

每份文档仅取词项是否出现，不采用人工干扰项。分折前根据无标签词袋签名排除重复文档，词表仅由训练文档拟合。剔除不变化的训练列并核查外层 train/test 词袋重复，所有方法的原始列数均以共同处理后的实际变化词表为准。文档到词袋属于各方法共享的输入准备，单列其成本范围。模型链计时从已有词袋出发，各臂均使用同一稀疏标准化岭分类器。完整学习词表的原始文本服务时延不是本试验的主要指标。

候选对单词在两个条件下的留出平方损失改善投票。一个条件只含截距，另一个条件已含训练内找到的强预测词。直接对 CSR 文档中出现的词、类别、同现词计数，免于创建稠密的文档×词矩阵。分数取两个条件下较小值，保留覆盖 99% 正投票量的词，并用词表大小平方根的下界及一半词表的上界限制宽度。该比例是票量阈值，列数由各训练折决定。作为领域对照，使用单变量 F、卡方、均匀随机（分别比较与新版同宽及独立保留 50%）以及独立的文档频数过滤。额外计算 20 个同宽随机子集的分数。

每个划分要求真正删列、相对全特征测试平衡准确率最多下降 0.02、同时完整的选列至预测时间缩短。对每项基线另要求同一划分中分数最多低 0.02、列数不多于它且总耗时更低，另核对至多多 10% 列及至少快 5%、10% 的情况。以每种预定语料至少过半外层划分通过考查该领域的一致性。保留所有失败和实际耗时，报告各基线胜负。
