# Cost of returning the mathematically specified support

This design was fixed before producing the new timings. Retain the archived 10% budget and input-order tie rule. Replay five archived splits from each of the eight benchmark sources, the three recorded witness seeds from each of gas and materials, and the one wrist/ankle training panel. Madelon is a published artificial benchmark and is identified separately when counting natural cases. Repetitions on a source share data.

Start each timed selector from the in-memory training arrays. Regenerate the witnesses for each call. For MHEALTH start with the training participants' derived wrist and ankle windows, standardize as in the recorded acquisition protocol and draw the externally specified triplets. Exclude file loading, splitting and raw signal-to-window extraction. Evaluate six backends on the same deterministic witnesses: largest layer in double precision, exhaustive floating minimum, pruned floating minimum, exhaustive integer minimum, exact-integer anchor pruning alone, and the fixed-point certificate with exact boundary comparisons. The integer baseline uses the same row-profile counts, per-layer denominators and arbitrary-precision column accumulations as the exhaustive integer scorer. It computes the anchor for all columns and secondary layers only for the surviving candidates; it does not use rounded bounds. All methods repeat feature validation and their own weight preparation. Warm up each variant once. Randomize backend order in five timed rounds per case, using one numerical-library thread and a fixed scheduling seed. Save construction, scoring and complete selection time from a single call for each observation. Summarize medians within a case before taking medians over cases on a source. Absolute times, paired ratios and across-case ranges are descriptive measurements on this machine.

Separately time fitting and predicting once per timed round on the integer-certified support using the archived standardized ridge (the original shared logistic model for MHEALTH); these runs include extracting the selected columns. Whole numerical arrays and split enumeration are outside this scope. Correctness checks use an exhaustive integer oracle and exact adjacent-score gaps at ranks h and h+1. Save the fraction as well as its decimal, numbers refined past the anchor and sent to the final arbitrary-precision fallback, any float-to-exact support disagreement, and the number of columns within twice the certificate's maximum layer interval width of the exact cutoff. The input and target construction can still vary with the observations or the witness draw.
