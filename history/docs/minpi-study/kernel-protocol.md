# Conditional integration benchmark

The time to identify hit/miss witnesses and fit a downstream predictor can mask the cost of integrating the coalition game. This experiment fixes the ternary witness matrix before comparing the exact and sampled calculations. It measures numerical error, head-of-list recovery and scoring time. It cannot measure predictive performance.

Use 192 witnesses, widths 64, 512, 4096 and 16384, and independent synthetic seeds 127, 503 and 887. Cross each width with an abstention probability of 0.1 or 0.8. Give each feature an independent normal shift (standard deviation 0.45), each witness an independent normal shift (standard deviation 0.8), and draw the sign of each non-abstaining vote from the logistic of their sum. This design gives unequal, overlapping feature scores and a range of row margins. For each matrix, use the same clipped sizes 0, 4 and 16 as the public selector. Keep the top ceiling(0.1p) with stable column-index ties.

At each positive size k, draw an ordered sample of k+1 distinct columns. An outside focal column uses the first k as its peers. A focal column among the first k replaces itself with the (k+1)-st. The resulting peers are a uniform k-subset excluding each focal column by permutation symmetry. Every draw is shared across all features and witnesses. Accumulate row counts and correct only the k inside columns. This avoids both materializing a draw×witness×feature tensor and rescanning every column per draw. The empty stratum is available without sampling.

Use budgets 4, 16, 64 and 256 per nonempty size. Reuse the initial sequence of draws at larger budgets. For exact and each sampled budget, report the median of three in-process single-thread executions in randomized program order after a small warm-up. Compare mean and maximum absolute error across feature minima and overlap of the two top sets. Keep every matrix in the machine-readable table. A separate small-game enumeration checks the optimized sampler against direct marginal evaluation for the same draws before timing. No classifier, serialization or random witness generation is timed.

Before the first timing run, the second theory review added one deterministic reference: draw peers independently with replacement from all p positions, including the focal position. Propagate the distribution of the sum of k ternary ballots by convolution and report the discrepancy from the finite-population minimum. Coupling bounds its absolute error for each size by one minus the probability of k distinct draws avoiding the focal position. The implementation checks this bound and checks the replacement formula against exhaustive small-game sampling with replacement. This reference uses the same matrices and top-set budget.
