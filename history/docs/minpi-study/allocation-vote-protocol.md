# 有监督波段分配的验证

首轮波段代表算法在牛奶和小麦上能达到全特征精度，但独立保留一半列的 F 检验得分更高。本变体在这一开发结果之后提出。拟定时没有查阅追加采集年份、土壤、药片和芒果第三季的测试成绩。

每个连续 16 通道区域先保留一个投票代表，额外列可按波段局部的训练边际解释力及同伴投票分配，或者按全局投票分配。投票评估零同伴和半同伴条件下的留出损失改善，采用较小值。候选宽度为约 1/8、1/4、3/8、1/2；上限为 `ceil(p/2)`，与预定的 F50、random50 对照相同。独立的训练内校准以全特征及 F50 中预测较好的模型为参照，在每个允许方向容许额外 1% 的留出目标总离差平方和；先保留通过的最小宽度，全不通过时选最大超额损失最小的候选。该校准未经外层结果选择。

沿用上阶段七个开发任务的固定外层行。新配置包括 NIRBENCH 的梨 2019、芒果第二季、第三季、IDRC 药片含量和陈述于前阶段方案的 NIRsoil 土壤有机碳。药片使用第一台仪器，按 NIRBENCH 整理方案合并 calibrate 与 test 部分为训练集，以 validate 部分为测试集。不同年份／季节分别报告，芒果重复收获不算多个独立材料来源。对照包括原波段 minPI、上一轮强同伴 minPI、全量岭、同宽 F、同宽随机、同宽等间隔采样、F50 和 random50。保留额外 20 份同宽随机抽样成绩。纳入选列至预测的全部计时，额外验证及前端数据装载在所有计时之外。

分别记录各项基线实际列数、测试决定系数及总耗时。每个配置提供（1）删列、相对全量分数下降不超过 0.02、耗时下降；（2）在（1）成立时再分别对每个筛选基线要求分数差至少 −0.02、总时间更短、列数不多于基线；（3）同时满足 F50 和 random50，以及在相同实际宽度下的比较。另做允许 10% 列数差和至少快 5%／10% 的敏感性检验。采用单线程预热、9 次轮换和三个预定种子，各种子共用本来源的官方测试集。
