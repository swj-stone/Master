# UCI HAR subject-transfer protocol

This protocol fixes the analysis before running any selector on the official UCI HAR test subjects. The experiment uses the original 561 time- and frequency-domain features from the UCI archive, SHA-256 `c00b803081a5c797cd5e4b83700a9810b38d53d9d84e01917e090e1fdbc81031`. The original data cover six activities, with partially overlapping windows within participants. The official partition assigns volunteers to training or testing. The script checks the archive digest, shapes, six labels and disjoint subject identities. All columns enter under their original one-based feature IDs. [Reyes-Ortiz et al., UCI HAR](https://doi.org/10.24432/C54S4K)

Use the complete 7,352-row training partition for fitting rankers and learners. ExactMinPI builds its usual bounded witness sample internally. Use the 2,947-row test partition only after fitting. Predeclare selector seeds 17, 29 and 43. They change the witness sketch, ExtraTrees randomization and uniform random permutations. The subject partition and deterministic downstream learners remain fixed. No test value selects a seed, budget, method or learner.

## Fixed comparisons

- For each seed construct one set of triplets and its three cardinality-specific rates at 0, 4 and 16 peers. Compare their minimum (ExactMinPI), their arithmetic mean, the single largest tier, the plain signed vote from tier zero and a Relief-style control that averages the signed raw distance margin on the same triplets. Fixed ties use the original feature order.
- Compare one-way ANOVA F, Extremely Randomized Trees impurity ranking (64 trees, square-root split candidates, scikit-learn default growth), uniform random ranks, and the full feature set. Every ranker emits one ranking per seed, reused at all budgets. Use ceil(fraction × 561) for fractions 1%, 5%, 10%, 25%, and 50%, yielding 6, 29, 57, 141, and 281 columns. The 100% full-width anchor yields one deterministic prediction vector per learner.
- Compare standardized ridge classification (alpha 1, direct Cholesky, one-vs-rest) and standardized Euclidean 5-nearest-neighbor classification (uniform weights, brute force). Fit means and scales on training data. The full-width training scaler can be reused for column subsets since each feature is standardized separately. Every subset uses all training rows. Publish predictions and label errors for all six activities. No hyperparameter search.
- Primary endpoint is balanced accuracy averaged equally across the nine held-out subjects. Within each subject average recall over the six activities. Also report pooled balanced accuracy and ordinary accuracy. For the landmark 10% budget report every subject and the three-seed mean. Each seed is a rerun on the same participants, so no row-wise or seed-wise hypothesis test will be used. Other operating points document budget sensitivity. Report where ExactMinPI wins and loses against F, trees, plain vote, mean and fixed-largest-tier.
- Report Jaccard overlap of selected columns between ExactMinPI and each selector at each seed/budget, and between seed pairs within each method. A width-by-width summary averages the three overlap values. Store each support, test label, subject, and predicted label to permit independent recomputation. These comparisons concern original columns at fixed budgets and the observed subject partition. They provide no wall-clock claim.

## Reproduction

Run `.\thesis-python.ps1 -m experiments.minpi_study_subjects --check-data` for a lightweight integrity check and omit the option for all fits. Place the official outer archive at `data/subject-transfer/uci-har-240.zip`. All machine-readable outputs are written to `results/minpi-study/subject-transfer/`. Seeds may be resumed from completed files. Caching shared model predictions for exactly equal feature sets has no effect on predicted labels.

For the largest-tier comparison, save the exact number and fraction of features attaining each tier minimum, allocating tied minima equally (absolute tolerance 1e-12, zero relative tolerance). Report matched top-set overlap and paired prediction differences by subject and learner.
