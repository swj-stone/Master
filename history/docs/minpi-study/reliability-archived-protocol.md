# 方向一致性 minPI 在原词项数据上的固定复测

冻结 `reliability_document_top_from_training` 默认算法后，在已有原始 CNAE 三折和 Dexter 固定训练测试划分的三个种子重新比较。此二来源的旧单次 minPI 和三次中位数结果已被观察，因此本实验属于既有数据复测，不属于全新来源验证。不再用这六例修改候选公式或参数。

仅创建新 runner，复用 `document_vote_archived_panels` 的原输入、原 dense 下游及历史 full 预测。共 8 臂：reliability、旧单次 minPI、仅过滤不变化词项、F 同宽、随机同宽、F 半宽、随机半宽、full。半宽以实际变化词项数计算；匹配宽度对照免费获得候选宽度。每个筛选方法计入扫描原 dense 矩阵识别变化词项的成本，两种 minPI 另外各自计入 dense 到 CSR 转换成本。下游仍接收原始计数。

两个独立进程、每进程每方法轮换 8 次，正式计时独占 CPU。计时前逐臂预热并核对 full、旧单次、仅变化列、两种半宽对照的逐条预测和列索引与旧原始档案完全相同；两个 pass 改变计时顺序种子但不改变算法种子。保存逐次计时、列索引、预测及源和库的 SHA-256，在新进程逐项复现。

核心成功仍为实际删列、相对 full 平衡准确率下降不超过 0.02、全链总耗时更短。各基线比较附加不比其多列、下降不超过 0.02 和更快。独立审计从原始逐次计时重算中位数，以两个 pass 的成功交集为正式结果，并用逐条预测和类别计数得到精确分数 Fraction 核对 1e-12 浮点边界护栏。另报多 10% 列及至少快 10% 的敏感性。全留和失败全部保留。CNAE 三折和 Dexter 三种子不是六个独立数据集；本候选仅针对词项出现投票，不把连续数值数据的原 69 组声称为覆盖。
