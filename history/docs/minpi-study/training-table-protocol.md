# Five-way training-to-selection comparison

Table 2 uses a complete new timing series for all five policies. Inputs, the 42 panels, the 2%, 10% and 50% budgets, clipping of the three peer counts at p−1, one numerical-library thread, one warm-up and five repeats match the [four-way series](training-verifier-protocol.md). The exact anchor arm completes the comparison in one run. All three budgets remain in the analysis even when two budgets round to the same width on diabetes. Model fitting and test data never enter the timers.

The direct selector and the anchor comparator use the same signed-word kernel on the 21 panels where the common scale fits. Time the same public selector twice, including its branch test and ballot construction, in separate slots. On the other 21 panels the anchor comparator uses its validated integer anchor and full-precision layer totals; the direct selector uses its normal certified intervals. Both verified policies generate their own binary64 proposal inside their timer. The unchecked policy returns the list from the same binary64 screening kernel. Rerun the independent all-column integer oracle on each panel before timing. After each call, check its new ballot array and support; check the expected archived hashes, budget, width, peer set and exact gap outside the timer. The source filenames, hashes and software versions are archived with the result.

Randomize the order of the three budgets in each round. At each budget, randomly permute the five policies, then cyclically rotate their positions through a randomly chosen order of the five offsets over the five measured rounds. Each policy occupies every within-budget position once. Use an independent random permutation for warm-up, and use the protocol's schedule seed 73139. The timing window begins with training arrays in memory and ends with returned indices. Each policy builds new ballots and computes its own column scores.

Summarize the within-panel ratio of five-call median direct time divided by five-call median comparator time. Use linearly interpolated 25th and 75th percentiles and the median within each arithmetic range; also report the overall direct/unchecked ratios. The same five repeats supply the archived absolute times in milliseconds. The samples describe these panel inputs and hardware. For earlier timing records see the [four-way training comparison](../../results/minpi-study/training-verifier/findings.md) and the [original Table 2 series](../../results/minpi-study/arithmetic-price). Differences between these series are repeat measurements and do not isolate a code change.
