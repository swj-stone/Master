# Certification of a floating proposal using input order

Use the 42 observed ballot matrices in the three-budget comparison. At each of the existing 2%, 10%, and 50% budgets, recompute the full rational reference order and check the matrix hash, decision and gap against the archived target. Also include both fixed cases in the correction experiment, Gas at half width with the extra size-one layer, and the 4,096-column strict winner. These two cases deliberately have erroneous floating proposals. They test the rejection branch and are reported separately from the 126 nominal comparisons.

The numerical-only verifier and the index-aware verifier first produce the same binary64 proposal. Both compute identical integer intervals, refine every proposed column and refine each outsider whose anchor upper bound reaches the smallest proposed lower bound. Once outside bounds are available, a strict separation of numeric endpoints accepts either proposal. In the new verifier equality also suffices when the largest proposed index at the weakest lower endpoint is smaller than the smallest outside index at the highest upper endpoint. This is equivalent to strict ordering of the endpoint pairs (score, minus original index). The original numeric threshold is used to screen challengers; this experiment changes only final acceptance. If neither test decides the case, both use the same boundary routine, with exact integer scores as necessary. The archived strict verifier is kept intact.

Construct each ballot once, before timing. For each fixed matrix run one warm-up and five timed rounds per method and budget. Use a seeded permutation of budget/method calls in each round (seed 73139, inherited from the three-budget comparison) and limit numerical libraries to one thread. The direct integer selector supplies a third comparator for the same target. Every timed sample includes receiving the matrix, scoring and returning the support, including the floating proposal, verification and correction if applicable. Exclude input reconstruction and independent oracle calculations. Record method decisions, refined columns, exact-score columns, correction size and raw nanoseconds. The differences between the methods' within-target median times are implementation measurements on one workstation. Summaries by budget use ratios of these medians with each panel counted once. A successful early decision need not reduce wall time.

Reproduce from the study root with `python -m experiments.minpi_study_tie_keys --output fresh-tie-keys` with `src` on the import path, or use the thesis PowerShell Python wrapper. The deterministic regression tests also enumerate indexed-subset reference scores and possible integer score vectors within small interval enclosures.
