# minPI 的条件重新拟合与相邻规模最低分

后续的跨数据验证增加了按环境打分、完整发现集校准、反向删列和跨进程复现核验。[稳定性与复现记录](stability.md)

本轮从已经运行过的分组近邻 minPI 出发。最初要解决的是 Gas 选择 64/128 列时分组版在训练期晚批次验证上的平衡准确率为 79.87%，相同预算的均匀随机选列为 85.47%。目标同时考虑预测质量和从筛选、取列、拟合岭模型到预测的总耗时。原稿的整数排序结论适用于原来的多数投票游戏；下述预测误差游戏按双精度计算。

## 投票和最低分的修改

1. 在外层训练样本内做双向交叉拟合。给定已选特征集合，每条内层评估样本为候选列投一张带符号、带大小的票，其值是加入该列前后的平方预测误差之差。连续目标使用原目标，分类使用独热目标。相同的单位岭惩罚用于每次条件重新拟合，所有候选共享一次矩阵分解。等价地，这张票衡量加入该列后，样本从超出容许误差变为达标（或相反）所覆盖的阈值区间长度，并按变化方向赋予正负号。
2. 首个重新拟合版 `refit` 按已选列数 0、1、2、4……分块。在各检查点重拟合模型，对每个未入选列保留迄今访问过的前缀上的最低平均得票，并据此确定下一块。每个规模对应实际已选的特征集合。它与在所有等大小随机联盟上求期望是两种不同的评分定义。
3. 关闭“保留过去最低分”，只用当前层的条件重拟合分数，在 Gas/材料 × 开发/已知留出 × 两档预算的 8 个平均值中改善 7 个。Gas 半宽开发准确率从 84.78% 到 88.07%，材料 10% 开发 R² 从 0.6143 到 0.6265。这是对同一划分的消融。[逐阶段消融](../../results/minpi-study/refit-ablation-20261117a/summary.csv)
4. 新版本 `local_refit` 在当前集合与去掉最后一个入选特征的集合上分别计算新增候选的贡献，取两者的最低分。已选集合为空时只有一层。它保留条件投票与跨规模最低分，仅使用当前附近的证据。每个块内的入选顺序决定“最后一列”。普通岭模型逐列重新拟合与批量公式的小样本核验见[实现测试](../../tests/test_local_refit_minpi.py)。

~~~python
from minppi_mofs.support_selector import PivotalSupportSelector

selector = PivotalSupportSelector(rule="local_refit", fraction=0.50, random_state=1129)
X_train_selected = selector.fit_transform(X_train, y_train)
X_test_selected = selector.transform(X_test)
~~~

回归任务显式传入 `task="regression"`。新规则通过 `rule` 启用，旧调用默认的 `static` 仍能复现实验。所有新规则只使用传给 `fit` 的训练行；内部选列会适应训练期验证信号，因此质量以外层评估行计算。

## 精度和时间的取舍

最终接入公开选择器的是相邻规模的增量实现。它在两次选列之间保留岭回归的矩阵分解与残差，并用最后一列更新，无需独立重建两个模型。UCI HAR 的半宽同场实验中，筛选从 143.2 ms 降至 65.6 ms，端到端从 340.9 ms 降至 259.0 ms；全特征为 437.0 ms，匹配 PFI 为 314.9 ms，上轮分组为 212.5 ms。相对全特征少 0.714 个百分点，节省 40.7% 的总时间。45 次计时调用均复现先前的支持集和预测。Gas/材料/乳腺/糖尿病的 90 个配置也逐列、逐预测一致。浮点运算顺序有差异，对未测试的近似平票输入没有逐位一致性保证。[HAR 增量计时](../../results/minpi-study/har-fast-half-20261117a/summary.csv) · [90 组核验](../../results/minpi-study/local-refit-fast-verification-20261117a/audit.csv) · [Gas 和材料的增量计时](../../results/minpi-study/local-refit-fast-verification-20261117a/summary.csv)

在 UCI HAR 的 50% 预算下，首个相邻规模实现为 94.98% / 343.6 ms，全特征为 95.70% / 436.8 ms，大样本 PFI 为 94.16% / 612.1 ms，小样本 PFI 为 94.45% / 314.5 ms，上轮分组为 94.07% / 208.5 ms。63 次调用逐次复现同一预算下的已存列和预测。计时在单线程下轮换运行，每个种子取三次中位数，再取三个种子的中位数。[跨被试逐次计时](../../results/minpi-study/har-half-timings-20261117a/timings.csv)

最后在 ISOLET 三个划分上核对了增量实现。9 次复测均复现参考实现与此前归档的特征名单、准确率与 AUC。同场的增量版为 91.21% / 546 ms，参考实现为 91.21% / 647 ms，上轮分组版为 91.33% / 441 ms，全特征为 92.12% / 1,324 ms。[ISOLET 实现对照](../../results/minpi-study/isolet-fast-half-20261117a/isolet.csv)

Gas 半宽开发实验中，局部版与全特征分别为 33.1、70.8 ms。局部版在历史第 9、10 批的平衡准确率降到 63.79%、46.87%，同批旧分组版分别为 88.05%、75.22%。材料 10% 的开发和历史留出中，局部版耗时分别为 3.9、6.2 ms，小样本 PFI 分别为 5.1、7.8 ms。材料开发 R² 距全特征仍有 0.104。ISOLET 半宽上局部版为 651 ms，上轮分组版为 455 ms，且稍准。乳腺数据保留 50% 特征时，局部版的平衡准确率为 95.18%，全特征为 95.38%，总耗时分别为 3.1、2.0 ms。[配对计时](../../results/minpi-study/local-refit-iteration-20261117a/summary.csv) · [支持集与预测核验](../../results/minpi-study/local-refit-iteration-20261117a/audit.csv)

另一条实验路线 `restoration` 用恢复一列之后的预测变化投票，比较其余全部列干净和已有目标数量的列被扰动两种情况。Gas 可在 `fit` 中传入训练批号及 `ordered_groups=True`，用训练期最新一批评价候选。在保留 10% 的开发实验中，双层最低分为 81.19%，使用同一模型、样本和置换的零扰动层为 78.16%，单用目标扰动层为 76.24%。保留 50% 时对应为 87.42%、88.81%、87.80%。同条件零层等价于 PFI，双层收益随预算变化。[恢复投票与单层对照](../../results/minpi-study/restoration-iteration-20261117a/summary.csv) · [逐列直接置换核验](../../results/minpi-study/restoration-iteration-20261117a/audit.csv)

另有两项固定联合岭模型、按同伴数取最低预测误差贡献的实验，`utility` 一次性排序，`coalition` 每选一列即更新边际贡献。它们在 Gas 开发半宽分别达到 84.33%、80.69%。同任务的相邻规模重新拟合达到 88.08%。[完整对照](../../results/minpi-study/predictive-iteration-20261117a/summary.csv)
