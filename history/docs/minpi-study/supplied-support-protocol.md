# Auditing a supplied feature list

The starting inputs are a fixed, in-memory ballot matrix, peer counts, a prescribed size and an already available list of feature indices. Compare the public direct exact selector with the index-aware certificate given this list. The certificate validates the list's cardinality, range, integer indices and uniqueness, and returns the prescribed membership, correcting it when necessary. Both procedures validate the ballot matrix and compute their own layer weights and bounds. Neither reuses intermediate scores or bounds. Time from entry to return, including input validation, index sorting, certification and any correction. Exclude ballot construction, list generation, the independent exhaustive oracle, equality checks and model fitting.

Use the same 42 observed panels and three retention budgets (2%, 10% and 50%, rounded up) as Table 2. Freeze each list once from the archived floating-point selection algorithm before either timed method runs. Recompute the independent all-column integer oracle and match the stored ballot hash, support and cutoff gap. Retain all 126 targets, including repeated diabetes widths. The additional two cases deliberately supply incorrect lists: the half-width Gas matrix with four peer counts and the three-row, 4,096-column strict winner. Their times describe these two audited corrections.

For each target, warm each method once. Pair the two calls consecutively on the same matrix in memory. Use five measured pairs per observed target to match Table 2, with each method first in at least two pairs. Use 32 pairs for each correction to describe run-to-run variation on these two very short calls; each method starts exactly 16 times. Shuffle first positions with the seed 73139 used in the budget study. Limit numerical libraries to one thread. Compare every returned list against the oracle after stopping the clock. The per-target ratio divides the median audit time by the median direct time. Summarize the 42 ratios separately at each budget, and report each correction individually. Within-target repetitions and different budgets do not add independent datasets.
