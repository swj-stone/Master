# Exact integer support experiment

The constructed near tie motivated a second algorithm. Its guarantee concerns integer counts for the specified finite game. It rounds signed row numerators down on a dyadic grid, bounds the unrounded sums, then uses exact integer scores where the support boundary remains undecided. Before timing this version, fix 40 fractional bits (automatically reduced for exceptionally many witnesses to prevent signed overflow). Compare against both its own exhaustive integer calculation and the existing pruned floating-point method. Include all three near-tie widths, a tied all-zero matrix and widths 128 and 4096 crossed with 32 and 192 witnesses on new seeds 38119 and 38149, 10% retention, abstention probability 0.75. For the wide case also run 16384 columns and 192 rows, seed 38119. Use five randomly ordered rounds after a warm-up. Evaluate agreement on real fixed training witnesses for all five archived Communities and Crime splits and the first archived Gisette split. Use a common input for all methods, record absolute times, candidate counts and how many columns need exact boundary arithmetic. Each training split is a retrospective numerical audit.
