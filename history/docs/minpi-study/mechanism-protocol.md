# Independent matched-triplet stress experiment

This protocol was written before generating the outcomes. It tests the scoring rule conditional on supplied comparisons. The supplied triplets emulate correct and reversed hit/miss assignments. No nearest-neighbour search takes place in this simulation.

## Population and interventions

Generate 48 independent worlds in each of two regimes, using NumPy SeedSequence with entropy (20261117, regime index, world index). Randomly permute 60 columns independently in every world. Six columns measure a binary class, six measure a binary acquisition site and 48 measure a common binary background condition. Within each block the loading of each column is sampled independently and fixed for the world. Class and site loadings are uniform on [0.65,1.25]. Background loadings are uniform on [1.5,2.5]. Each measurement equals its loading times the corresponding sign plus independent standard Gaussian noise.

Each triplet consists of a query and two references. The query's class, site and background are independent random signs. With probability one half the designated hit matches the query's true class and the miss has the opposite class (valid). For the other triplets, the hit has the opposite true class and the miss has the same class (reversed). In valid triplets the designated hit is from the opposite site and the miss from the same site. In reversed triplets the designated hit is from the same site and the miss from the opposite site. Thus class and site provide competing explanations for the acquired comparison. In a *structured-background* triplet, a fair coin decides which reference matches the query's background, and the other reference has the opposite background. In an *unstructured-background* triplet both references have the query's background. The former induces a largely aligned background ballot of random sign; the latter leaves background distance differences to measurement noise. These conditions are assigned before generating feature values. No triplet is accepted, rejected or relabelled on the basis of its measured votes.

Regime 0 assigns the unstructured background to valid triplets and the structured background to reversed triplets. Regime 1 interchanges this assignment. Both regimes keep the same marginal prevalence of valid comparisons, site confounding, signal distributions and downstream population. On raw measurement scales a coordinate votes by the sign of its absolute miss distance minus absolute hit distance. Positive within-coordinate standardization would preserve the sign.

## Samples, budget and outcomes

Per world, independently draw 192 training triplets and 768 assessment triplets, sharing only the world's loadings and feature types. Select six columns (10%) by the mean sign vote, the exact size-16 pivotal score, or the minimum of the scores at sizes 0, 4, and 16. Use input order for ties. Evaluate a selected set on the independent triplets by its mean across selected columns of each column's minimum across the three assessment layers. Count its true class features. Record how many features the minimum replaces relative to size 16, and report all worlds, including identical supports.

For the independent prediction endpoint draw 384 fitting observations and 1,536 test observations with independent fair class, site and background signs and fresh measurement noise; fit a standard scaler followed by logistic regression (C=1, L2 penalty, lbfgs) to each support using only the fitting sample. Measure held-out ROC AUC and probability log loss. This endpoint asks whether columns chosen from acquired comparisons predict the true class when site and background are unrelated to it. No downstream fits see assessment triplets or test outcomes during selection. The sole prediction tolerance is 0.01 AUC. Include the difference in mean absolute row imbalance between the two background structures as a manipulation check. Archive per-world data summaries, every support, held-out predictions and world identifiers.

## Direction and uncertainty

The primary contrast is paired test AUC for size 16 minus mean signs. Predict positive mean difference in regime 0 and negative in regime 1. Accept the directional prediction only if both two-sided 97.5% paired world-bootstrap percentile intervals exclude zero in their prespecified directions (Bonferroni for two contrasts). Separately report whether those intervals clear the respective 0.01 practical margins. Use 10,000 resamples of 48 whole worlds within each regime, seed 20261118. For minimum minus size 16, report descriptive paired 95% world-bootstrap intervals in AUC, log loss, recovered features and assessment weakest-layer score, and the count of worlds whose selected set changes. An empirical advantage of the minimum on its own surrogate needs a positive interval there; predictive improvement requires a positive interval in AUC. No minimum-benefit direction is prespecified. Neither these deliberately confounded acquisitions nor artificial frequencies estimate prevalence on real tasks.
