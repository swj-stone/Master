# Training-to-selection timing for index-aware verification

Start each timed call from the same in-memory training arrays used for Table 2. Input loading precedes timing, including the preparation of MHEALTH windows. The clock includes constructing a fresh ballot matrix and returning the selected indices. For either verifier the clock also includes producing its own binary64 proposal, constructing bounds, and any exact correction. Pure floating pruning and direct exact selection are timed in the same run to show the cost of the comparator and to provide a repeat measurement of the earlier comparisons. No policy receives cached ballots or a supplied list. Fitting the downstream model, input checks against the archive and correctness checks against the oracle are outside the clock. The public selector's own argument validation is timed.

Use the 42 observed panels and the prescribed 2%, 10% and 50% budgets from Table 2. They compare a small screen, the original one-in-ten budget and half the original width. Rounding upwards gives the same one-column budget on the five diabetes panels at both 2% and 10%. Keep these panels in both budget strata. Before each panel, compute the full integer reference support and true cutoff gap independently. Check the archived ballot SHA-256, dimensions, peer counts, native-word classification, gap and proposal membership. After each run, compare the rebuilt ballots and the selected support with the expected values.

Use the original single-threaded numerical libraries, one unrecorded warm-up per policy and budget and five recorded rounds. Randomize the order of the three budgets within each round using seed 73139 as in Table 2. Keep the four policies in adjacent slots within the same budget. At each budget, randomly permute a four-policy cycle and rotate it through all four positions in the first four measured rounds in a random order. Use a fresh permutation in the fifth round. Each policy appears once or twice in each position. Timing repeats measure variation on the same input.

For each panel and budget, divide the five-call median of direct exact selection by the five-call median of each comparator. Report the median and the linearly interpolated 25th and 75th percentiles across the 21 panels in each arithmetic group. The 42-panel pooled summary, absolute panel medians and same-run index-aware/strict ratios are also archived. Table 2 adds two marked rows from this run and retains the earlier timing records for its other rows. These are observational panel summaries; splits overlap and the gas and materials seeds reuse their respective training partitions.

To repeat the measurements in a new directory, run `python -m experiments.minpi_study_training_verifier --output fresh-training-verifier`. To regenerate Table 2 from the archived records alone, run `python -m experiments.minpi_study_training_verifier --report-only --output results/minpi-study/training-verifier --table rebuilt-table.tex`.
