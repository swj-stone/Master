# Layer, precision and budget sensitivity

Design fixed before the new runs. The target is the exact top set of a specified finite vote game. Changing its set of peer counts changes the game; changing grid precision may change the work needed to certify it. No predictive outcomes are used in this study.

Use the first recorded gas, materials and wrist/ankle panels, the two exact-boundary-tie panels (diabetes 2027, Communities and Crime 3301), and the narrowest positive budget gap among the previous empirical panels (Gisette 3301). The last three are retrospective numerical stress selections. Add the two previously reported 4,096-column near ties with a unique or a tied maximizer. These are not independent random draws. Audit the following six peer sets, capping the prespecified template counts at p−1 for the ten-column diabetes dataset: {0}, {4}, {16}, {0,4,16}, {1,5,15}, and {0,1,4,16}. They separate raw signs and individual layers, compare an all-odd target, and isolate the addition of an odd layer to the default game. The public API rejects an explicitly infeasible size.

Cross each peer set with budgets 1, ceil(p/10), ceil(p/2), retaining unique budgets within each panel. For diabetes the first two requests coincide. Use fixed-point precisions 0, 8, 20 and 40 fractional bits. Their worst-case bounds on single-column normalized interval width are 1, 1/256, about 10⁻⁶, and about 10⁻¹². This checks a coarse stress setting, an inexpensive diagnostic precision, an intermediate precision near the smallest positive real gap previously observed, and the implementation default. With a mathematical tie, finer precision alone need not settle the specified input-order decision.

For each panel, peer set and budget, compute the exhaustive rational target, exact adjacent gap and overlap with the same-budget default peer set. Check every precision against that oracle. Time the public integer backend on fixed votes, including tally formation, sorting and necessary refinement, using one thread and three randomized measured rounds after one warm-up. Archive selection indices, refined and fallback counts, time for every call, and a float/exact agreement check at each target. Record and interpret grid dependence for a fixed target separately from changes of target. No parameter is tuned on these cases.
