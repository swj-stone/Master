# 外部来源检验与训练条件

本方案在读取新算法的任何测试结果前确定。问题是已经剔除训练常量后，最差同伴数下的投票能否从真正变化的列中比随机抽出更有用的列。

1. 来源指定的探针数据使用已有的 Gisette、Arcene、Dexter 三个数据源。Gisette 用本地原始注册快照（5,000 列）。将行按类分成三个互不重叠的池，每池分层抽 1,536 行训练、512 行测试。Arcene、Dexter 分别只计一个官方训练/验证划分，和原额外面板共享验证行，列空间在本专项中另行定义。这三种数据在发布时均含由挑战组织者加入的探针。[挑战说明](https://papers.nips.cc/paper/2004/hash/5e751896e527c862bf67251a474b3819-Abstract.html)
2. 自然数据对照采用此前两个主面板均未包含的 UCI Multiple Features。将每个原始字符的六套特征按原行号连接成一个 649 列样本，完整使用数据发布时的数值。用三个互斥的分层测试折，每折以其余样本训练。真实书写者的 ID 不可用。[数据与类别说明](https://archive.ics.uci.edu/dataset/72/multiple+features)
3. 每一折从所有模型的共同输入中移除仅在训练中恒定的列，再训练、计时、评价。宽度的分母和全特征对照都只含训练中变化的列。该操作是构造专项任务的公共前处理，记录其耗时，另报将这段成本同时计入各臂后的时间比。其节省不归入 minPI。各折对所有方法使用相同行和相同的列置换。
4. 保留冻结选择器的 99% 正投票量规则；同宽 F、同宽零同伴投票、同宽随机及全特征各自重训岭分类器。额外用 32 个独立同宽随机支持估计参照分布，固定岭模型种子。若 minPI 实际删列、平衡准确率下降不超过 0.02、端到端计时中位数短于全特征，且测试分数严格大于至少 24/32 个随机支持，记为一次强化成功。同一数据源有三次划分时须至少两次强化成功；官方单划分的结果单列，不能据此声称跨划分稳定。三个探针来源均过线才支持跨来源的该类主张。自然对照单列。计时预热后单线程，五臂各测五轮。
5. 另在原 69 组、额外 57 组和来源专项检查可从训练过程识别的条件：训练行数至少为 512、变化前主面板的可用宽度或来源专项剔除常量后的宽度至少为 32、冻结选择器得到的宽度至多为输入的三分之一。这个“投票集中”标记是第二项独立假设，不使用测试成绩调整门槛。报告覆盖来源数与每来源结果。对前两个面板的多随机核对按 20 次中至少严格胜过 15 次计。
