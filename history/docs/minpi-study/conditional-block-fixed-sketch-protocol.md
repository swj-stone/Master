# 条件整块 minPI v2：保持原始投票样本的必要控制

v1 的源已按原 manifest 核对并保存于 `conditional-block-development-20261117a/source-snapshot.zip`，新进程所有数组、40 臂支持/预测/分数和内部统计精确重放。v2 为新模块和新 runner，不修改 v1。

此控制消除重新划出 calibration 后投票子样本改变的混杂。沿用原 document minPI 在完整外层训练数据上以原 seed 抽取的 512 行及原零／一同伴层分数，保持每个端点和取最小值完全相同；仅将并列时使用的 marginal 改为该 512 行统计，避免 calibration 标签影响并列排序。提供固定旧全训练宽度 k。所有 teacher 拟合、残差提案、伙伴选择和小块重估只使用这 512 行；从其余训练行用 SeedSequence([93019, seed]) 不放回等概率抽取至多 256 行作为 calibration。若投票或校准缺少类别则明确拒绝，不另试 seed。当前原型要求 n>512。

这仍是以给定 k 为条件的归因控制，k 来自旧全训练自动宽度可能使用剩余行标签，不能称为完全隔离的自动预算算法。native 旧核会计算未使用的全训练 marginal，v2 明确丢弃它；改动所有非投票行的数据/标签不改变新 rank、支持提案或拟合系数已由测试核验。

一次 8 列交换、最多 16 列局部重估、global 空/全同伴 minimum、local 最终及平均少一同伴 minimum、calibration BA 最多下降 .02 的门槛全部保持 v1，不再调公式。比较相同512行rank的无交换支持、同512行 F/pooled、全训练旧版/F/pooled、同宽随机与 full。对机制的判断使用交换后减无交换，不能把与旧版并列处理差异的收益归为交换。

仅运行同一 SMS/Amazon/IMDb/Yelp 第一折四个开发配置；若仍无可靠改善则冻结该分支，不扩大验证或根据外层结果改参数。全部支持仍在完整外层训练数据重新拟合同一下游。单次耗时仅作非正式开发诊断，不作加速结论。保留源码快照、负面结果和新进程精确重放。
