# 自适应 minPI 的本轮验证方案

本轮在读取新候选的外层结果前确定如下比较。沿用分数容差 0.02。主指标按同一配置计算，每组须确实删列、相对该组全特征岭模型保住任务分数、从选列到预测的总耗时中位数严格更短。全留计为失败。另报精确不掉分以及加速至少 5% 和 10% 的结果。

基线的实际宽度和时间也参与判断。对每项基线分别报告，在相同一组里，新版分数至多低 0.02、总耗时更短、特征数不多于该基线的次数；另用允许多 10% 列作敏感性检查。与基线的比较同时要求新版自身取得上述三项达标。固定保留一半的 F 检验与均匀随机都使用 `ceil(p/2)` 个特征；这两项和原自适应 minPI 都有独立于新版的宽度。此外，逐例让 F 和随机免费获得新版的宽度，以检查胜负是否能由列数单独解释。统计使用每个配置的预热后重复计时中位数，不允许按组用外层分数挑方法。

原 69 组和原额外 57 组重新测量两种通用候选。联合岭投票估计在不同同伴数下增加列的留出贡献，并在训练内检查整个候选子集的丢失。配对投票根据不同训练方向和同伴数下的投票一致程度及信号集中程度决定宽度。这些数据曾用于以前的开发，外层成绩用作已有面板的重测。

本轮独立应用为具有已知波长次序的真实近红外光谱回归。采用 NIRBENCH 发布方冻结的训练和测试样本，预选编号 1、5、13、15、19、22、30，每个采集来源只取一个任务，各任务均有至少 100 个光谱通道。主要类别在目录发布时已有至少 512 个训练样本，含牛奶蛋白、梨可溶性固形物、芒果干物质和小麦蛋白四个不同来源。小样本对照为小麦籽粒蛋白、瓜果可溶性固形物和另一采集批次的小麦水分。所有测试只使用光谱变化的原始测量，三个选择器种子共用固定外层测试划分。核查每组跨训练/测试完全重复的光谱并单列实际排除数。

对波长已排序的光谱，候选算法将相邻且训练相关性足够高的通道划为小区间，每区间保留一列，由两个同伴条件中的较低留出增益决定代表列。额外加入同宽均匀间隔采样和同区间取中央波长的对照。主要类别的稳定性按来源报告，要求四个来源分别至少 2/3 个种子满足联合指标，同时给出各项基线上的实测差距。对逐组固定 50% 的独立宽度基线，还报告同时通过随机和 F 两种比较的交集。若方案未通过，开发修改要与新样本检验分开记录。实际运行时间由完整重训决定，属于本机计时。
