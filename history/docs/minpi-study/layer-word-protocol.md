# Separate integer scales at the selection boundary

Compare the existing exact selector with a second selector that keeps one integer denominator per peer count. For each size k let D_k = choose(p−1,k). The magnitude of every signed partial column sum at that layer is bounded by w D_k. When every bound is at most 2^63−1, the new selector accumulates numerators in signed 64-bit words, omits the common positive factor 1/w and compares the resulting signed ratios using arbitrary-precision integer cross products. The largest peer count gives an exact upper bound. Score the leading h anchor columns, retain any outsider whose anchor can equal or improve their weakest exact minimum, and resolve ties by the original column index. If any layer exceeds the bound, run the existing dyadic selector. The original selector still dispatches by the common denominator; the new selector actually uses separate scales even when a common scale fits. No decision uses the test labels or a timing threshold.

Use all 42 original measured training panels, with their original votes, capped peer counts and ceiling budgets of 2%, 10% and 50%. These budgets permit comparison with the previous screening experiment. Match every panel's ballot hash and archived support and recompute its full ordering by independent exact composition counts. Check every timed support after the clock stops. The five diabetes panels have the same target at 2% and 10%. Classify panels using their denominators before timing: both bounds fit, only the separate-layer bound fits, or neither bound fits. In the last group both selectors call the same dyadic algorithm, but the publicly callable routes include different eligibility checks and are timed separately.

There are two disjoint timing scopes. One starts from the in-memory training arrays, rebuilds the ballot matrix, and returns the selected indices. It excludes disk reads and downstream fitting. The other starts with the cached ballot matrix and calls the complete scoring function again. It includes checking eligibility, exact row counts, native accumulation, rational comparisons, and the return of the support. These cached-ballot times are separate calls, not a subtraction from the integrated time.

Use one numerical-library thread, one warm-up per (panel, budget, scope, policy) and five measured calls, following the previous timing protocol. At each repeat independently randomize the order of the six budget/scope pairs and the order of the two policies within each pair using schedule seed 73139. Use each policy's median over the five calls in each panel, budget and scope. Report the ratio of the separate-layer policy median to the existing selector median. Summarize individual panel ratios by their median and 25th/75th percentiles for the three arithmetic strata and all layer-eligible panels together. The three materials panels reuse the same training split with different ballot seeds. These descriptive comparisons do not establish independent population effects.

From the package root with `src` on the Python path run `python -m experiments.minpi_study_layer_word --output fresh-layer-word`. The study PowerShell wrapper supplies the same path locally. The result directory contains each call in nanoseconds, ballot hashes, exact support identifiers, within-panel medians and grouped summaries.
