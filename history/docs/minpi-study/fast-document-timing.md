# 二分类投票实现的重复计时

另将同一冻结实现用于已有 Apache SpamAssassin 跨采集批次的独立邮件试验，使用原训练词表和相同的三个选择种子。该面板仅有一个固定的外层测试批次，结果与 17 个 UCI 划分分别报告。三个种子均保留为计时配置，不作为三个独立测试集。

复用已归档的同一 17 个外层划分、原始 UCI 文本、训练词表、标签、模型与选择种子。加速只针对二分类二值 CSR 的实现。每组先和原实现比对自适应宽度、词表内的列索引、两个端点的增益、最终投票分数及完整模型预测。按原索引逐项核对数值差与浮点位模式，分别报告完全相等和最大绝对差。将原 17 个存档的所有支持和预测作为参考。

每组计时包括快速二分类 minPI、原 minPI、全特征、同宽 F/卡方/均匀随机/词频前列、固定半宽 F/卡方/均匀随机、文档频数至少 2，以及同宽和固定半宽的全训练集单词边际岭增益。后两项采用二分类二值 CSR 上的闭式计数，按列号打破平局。每组核对全部词的边际分数与独立矩阵实现一致，在已有消融存档的 17 组逐项核对同宽支持及预测。全部使用相同稀疏标准化岭分类器，对照在同组获得 minPI 的实际宽度。先预热，每轮按种子决定的初始顺序循环平移，13 次重复使每个方法恰好占每个计时位置一次。计入每次重新选列、取列、标准化、拟合、预测。另在两个独立进程完整计时，第二轮使用不同的轮换初始顺序，并对照第一轮及上次归档的逐项输出，另外在新进程复核。额外 20 个同宽随机子集由原档案给出，固定宽度及候选预测都复现后可重用该分布。

沿用原标准，实际删列、平衡准确率相对全特征下降最多 0.02 且总耗时更短。对每一基线，报告同时满足自身联合成功，且比该基线列数不多、分数至多低 0.02、总耗时更短的次数，另列允许多 10% 列的敏感性。对于固定 50% 的 F、卡方、随机三者及加入边际岭的四者，报告同一划分跨多项对照及两轮计时的交集。计时从已取得的词袋矩阵开始，原始文本的共同词表准备耗时单列。
