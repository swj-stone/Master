# 冻结文本 minPI 的邮件批次转移检验

短信与视频评论的首轮结果出炉后，保持 document_vote 的代码、阈值、词袋和模型不变，在 Apache SpamAssassin 的独立发布批次上检验。使用 20030228 版 easy_ham、hard_ham、spam 训练，使用 easy_ham_2、spam_2 测试。依发布者勘误排除 spam_2 中编号 00529 的一封误标邮件。仅使用邮件正文，优先 text/plain，必要时取 HTML 可见文本；移除空文档、附件以及具有重复词袋的消息。固定训练内词汇表，过滤训练常量词，核对训练与测试的投影词袋。忽略邮件头、文件名、文件夹、附件名、外部链接内容。样本按成员文件名排序以保证重现。

三个固定选列种子 1129、2027、3469 共用发布方的批次划分。模型从数值词袋输入起按原十项方法轮换计时，同宽随机额外抽取 20 次。沿用 0.02 平衡准确率容差、真删列、端到端耗时更低，以及对各基线逐一比较的一致口径。本批次至少 2/3 个种子通过作为该来源通过，单独报告三种种子与独立测试集数量。[发布方数据与版本勘误](https://spamassassin.apache.org/old/publiccorpus/readme.html)
