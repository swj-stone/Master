# 稀疏文本的逐文档留一投票

两项冻结的研究接口为 `from research.text_peer import log_peer_support, square_peer_support`。传入训练折的规范二值 CSR 矩阵和二分类标签即可得到升序原列号。两者的自动列数由超过 1e−15 的最低票值个数决定，并依各自协议处理空集。排序前分数取 14 位小数，再按零同伴分数和原列号处理并列，数值边界处的列身份以实际排序为准。

在二元词项出现矩阵上，每份训练文档轮流作为见证。对见证类别 c 和出现的词 j，用其余文档估计该词支持正确类别的有符号对数证据。设剩余两类的先验比例为 π 和 1−π，出现该词的两类剩余计数为 a、b，证据为 log(1+a/π)−log(1+b/(1−π))。用见证文档出现的不同词数的平方根归一化，各词贡献相加。单文档对一个组合的收益为其正确类别的对数概率 log σ(组合的有符号证据)。类别贡献等权。候选词分别在零同伴和其余词全部在场时计票，取较低的平均边际增益，按预定规则保留严格正收益列，空集时至少留一列。对数收益的边际在中等同伴数时也可能更低，理论范围限于明确的两个同伴规模。初始原型将缺席词置零。不同见证有自己的留一证据值，训练见证的标签仅用于选取对应留一计数和计算正确类收益。

开发比较使用旧 SMS、Amazon、IMDb、Yelp 第一折训练部分的三个内层划分。比较两种归一化、两种有界/对数收益，以及单位归一化时的两档方差扣分。平方根归一化的对数收益在这些内层划分平均 BA 为 75.90%，相同宽度 F 为 73.69%，单词边际岭收益为 73.83%。单位归一化得分略高，但其“全同伴单层”的均分高于取两层最低值。加方差扣分后在几个小样本上过度删列。最后冻结平方根归一化、对数收益和两层最低分，然后从 Cornell 作者网站获取两份预先指定的新数据。[开发结果](development.csv) · [方差扣分](development-penalties.csv) · [有界收益](development-bounded.csv) · [确认协议](protocol.md)

## 第二轮，加入缺席票并计算全部同伴规模

初版在长影评失效，也在土耳其短信失效。第二轮检验两个原因。仅词项出现时投票，会遗漏“本该出现的词未出现”携带的信息；把大量有相关性的对数证据相加，也可能高估全体同伴的预测把握。为检验这两点，改用所有训练文档的留一表，对出现和缺席两种状态分别估计有符号证据。沿用前述留一计数 a、b、π，对实际观察到的状态，用

`u_j = (a/π − b/(1−π)) / (a/π + b/(1−π) + 2)`

表示词项对正确类别的证据。计算每个见证的全词汇证据和 Z，以类均衡加权期望拟合一个共同的非负尺度 α，使 E[(1−αZ)²] 最小。α 由训练结果估计，之后在各同伴规模和组合中固定。对类别与词项计数预存“缺席时的证据”，稀疏乘法只累加出现带来的差，因此无需把稀疏词袋展开。

若 S 在 j 以外 p−1 列中均匀抽取 k 列，平方收益变化等于

`2α E[u_j] − α² E[u_j²] − (2k/(p−1)) α² E[u_j(Z−u_j)]`。

于是最低规模得分可精确地从两个端点求出。p=1 时仅有空同伴。这个等式约束训练票表上单列在均匀同伴中的平均边际；对最后选中子集的测试 BA，需要重拟合验证。最小端点大于 1e−15 的列全部保留，若空则回退全宽并记失败。一次统计量累积所需 O(nnz+p+n) 工作，确定性全排序另需 O(p log p)。[实现](square.py) · [每个同伴数逐项枚举](test_square.py) · [独立协议](square-protocol.md)

训练内 12 个划分的均衡准确率为 76.93%，关闭缺席票的独立自适应版本为 75.35%，Full 为 74.91%。用同一列数重跑已看过的 Cornell 两源时，完整影评从第一版 72.98% 升到约 80.2%，主客观句子从 75.97% 升到约 82.3%。在这六折固定二版宽度去掉缺席票，BA 平均低 3.23 个百分点，单独使用全同伴层的 BA 平均高 0.16 个百分点。这些数据参与了第二版失败诊断，因此作为复查。土耳其短信的二版均值约 87.0%，全特征约 97.8%。[四训练源开发结果](development-square.csv) · [30 个已开封配置与同宽消融](../../results/minpi-study/text-square-recheck-20261118/cases.csv)
