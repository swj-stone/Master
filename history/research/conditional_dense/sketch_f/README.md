# 相同训练样本、相同列数下的 ANOVA F 对照

在此前表现较好的三个来源，条件投票 minPI 在 **8/8 个配置**都比同一样本上的 ANOVA F 选出分数更高的列，平均平衡准确率优势为 HAR **2.52**、ISOLET **2.03**、Spoken Arabic Digit **0.38** 个百分点。每个方法均在全部外层训练集上重拟合相同的岭分类器。若再要求从抽样到预测的总耗时在两个进程中都低于 F，只有 **2/8** 做到。两个成功配置也都实际删列、对 Full 损失至多 0.02 且两个进程均快于 Full。

本项为看到完整训练集 F 的确认结果后追加的强对照。限定同一随机样本可以检查同伴评分能否从同样多的信息中选出较好的特征组合。HAR 和阿拉伯语数字各有三个种子，共用各自唯一的官方测试集；ISOLET 是两个外层随机划分。三个来源属于前期已出现优点的子集，之前报告的 Gas、Multiple Features 和 Digits 的结果继续有效。样本加宽和重新调参都不属于本项测试。[计时前协议](protocol.md) · [所有来源及原对照](../README.md)

## 方法与验证

每次测量重新从外层训练样本中为每类随机选一行，再从其余样本均匀补齐至 768 行。每种方法取得实际被冻结 minPI 采用的同一批行号。冻结 minPI 仍自行推导宽度，同样本 F 和零同伴对照免费获得该宽度。F 对这些行的原始特征先用双精度中心化，再用 scikit-learn 的 `f_classif` 计算单因素方差分析统计量。通过各类均值和总方差独立分解得到的排名截断，在 8 个配置均给出完全相同的 F 支持，没有边界替换。全部方法共用相同的 StandardScaler 和以 Cholesky 求解的 RidgeClassifier。

两个新进程均限制单线程。每进程先单独预热每种方法，随后做四次定种子轮换，使每个方法在每个顺位恰好出现一次。计入抽取训练行、选择列、切取训练与测试矩阵、拟合 scaler 和分类器、全部测试预测；数据读取、公共的阿拉伯语语音矩阵准备和统计评分在计时区间之外。共计 256 条计时，跨进程逐项核对 115 个保存数组。另核对三个旧方法的支持、类别预测和决策分数与冻结档一致。不同试验轮的毫秒数和本次多个来源共享的种子均不当作独立来源。[验证记录](evidence/verification.json) · [第一轮逐次记录](../../../results/minpi-study/conditional-sketch-f-timing1-20261118a/trials.csv) · [第二轮逐次记录](../../../results/minpi-study/conditional-sketch-f-timing2-20261118a/trials.csv)
