# Free Spoken Digit Dataset 的跨说话人确认

**集中度选宽 minPI 在三个测试折均删列、在两次计时中快于 Full，平衡准确率相对 Full 分别变化 +0.6、−1.2、+3.3 个百分点。** 相对两个同宽 F 方法，三个折均更快，其中两个折同时更准。第三折同样本 F 的分数比 minPI 高 2.4 个百分点。旧版残余尺度宽度在三个折的分数都比 Full 高，但只有第三折在两个进程中均比 Full 快。这个实验增加 **一个独立数据来源、六名测试说话人、三个互不重叠的测试折**。[事前冻结协议](protocol.md) · [全配对分数、列数、时间与交集](evidence/cases.csv)

## 测试设计

使用作者提供的 FSDD v1.0.10，归档 SHA-256 为 `c680098f5d2355ba7cc4bd8b0ca9e0a24c00ebe3b4c552208889a4d28d4fbc2b`。原作者的官方测试用每个说话人各数字序号 0–4 的录音，序号 5–49 训练。本实验的问题是对未见过的说话人能否泛化，因此按说话人字母顺序每次留出相邻两人，四人共 2,000 条录音训练、两人共 1,000 条测试。第一折 george / jackson，第二折 lucas / nicolas，第三折 theo / yweweler，选择器种子分别为 1129、2027、3469。每人每个数字恰好 50 次。所有折训练与测试之间完全相同的 PCM 波形数与完全相同的 208 维特征向量数都为零。三折训练集相互重叠。[作者的冻结版本与官方划分](https://github.com/Jakobovski/free-spoken-digit-dataset/tree/v1.0.10) · [逐折完整性核查](evidence/split-audit.csv) · [说话人与数字频数](evidence/speaker-digit-counts.csv)

对每条录音单独按 25 ms 窗和 10 ms 步长提取 13 个 MFCC（26 个三角 Mel 滤波器、对数能量、正交 DCT-II），在 16 个相对时间点插值，得 208 列。提取过程只依赖这一条录音。两个 minPI 版本使用此前冻结的代码，各自推导列数。对每个版本分别比较相同宽度的全训练行 ANOVA F、相同 768 行 ANOVA F 和均匀随机支持；独立半宽 F 固定保留 104 列。所有最终模型都在全部训练行上重拟合 StandardScaler 及单位岭罚的 Cholesky RidgeClassifier。[特征提取细节及程序](features.py) · [完整测量程序](study.py)

## 从选列到预测的总耗时

两个实际独立的单线程进程各做十次顺位平衡的重复，每个表格单元给出第一 / 第二个进程的中位数或比值。比值小于 1 表示该进程中 minPI 更快。选列、抽样、自定宽度、切取训练及测试矩阵、最终拟合与预测均计时。

| 折 | minPI 选宽 | minPI 总毫秒 | 总时间 / Full | 总时间 / 同宽全行 F | 总时间 / 同宽同样本 F |
|---|---|---:|---:|---:|---:|
| 1 | 残余尺度 | 9.39 / 9.53 | 1.048 / 1.030 | 0.806 / 0.822 | 0.980 / 0.980 |
| 1 | 集中度 | 7.30 / 6.83 | 0.814 / 0.738 | 0.739 / 0.685 | 0.920 / 0.889 |
| 2 | 残余尺度 | 8.98 / 8.73 | 0.998 / 1.060 | 0.780 / 0.813 | 0.999 / 0.957 |
| 2 | 集中度 | 8.05 / 6.72 | 0.895 / 0.816 | 0.792 / 0.649 | 0.907 / 0.838 |
| 3 | 残余尺度 | 8.88 / 8.66 | 0.980 / 0.916 | 0.769 / 0.770 | 0.981 / 0.972 |
| 3 | 集中度 | 7.89 / 7.23 | 0.871 / 0.765 | 0.743 / 0.694 | 0.947 / 0.977 |

在同一折要求删列、对 Full 损失至多 0.02、两个进程都比 Full 快、还要同时比两个同宽 F 更准且更快，集中度版通过 2/3（第一、二折），残余尺度版通过 0/3。若只要求更准且更快于同宽全行 F，集中度版 2/3，残余尺度版 3/3。两种规则均未在任何折的两个进程中都快于其同宽随机对照。与独立半宽 F 相比，新规则多用 13–23 列，3/3 更快、2/3 更准。这些结果分别来自两条事先冻结的规则。[各条件的逐折交集与汇总](evidence/summary.csv) · [各方法的分阶段毫秒数](evidence/process-medians.csv)

**从原始录音开始时，时间优势较小。** 两次从压缩包读取全部 3,000 条音频到构建共同特征矩阵耗时约 681、683 ms。特征矩阵已就绪时，新方法选列到预测耗时 6.72–8.05 ms，Full 为 8.24–9.46 ms；将本进程各自的公共特征提取开销一次等额加回，新方法相对 Full 的总节约约为 0.14%–0.35%。绝对数值适用于本机、本批量和固定学习器。[第一进程公共提取时间](../../../results/minpi-study/fsdd-confirm-timing1-20261118b/preparation.json) · [第二进程公共提取时间](../../../results/minpi-study/fsdd-confirm-timing2-20261118b/preparation.json)

## 复现与核验

在 `history` 目录使用作者的同一版本归档，两个计时进程依次独占资源，输出使用新目录。两个特征测试以静音信号和独立构造的三角权重、余弦变换验证 MFCC 的数值和布局。审核重新提取训练矩阵、逐个核对输入文件与重复、从保存的预测复算所有折和 120 个随机支持的分数，600 条计时的数据与 345 个跨进程数组均已核对，15/15 个官方 F 支持与独立方差分解完全相同。正式测量使用后缀 `b`；初次准备在训练前因索引归档字段名与库参数冲突停止，修正该字段后按同一冻结协议重新启动。[审核程序](audit.py) · [审核结果](evidence/verification.json) · [MFCC 数值检验](test_features.py)
