# Original survey, advertisement and simulation comparisons

Each run covers 33 archived configurations. The sparse-signal, XOR and random-label simulations are the three original formal simulated matrices. Each has five 75/25 row splits using the manuscript’s held-out seeds and ROC AUC. The two surveys, ANES96 and Fair, each use three outer folds. The original and expanded (192-column) versions within a survey fold share outcomes and held-out records. The expanded versions add independently simulated covariates. ANES96 uses balanced accuracy and Fair uses R². UCI Internet Advertisements uses three outer test pools. Within each pool the 256 and 768 training sizes are nested and the test set is identical. Its metric is balanced accuracy. The source archive and frozen held-out rows or matrices are checked against archived results. For every case the full-feature predictions must reproduce the original predictions.

All arms receive matched outer training and test matrices. The downstream learner is the original standardized LSQR ridge classifier or regressor. The new and previous selectors each choose their own width. Single-feature F uses the official full-training ANOVA or regression statistic at the new width, with float64 centering and an independently validated score boundary. Uniform random selection takes the same number of columns without replacement. For advertisements, the three data-dependent selectors first fit per-column means on the training inputs and fill missing training entries. The estimator independently fits training means on each deployed subset before filling model inputs. The timer includes each deployed imputation. No held-out data are used by the selectors.

The five arms receive one warm-up and then five timed repetitions each per configuration in each of two separate single-threaded processes. Arm order rotates through all five positions within each process. Measured calls repeat selection, slicing, model preparation, fitting, and prediction from scratch. Replicate supports, predictions and decision values must match. A speed win requires both within-process median total times to beat the specified baseline. Removing zero columns counts as a compression failure. Source, family, fold, seed and the individual metric appear in the cases table. Repeated splits, synthetic variants and nested training sizes are dependent configurations.
