# 低维空集与单同伴投票

在不超过 32 列的数值矩阵上，以一次充分统计量计算代替随机同伴前缀的 Cholesky 分解。较宽的分类及回归矩阵复用各自已有的集中度选宽。32 列是本实验开始前选定的运算分界，每列最多枚举 31 个同伴。规则只使用任务类型和输入宽度。[公开入口](method.py) · [计算内核](native_votes.c)

所有得票在一个训练样本上计算。训练行不超过 768 时用全体；更多时按原训练行顺序等分成 768 个连续区间，每区间按种子均匀取一行。区间端点为向下取整的行数分位位置，不使用标签或测试行。分类标签编码检查整个训练标签向量，投票统计只使用抽中的行。每个特征在该样本中减均值、除以总体标准差，常数列的标准化值为零。回归目标也如此缩放，分类使用中心化的独热向量。最小化的目标为岭平方损失加系数平方惩罚，惩罚系数取样本行数的平方根。

设标准化特征为 Z，响应为 Y，A = ZᵀZ + λI，B = ZᵀY。得票由在给定同伴下允许全部参与列重新拟合产生的最优目标下降计算。按列 j 分别求空同伴的下降值与所有单同伴下降值的算术均值。

```
gain(j | ∅) = ||B[j]||² / A[j,j]
gain(j | k) = ||B[j] − A[j,k] B[k] / A[k,k]||²
              / (A[j,j] − A[j,k]² / A[k,k])
score(j) = min(gain(j | ∅), mean_{k≠j} gain(j | k))
```

单同伴等式由二元正定岭系统消去同伴 k 得到。两层贡献取最低值后按降序选择，平局优先原始较小列号。将非负票归一化为总和一的权重 w，列数取 1/Σw² 的向上取整。全部零票时回退全宽；单列输入只用空集。宽度与组合均只依赖训练数据。该公式描述得票集中度，测试误差由外层划分给出。

实现只遍历一次抽中的特征行，同时累加各列相对首个样本的偏移、交叉乘积及与响应的乘积，在双精度下直接消去均值，再计算两层收益。样本量为 m、特征数为 p、响应维数为 c 时，主要计算量为 O(mp² + cp²)，仅保存低阶矩、最多 768 行的位置、响应及每类统计量。分类用 C 实现按首次出现匹配抽到的类，额外成本最坏为 O(mc)。小矩阵专用内核与样本重复抽取的开销都计入选列。宽矩阵的旧版规则、同宽 F、同宽随机及 Full 的具体定义见各实验协议。[独立逐列重拟合检验](test_fast_support.py)
