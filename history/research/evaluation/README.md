# 配对实验与验收标准

这项研究测两个量。相同列数下的测试分数用于判断 minPI 能否选到更好的组合。实际使用时，还要用完整流程的时间和列数判断这种选择是否划算。

| 对照 | 共享条件 | 记录什么 |
| --- | --- | --- |
| 同宽筛选 | 给各方法相同 k、训练样本、测试样本和下游模型。自动选宽的 minPI 承担确定 k 的耗时。 | 与旧 minPI、ANOVA F、均匀无放回随机支持及适用的论文基线逐一比较分数，另记每个方法的选列与总耗时。 |
| 各自选宽 | 同一外层划分、同一评估量，各自只用训练数据确定宽度。 | 每个完整方法的 (特征数、分数、总耗时)。分数、时间、列数的差均相对于同一个明确点名的对照。 |
| 全特征 | 保持相同预处理、训练行和下游学习器。逐个数据类型检查求解器。 | 当前统计真删列且完整时间更短的配置，逐项报告其分数差。另算同时符合旧分数容差的子集。全留计零。 |

总耗时从收到相同训练和测试特征矩阵开始，包含选列、内部验收或校准、训练和测试矩阵切列、必要预处理、重新拟合及预测。共同数据加载另列，文本分词或建表如置于计时区间外需明示。固定线程，轮换方法执行次序，每次重做选列与拟合。报告重复次数、两进程的结果及实际时间，保存支持与预测。单次预选的随机支持用于配对计时，额外独立随机子集的分数分布用于检验选择质量。

当前主读数为实际删列并加速的数量及其原始得分变化，不设硬性得分损失上限。与同宽筛选器比较时单列同时更准、更快的严格优势。已有损失上限 0、0.005、0.01、0.02 的结果可用于灵敏度分析。分类使用原协议指定的平衡准确率或部署单位聚合，回归采用测试集 R²。0.02 对平衡准确率表示两个百分点，对 R² 表示 0.02 个绝对分值。比较有得有失时，同时报告损失与节省。保证某一冻结票表的多数收益严格提高，仅能解释训练中的机制，预测结论要用外层重拟合的结果支持。[最新实验与实际取舍](../four_stage/README.md)
