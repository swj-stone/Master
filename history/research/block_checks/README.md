# 第三列之后的成对决策与停止核对

## 训练目标的独立求解

每个候选集合均在中心化的同一批训练行上重新拟合岭回归。独立实现直接在设计矩阵下拼接 $m^{1/4}I$，对扩充后的目标做最小二乘，计算含惩罚的完整残差平方和 $R(S)$。候选评分采用 $m\log [R(S)/R(S\cup B)]-|B|\log m$。这条路径只共享采样、标准化约定和投票宽度上限。核对包括种子列对、每一轮所有可行的一列或两列、拒绝剩余候选的步骤和同分顺序。

28 个低维输入涵盖分类和回归、三类独热响应、单列、无信号、正信号且上限等于全宽、奇数上限、重复列、近共线、float32 负步幅以及超过 768 行的采样。4,054 个完整候选重拟合给出的选择与原生程序一致，其中 44 次为种子之后的决策，有 12 次提前停止。另有两组 33 列输入核对了高维回退。单列与两列的得分边界另用三组可解输入核对：令第 4 个系数恰好使最佳单列与最佳对同分时，程序取单列；将该系数分别乘以 $1-10^{-10}$ 与 $1+10^{-10}$，程序分别取单列和列对。[验证源码](verify.py) · [独立求解](reference.py) · [逐项记录](verification.json)

构造数据用八个取值为 $\pm1$ 的独立因子的全部 256 种组合。令列 0 和 1 为 $U_0,U_1$，列 2 和 3 为 $U_2,0.96U_2+0.28U_3$，其余四列重复 $U_0,U_1$。响应取 $U_0+0.9U_1+0.7U_3$ 时，前两列为 0、1。随后选择 2、3 的联合评分为 91.47，最佳单列评分为 10.46。响应改取 $U_0+0.9U_1+1.4U_7$，其中 $U_7$ 不在候选列中，投票上限为 6，种子后的最佳候选得分为 −1.99，实际保留 2 列。这两个例子用于展示决策机制，未计入真实数据结果。

## 真实数据的消融协议

沿用 56 个历史低维配置、上一轮的 12 个外部折以及本轮新增的 6 个折。对每个配置先在训练数据上固定全部方法的列集。保持原划分、模型和测试指标一致，仅将列集替换为各臂的选择。每个配置的原规则、上一版和本轮规则还分别与正式计时运行记录的列集、宽度和预测分数核对。

| 表内名称 | 训练规则 |
|---|---|
| `vote_cap` | 原投票排名保留到原宽度上限 |
| `pair_cap` | 最佳对起步，此后逐列条件前向直到原宽度上限 |
| `block` | 最佳对起步，此后比较条件单列和列对，惩罚得分不再为正时停止 |
| `vote_matched` | 原投票排名截取到本轮实际宽度 |
| `pair_matched` | 上一版逐列前向路径截取到本轮实际宽度 |
| `anchor_matched` | 边际贡献最高的单列起步，此后逐列条件前向到本轮实际宽度 |
| `singleton_stop` | 同样以最佳对起步、同样按惩罚得分停止，此后只考察单列 |

同宽参照使用训练阶段已经确定的列数。核对每个残余列对是否等于从同一前缀顺序选择两次最佳单列所得的集合，还记录该轮最佳单列能否单独达到接受阈值。另行穷举全部 18 个外部折各自实际宽度下的列集，以精确给出测试得分在同宽均匀随机分布中的位置。测试分数仅用于事后比较。

## 宽度与列组合各自的影响

下表为本轮方法相对各参照的测试分数升、平、降，绝对差至多 $10^{-12}$ 记为平分。不同数据保持原指标，计数单位为配置；同一数据上的折或选列种子存在相关性。

| 参照 | 原有 68 组，升 / 平 / 降 | 新增 6 折，升 / 平 / 降 | 74 组最终列集相同 |

| 同宽、原投票排名 | 48 / 12 / 8 | 1 / 3 / 2 | 12 |

74 组中有 51 组提前停止。将上一版路径直接截到本轮宽度，同宽下只有 5 组最终列集还不相同。这 5 组的训练岭收益均提高。Concrete 第 3 折从 8 列选 5 列，成对搜索的 $R^2$ 提高 0.01984，所选组合在全部 56 个同宽测试组合中排名第 1。Wisconsin Breast Cancer 的 4 个配置中，3 个平衡准确率分别下降 0.00704、0.01124、0.00704，另一个 AUC 持平。新增的 6 折在给定宽度和同一种子对时，逐列与成对搜索全部选中了相同集合。由此观察到的实际改动主要来自提前停止，相同宽度下后续成对决策的独立预测收益仅出现在一个测试折。[74 组七臂逐例结果](cases.csv) · [按来源的比较计数](comparison.csv)

52 个配置出现了种子后的两列加入，共 69 次。63 次与从同一前缀贪心选两次单列得到相同的两列。仅有两次是在最佳单列无法过阈值时接受一对：Wine 的额外配置第 3 折（最佳单列 −0.978，列对 +4.060），以及 Wisconsin Breast Cancer 的正式第 5 折（−1.816，+0.073）。在这两次中，若忽略停止条件且继续逐列走两步，仍会得到同一列对。[每次残余列对及贪心反事实](residual-pairs.csv)
