# 条件列对与提前停止的复验

本轮改变了 74 个低维配置的选列规则。相对全特征模型，74 组均删列，两次独立计时均提速的有 36 组，其中 33 组得分损失不超过 0.02，8 组无损失。上一轮先选一对、然后逐列加至宽度上限的版本对应为 33、32、13 组。本轮最明确的优势出现在同宽 F 对照，47 组预测得分严格更高且总时间更短。两个首次使用的数据来源均大幅删列，六折都未缩短总时间。

|---|---:|---:|---:|---:|---:|
| pair，上一轮先选一对再逐列增长 | 12/29/33 | 37 | 7 | 13 | 1.000 |

## 得分与耗时的交换

| 来源及协议 | 次数 | 保留列 | 相对全特征的平均得分差 | 保守时间比中位数 | 删列且提速 |
|---|---:|---:|---:|---:|---:|
| 原始 Abalone | 9 | 4–5/10 | −0.02021 R² | 0.935 | 7/9 |
| 原始 Diabetes | 3 | 5/10 | −0.00048 R² | 1.064 | 1/3 |
| 原稿 Diabetes | 5 | 4–6/10 | −0.00367 R² | 0.961 | 4/5 |
| HTRU2 | 3 | 2–3/8 | −0.00012 AUC | 0.776 | 3/3 |
| MAGIC Gamma，模拟事件 | 3 | 4/10 | −0.00239 AUC | 0.595 | 3/3 |
| Raisin，新增 | 3 | 2–3/7 | −0.00024 AUC | 1.179 | 0/3 |
| Yacht，新增 | 3 | 2/6 | −0.00116 R² | 1.064 | 0/3 |
| 美国宏观 GDP | 3 | 2/24 | −0.74033 R² | 1.077 | 0/3 |

原始 Abalone 的九次包含三个划分与重复种子。每折有约 2,785 行训练样本。提前停止把列数从 8 降为 4–5，相较上一轮平均再损失约 0.0202 R²。相比之下，HTRU2 每折训练 11,932 行，平均 AUC 从 0.97466 变为 0.97454，两个流程的典型总时间分别为全特征 3.10 ms 与新方法 2.33 ms。MAGIC 每折训练 12,680 行，典型总时间从 4.07 ms 降为 2.34 ms。新增 Raisin 训练 600 行，Yacht 训练 196–210 行；两者均有 3/3 折的得分损失低于 0.02，六折都未同时在两个进程中加速。美国宏观 GDP 三折从投票允许的 6–8 列提早停在 2 列，单折最大 R² 损失为 1.5500。[所有来源明细](evidence/by-source.csv)

在 74 个低维配置中，51 个提前停止，23 个用尽旧宽度上限。相对 pair，提前停止的 51 组得分 11 胜、7 平、33 负。23 个宽度相同的配置有 22 个列集逐项一致，另外一个 Concrete 配置提高 0.01984 R²。低维配置保留列比例的中位数从 62.9% 降至 41.4%。训练惩罚确实能压缩列数，付出的预测代价主要出现在提前停止的配置。固定 K 的逐步消融由独立核验给出。

逐配置先平均两个进程的选列时间中位数，再跨 74 个配置取中位数，block 为 0.0547 ms，pair 为 0.0526 ms，current 为 0.0516 ms，F 为 0.3322 ms，随机为 0.0463 ms。相对 F 的优势同时来自这套 F 实现的开销和所选列的预测效果。随机选列本身极便宜，block 在多数配置获得更好预测，但端到端用时胜出的仅 16 组。相同机器上的两个进程能够检验运行顺序和短期计时波动，跨机器性能、其它下游模型与随机子集分布仍需独立实验。

## 样本与计时

复验覆盖 179 个“数据来源、划分、种子、实验流程”配置。由原始 69 组、原额外 57 组、其余历史低维实验的 35 组、上一轮四个 UCI 来源的 12 折和本轮两个新 UCI 来源的 6 折构成。不同流程可能使用相同数据。三折、五个划分或同一划分的多个种子也会重复同一来源，配置数不能当作独立数据集数。

六条流水线共享每一配置的训练、测试、预处理、下游预测器和指标。block 为本轮规则，pair 为固定宽度、先选一对再逐列增长的上一轮规则，current 为改动前按空同伴与单同伴投票排序的规则。F 使用分类的单因素方差检验或回归的单变量 F 检验。random 按当前配置种子生成原列号的均匀随机排列，取前 K 个。F 和 random 均领取 block 实际选出的 K 并重新选列。full 使用全部原始特征。抽取一份随机子集只能支撑对这个已登记种子的比较。

端到端时间从内存中的矩阵开始，含实际选列、切取训练和测试列、该流程规定的缺失值处理及特征变换、重新拟合和预测。数据读取、软件导入、编译、动态库首次加载和测试集评分在计时外。每套数据运行两个独立的单线程 Python 进程。每个进程对每种方法预热一次，再按种子随机安排循环顺序，轮换 6 次，使每种方法在 6 个位置各执行一次。每次从输入重新选列和拟合，记录操作耗时。仅当方法在两个进程各自的 6 次中位数都小于对照才记提速。表中时间比取每配置两个进程中较大的方法/对照中位数比，再对配置取中位数。完全保分的浮点容差为 1e-12。全留不计删列成功。

## 复现

在 history 目录执行下列 PowerShell 命令。新的计时输出目录必须尚未存在。

```powershell
$runPath = 'results/minpi-study/block-completion-replication'
foreach ($suite in 'archive','external','fresh') {
    $flags = @()
    if ($suite -ne 'archive') { $flags = @("--$suite") }
    $first = Join-Path $runPath "$suite-pass1"
    $second = Join-Path $runPath "$suite-pass2"
    .\thesis-python.ps1 -m research.block_selection.benchmark $first @flags
    if ($LASTEXITCODE -ne 0) { throw "First pass failed for $suite" }
    .\thesis-python.ps1 -m research.block_selection.benchmark $second --previous $first @flags
    if ($LASTEXITCODE -ne 0) { throw "Second pass failed for $suite" }
}
.\thesis-python.ps1 -m research.block_selection.aggregate $runPath --out "$runPath/summary"
```
