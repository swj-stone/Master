# 互补列对与后续选列的独立核对

## 第三列及以后在开发数据上起了什么作用

沿用[单同伴消融清单](../lowdim/peer_evidence/cases.csv)的全部 31 个低维配置，包含 Abalone、Diabetes、Wisconsin Breast Cancer、美国宏观 GDP 和 Wine。每个配置采用原训练子样本与自适应列数。此清单的 $K$ 均大于 2。对同一训练输入，先冻结以下四个选择，再按原协议重新拟合和测试。

| 方法 | 初始化与后续步骤 | 相对原规则改变列集 | 测试得分升 / 平 / 降 |
|---|---|---:|---:|
| 原规则 | 按单同伴投票排序取前 $K$ 列 | 0 | 0 / 31 / 0 |
| 最佳对 + 原排序 | 选择最大联合训练岭收益的一对，再依原投票排名补足 | 0 | 0 / 31 / 0 |
| 单列起步 + 条件前向 | 先取边际岭收益最高的一列；每次加入对当前整个集合贡献最大的列 | 26 | 15 / 8 / 8 |
| 最佳对 + 条件前向 | 先取最佳对，后续每步都对当前整个集合评分 | 26 | 15 / 8 / 8 |

给定最佳列对后，如果仍按原排名补列，在这 31 个配置中全部返回原列集。改为条件前向后，26 个列集发生变化，这 26 个配置的训练收益均增加。以最高分单列起步做条件前向，也在全部 31 组得到与最佳对起步相同的最终列集。因此这批数据证实后续步骤可以改变列集，还不足以区分两种起点的预测效果。

| 来源和协议 | 测试组数 | 新规则相对原规则升 / 平 / 降 | 配对得分变化范围 |
|---|---:|---:|---:|
| Abalone，原始，$R^2$ | 9 | 1 / 5 / 3 | −0.000118 至 +0.000323 |
| Diabetes，原始，$R^2$ | 3 | 3 / 0 / 0 | +0.013534 至 +0.024424 |
| Diabetes，重复留出，$R^2$ | 5 | 5 / 0 / 0 | +0.001472 至 +0.038272 |
| Wisconsin Breast Cancer，平衡准确率 | 3 | 2 / 0 / 1 | −0.007042 至 +0.011244 |
| Wisconsin Breast Cancer，重复留出，AUC | 5 | 2 / 0 / 3 | −0.001258 至 +0.002516 |
| 美国宏观 GDP，$R^2$ | 3 | 2 / 0 / 1 | −0.860122 至 +1.131659 |
| Wine，平衡准确率 | 3 | 0 / 3 / 0 | 0 |

原始 Abalone 的 9 个配置由 3 个不同测试划分和 3 个选列种子组成。升降按绝对差超过 $10^{-12}$ 判断。各组的任务、指标、列数、选择顺序、训练收益及留出得分见[逐组数据](cases.csv)。此处只检验算法机制，耗时由[主实验](../pair_selection/benchmark.py)独立测量。

## 全部 56 个低维归档配置与 12 个新折

将同样的四臂消融扩展至其余 25 个低维归档配置和 4 个新来源的 12 个互斥测试折。在 68 组中，最佳对加条件前向相对原规则改变了 53 个集合，留出得分 32 升、20 平、16 降。仅用最佳对起步、后续照旧按原分数补齐，67 组返回原集合，1 组改变且得分上升。在完全相同的条件前向步骤下，最佳对起步与普通最高边际收益单列起步有 **67/68 个集合一致**。唯一不同的是 Wisconsin Breast Cancer 四阶段岭协议的第 2 折，两者取 19 列，最佳对起步的平衡准确率为 0.94650，单列起步为 0.95070。在这些真实配置上，观察到的主要改变来自给定当前集合后的后续选列，最佳对起步没有取得独立的测试分数优势。这批消融没有对两种起点单独计时。[56 个归档配置四臂明细](archive-all.csv) · [外部划分与输入验证](../pair_selection/external.py)

外部折可穷举评价同宽随机。每折先按训练集固定全部算法选出的列与宽度，再对 $\binom pK$ 个集合分别训练相同的岭预测器并在该折测试集评分。12 折均删列，合计 **2,366 个集合评分**。下表按折给出最佳对加条件前向的测试分数排名，第 1 表示在指定宽度下留出得分最高。所有排名只用于事后审计。

| 新来源 | 主要指标 | 折 1，排名 / 组合总数 | 折 2 | 折 3 |
|---|---|---:|---:|---:|
| MAGIC Gamma Telescope | AUC | 3 / 210 | 16 / 252 | 4 / 210 |
| HTRU2 | AUC | 7 / 28 | 19 / 56 | 1 / 56 |
| Concrete Compressive Strength | $R^2$ | 4 / 56 | 4 / 56 | 2 / 56 |
| Red Wine Quality | $R^2$ | 13 / 462 | 3 / 462 | 5 / 462 |

最佳对加条件前向与原规则均在 12/12 折超过真正均匀随机子集的得分中位数。两者直接比较，新规则 9 升、1 平、2 降。选中列的得分、同宽得分分布、并列排名区间以及每一个集合的分数均可复查。[逐折精确排名](external-ranks.csv) · [全部候选集合的测试分数](external-all-subsets.csv)

## 独立数值检查

供查验的参考实现在每一个候选集合上从头求解岭问题。小矩阵的独立测试还将 $m^{1/4}I$ 作为额外设计行，以最小二乘直接计算完整惩罚目标。这条验证路径不使用原生内核的二元闭式解或递推式。分类响应为中心化的独热矩阵，回归响应在训练子样本上标准化。核对覆盖负步幅、32/64 位浮点特征、近共线、完全重复的列、常数列、常数响应、跨越 768 行的子样本、$K=1$、全宽短路，以及跨过 32 列的两种任务回退。[逐项核对记录](verification.json)

对 $K=3$ 的构造，将八个独立二值因子的完整析因组合用作 256 行训练设计。第 0、1 列重复同一个强信号；第 2、3 列分别携带系数为 0.60 和 0.32 的独立信号。先取最佳对选中第 0、2 列，再按原排序补列会选重复列 1；按已选集合计算新增收益则改选独立列 3。惩罚训练收益从 229.063 增至 240.941。该例用于核对第三步具体选择，属于可解的训练目标示例。

在得到 31 组开发消融结果后，另构造了一个区分初始化的 $K=4$ 例子。相同的完全析因设计中，令 $X_0=U_0$、$X_1=0.96U_0+0.28U_1$，其余 $X_j=U_j$；响应为 $U_1+0.34U_2+0.32U_3+0.30U_4$。$X_0$ 本身与响应正交，但 $X_1-0.96X_0$ 恰好提取强信号。单列起点最终选 $[2,3,4,1]$，最佳对起点选 $[0,1,2,3]$，惩罚训练收益分别为 71.177 和 118.801。该构造说明两种起步规则在数学上存在差别。其余 68 个分组的留出结果更适合判断这种差别在现有数据中的实际价值。
