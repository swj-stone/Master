\section{What the observed votes imply}
Let $\mathcal O$ store the votes already measured, including those obtained while
scoring other features. For a fixed $i$, the Boolean cube is a disjoint union
of edges $(S,S+i)$, $i\notin S$, where $S+i=S\cup\{i\}$. Write $\bar m_i$
for the largest exact $m_i$ attainable by a binary game agreeing with $\mathcal O$.

\begin{proposition}
If an observed edge in direction $i$ descends from one to zero, $\bar m_i=-1$.
Otherwise $\bar m_i=1$ if every observed vote agrees with membership of $i$,
and $\bar m_i=0$ in all other cases.
\end{proposition}
\begin{proof}
Fill each missing lower endpoint with zero and each missing upper endpoint with
one. Every coalition has exactly one role for this $i$, so this completion
simultaneously maximizes all its edge differences. The smallest completed
difference is $-1$ exactly on a fully observed descent. All differences are
one exactly when every observed lower endpoint loses and every observed upper
endpoint wins. The remaining minimum is zero.
\end{proof}
The bound is sharp separately for each feature over Boolean completions.
In a fully observed game, $m_i=1$ therefore means $v(S)=\mathbf1\{i\in S\}$
for every $S$, the usual dictator rule. Every other index must then be zero.
Finding all three groups in the same exact game is impossible. Storing observed
coalitions as bit sets lets us check whether the predecessor of each observed
losing coalition has already won, even when the votes were queried for different
features. These extra witnesses require no further fits.

\paragraph{Locating a witness.}
Suppose $A\subset B$, $v(A)=1$ and $v(B)=0$. Order the $d=|B\setminus A|$
new features and add them successively. Apply the binary path search used
for Boolean-hypercube edge testing~\cite{chen2019unateness}. Query the middle support.
A win keeps the right half of the path; a loss keeps the left half.
The retained endpoints still have votes one and zero. Within
$\lceil\log_2 d\rceil$ queries a single edge remains. This proof permits
any number of reversals along the path. The binary-search bound is optimal
for a known bracket when queries are restricted to that path: a path with one
unknown drop has $d$ possible locations and each answer gives one bit.

For comparison, suppose that the path has one drop whose position is
uniform among its $d\ge3$ edges. Query $q$ distinct interior vertices
uniformly with both endpoints already known. The probability of observing
the descending edge is $q(q+1)/[d(d-1)]$. The two boundary edges each
need one particular interior query and the other $d-2$ need two. Averaging
their inclusion probabilities gives the formula. Section~\ref{sec:chain-evidence}
uses the observed brackets and their actual votes for the matched comparison.

Our chain sampler first queries the block endpoints along all four cyclic paths
in each of the same random partitions. It bisects each descending block in
permutation order and ranks by the resulting $\bar m_i$ with the same coefficient
tie order. When both endpoints of a block agree, an internal descent can go
undetected. The original sampler can find such a descent by testing individual
additions. The two schedules therefore trade the number of votes against the
chance of finding a witness.
