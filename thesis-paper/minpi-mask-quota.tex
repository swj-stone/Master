\paragraph{Fidelity under unknown levels of availability.}
Let $T$ be the set of available inputs. The full model can then use $T$ and
a model deployed with inputs $S$ can use $S\cap T$. Write
$\mathcal D(S)=\{H:H\not\subseteq S\}$ for the path groups lost from the
deployment. For $T$ uniform among all $s$-subsets of $N$, put
$L_s(S)=\mathbb E[\|f_T-f_{S\cap T}\|^2\mid |T|=s]$.

\begin{proposition}
Let $D$ be the largest number of distinct required inputs in a path group.
At every size, the squared fidelity loss is
\[
 L_s(S)=\sum_{G,H\in\mathcal D(S)}
  \langle a_G,a_H\rangle
  \frac{\binom{s}{|G\cup H|}}{\binom{p}{|G\cup H|}} .
\]
The minimum of the slacks $\rho^2 L_s(\varnothing)-L_s(S)$ over integer
$0\le s\le p$ is their least expectation over exchangeable laws for $T$.
\end{proposition}
\begin{proof}
The margin difference is
$\sum_{H\in\mathcal D(S)} a_H\,\mathbf 1\{H\subseteq T\}$.
On squaring, each ordered pair contributes exactly when $G\cup H\subseteq T$.
Counting the $s$-subsets containing that union gives the displayed fraction,
including zero when $|G\cup H|>s$. Under an exchangeable law, all masks of
the same size have equal probability. The expected slack is a weighted
average over sizes, and a law concentrated at a minimizing size attains the minimum.
\end{proof}

Thus every exchangeable availability law satisfies the mean-square budget if
and only if every size passes. The check uses differences and still applies
when $L_s(\varnothing)=0$. The empty mask always contributes zero slack, so
the minimum tests feasibility and ties all feasible supports. Grouping the Gram terms by union size leaves a
polynomial in $s$ of degree at most $\min(p,2D)$. The guarantee concerns
the average within a size and the fixed calibration rows. For instance, with
singleton increments $1$ and $0.1$, retaining only the first feature meets
the size budgets at $\rho=0.2$, although the mask containing only the second
feature loses its entire signal.
