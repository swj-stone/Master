## Replay archived outcomes

From the thesis checkout, the command below extracts the ZIP to a temporary directory and uses its own code and records. It independently recalculates guard scores from the probabilities, scores the wide-panel outer predictions, and reproduces 58 numerical tables covering historical collisions and risk, prospective nominations, lottery comparisons, both receiving learners, tied candidates, the two donor backgrounds and all within-fold candidate rankings. Replay requires the numerical Python environment recorded in [pyproject.toml](../../pyproject.toml). The original runtime used Python 3.13.9. In a separately configured environment, the same script accepts the ZIP path through `python` directly.

```powershell
.\thesis-python.ps1 thesis-paper/package_revision.py --verify-transport packages/thesis-transport-evidence.zip
```

The two external panels include derived `guard-targets.npz` members. Each stores the original guard row IDs and encoded labels, extracted from the fitting input whose bytes match the original layout hash. The per-fold `targets.npz` files are the original separately stored outer target arrays. Raw predictor matrices and upstream dataset archives must be recovered from the cited sources for training, candidate-score reconstruction or a new exact-feature-duplicate audit. Source manifests identify each release and the expected digest. [Ten-task sources](transport/sources.json) · [Wide-panel sources](wide/sources.json)

The earliest source receipts hash literal Windows working files, including mixed line endings in two Python modules. The ZIP preserves those exact bytes. A Git checkout may normalize text while preserving the algorithm. For the wide panel, the pre-outcome package is also in commit `9c762f7`. The regular wide scorer checks the committed lock and probability package before loading outcomes. The standalone ZIP replay checks internal digests and recomputes the recorded scores. The historical timing columns record elapsed time on the original machine. [Ten-task seal](transport/prediction-lock.json) · [Wide-panel seal](wide/prediction-lock.json)
