# Independent review of the frozen-tree experiment

This review used the selection code, the registration, the draft method and a synthetic stump. It was written without opening the thirteen-source outcomes. The forecast lock is commit `c54b096`. The numerical manuscript still needs a separate review.

## Scientific contribution

For an available split, the deployed rule follows the input value, including the learned default branch for a missing value. At the first unavailable split it returns the precomputed cover-weighted margin at that node. Each reached edge therefore contributes exactly when every distinct feature tested through that edge is retained. This proves the subset identity for this routing policy. Hessian cover need not equal a count of records. It does not give the conditional distribution of the remaining split variables given all the available features.

The grouped path increments have direct prior art. Saabas accumulated child-minus-parent increments by exactly the set of distinct split features encountered so far. His application was a decomposition of a prediction. For this paper, the use of those groups as sufficient statistics for all truncated supports, followed by incremental exact-greedy screening, is the part to evaluate. The publication should explicitly credit the earlier decomposition. Nan, Wang and Saligrama already studied pruning an existing forest to trade accuracy against feature acquisition cost. Their optimization addresses expected acquisition cost and permits different evaluated variables on different paths. The present target is one global input schema selected against a fitted teacher. [Saabas's 2016 description](https://blog.datadive.net/random-forest-interpretation-conditional-feature-contributions/) · [implementation, lines 74–88](https://github.com/andosa/treeinterpreter/blob/master/treeinterpreter/treeinterpreter.py#L74-L88) · [Nan et al., NeurIPS 2016](https://proceedings.neurips.cc/paper/2016/hash/3948ead63a9f2944218de038d8934305-Abstract.html)

The four sign/magnitude cells give orthogonal vectors. The sum of their squared, normalized inner products equals the squared norm of the projection onto their span. Equivalently it is the maximum squared projection along any unit direction in that span. Subtracting this maximum from a cutoff gives a literal minimum slack. Taking the worst of four individual cell votes would give a different bound. The implemented bound follows from standard projection geometry. Calling it MinPI requires disclosing that its voter and index differ from the original coalition power index and from a minimum over coalition-size strata.

Exact arithmetic gives the dense greedy deletion and tie when candidates with a lower bound equal to the incumbent remain eligible. Termination proves only that every remaining individual deletion fails the empirical budget. Two columns with opposite effects can be removable together. The guarantee concerns the calibration raw-margin norm around the teacher, with normalization by the full-minus-root margin. It gives no direct guarantee for held-out ranking, accuracy or MAE. Multiclass margins also retain per-row common offsets that leave probabilities unchanged.

## Empirical comparisons

| Contrast | Question answered | Main limitation |
|---|---|---|
| Exact greedy vs frozen Gain sweep or prefix | Does evaluating marginal distortion lead to a smaller input schema at the same fidelity budget? | Gain is a ranking from the same fitted teacher. A new model trained on each support solves a different problem. |
| Four directions vs zero directions with identical caching | Does the projection reduce fresh norm computations and actual selector time? | The paths must coincide. The projection cannot improve width or test scores over the matched cache. |
| Exact greedy vs vectorized dense greedy | Is the whole sparse implementation faster at identical output? | Both caching and screening differ, so the time ratio cannot be assigned to votes alone. |
| Restricted forest vs original native full forest | What does compression do to prediction scores and deployment cost? | The registered full arm uses the custom traversal and pays extraction. Native XGBoost inference has a different time and memory profile. |
| Guarded vs unguarded | Does using calibration outcomes to choose among feasible widths preserve test performance better? | The guard is secondary. Its successful results cannot replace a failed unguarded primary endpoint. |

For selector wall time, the registered Gain sweep repeatedly slices SciPy sparse columns while the directional code uses compiled sparse loops. A faster implementation of the same sweep should precede a broad speed claim. The optimized single-pass Gain prefix is already a relevant practical control. For speed versus deploying the original forest, charge native fit and prediction, with warm kernels, matched CPU affinity, batch size and input conversion. Report extraction, selection and batch inference separately. Restricting the set of columns that must be supplied does not itself establish a smaller serialized model or lower inference latency.

The predeclared practical test is a source-equal width ratio of at most 0.90 versus Gain sweep with the predictive tolerances. Average paired differences over the five overlapping splits of each source and show source exceptions, class AUC and accuracy, regression R² and scaled/native MAE. Show the result for both panels. Separate favorable point estimates from source-cluster intervals crossing a tolerance. Thirteen selected sources, with even fewer per response type, cannot establish population noninferiority. Count support width against all inputs and distinguish unused teacher columns from inputs removed despite appearing in a split.

## Numerical implementation

On a two-row, one-feature stump with root margin zero and leaves ±1e−8, the full-centered margin has norm √2 × 1e−8. With rho = 0.20, dropping that feature has relative error one. On the locked implementation the Gain prefix returns the empty set. Dense, cached directional and Gain sweep keep the feature. Multiplying the same leaf values by 10,000 restores agreement. The prefix applies its absolute tolerance in squared units while the other selectors apply theirs in norm units. The secondary guard also has a separate absolute allowance. The locked runner verifies the actual relative distortion of every selected support; preserve that check and disclose any instances that fail. A shared scale-aware rule and a replay of locked supports can establish whether a code correction affects the observed experiment.

The implemented roundoff allowance for projection screening is heuristic. Exactness is a theorem for real arithmetic. Check full paths against an independently evaluated dense path for every measured split. Avoid a universal guarantee about the floating-point implementation and avoid claiming identical native XGBoost binary margins when agreement was tested with tolerances.

## Decision before unsealing

The mathematical description is adequate for a scoped engineering paper on frozen-tree input compression. Attribution of the path representation, an honest strong runtime comparator, and the prospective width/score results determine the empirical claim. A top-conference novelty verdict is premature even if all registered numerical targets pass. The fixed-width additive exchange article and this local tree compressor address different optimization problems and require different theorems and result tables.

## Registered follow-up with coalition-size voters

The follow-up registered in `558c770` uses three actual coalition sizes. The anchor for feature j at size s is its mean marginal vector over uniform backgrounds of that size. For a required set H containing j, its contribution occurs with probability C(s, |H|−1) / C(p−1, |H|−1), taken as zero when s < |H|−1. These containment probabilities follow directly from the unanimity basis. Fixed-size expected marginals are related to the classical semivalue construction for scalar games; here they are computed coordinate by coordinate. The distinct step is using their directions to screen the current constrained deletion. [Dubey, Neyman and Weber, 1981](https://doi.org/10.1287/moor.6.1.122) · [Hart and Mas-Colell, 1989](https://math1.math.huji.ac.il/~hart/papers/pot.pdf)

The minimum over three pass slacks uses the maximum individual squared projection. Unlike the orthogonal cells above, the three anchors can coincide or point in different, nonorthogonal directions. Their squared projections must not be added. In a game with groups {j}, {k}, {j,k} and contributions v, v, −v, both full-width marginal effects vanish. After k is deleted, omitting j loses v. The empty-background direction certifies that deletion fails whenever rho < 1. The full-width direction must send the case to an exact calculation. This gives a strict example of additional screening; empirical counts and times determine its frequency and practical value.

The independent check enumerated all supports of 63 signed small games with 1–7 columns, including zero, duplicated-output and integer-tie cases. All 1,260 marginal vectors matched the uniform-background averages. All 189 complete deletion paths across the three implementations matched direct scoring from each retained set, and the strict example saved one norm refresh. A separate scale check detected overflow in the initial implementation at amplitude 2^270 when the squared inner product was materialized before dividing by the anchor norm. The small game used singleton contributions 1, −1, 15 and a pair {0,1} of weight 1. Its dense deletion path at rho = 0.20 is [1,0]. With power-of-two rescaling and division before squaring, all three modes recovered this path at both scales.

The compiled Gain sweep replay and native XGBoost full-prediction control added after the forecasting lock address the implementation disparities above. Their design checks every sweep deletion and compares native test-input predictions to the locked forecasts before timing. Total times assembled from the original shared costs and the additional sweep timing should be labeled accordingly. Raw MAE should be given separately for each target with its own units.
