# A scalar correction for truncation-induced attenuation

The empty forest fixes the intercept. One common multiplier between 0.5 and 2 acts on every raw class margin (or the single regression margin), relative to that fixed intercept. On calibration, the mean-square minimizer is the clipped inner product of full and retained centered outputs divided by the retained squared norm, with unit fallback at zero norm. The predictor uses only selected columns. At fixed support a positive scalar preserves a binary model's ROC ordering, although its default decision threshold and the support selected under the new fidelity game can both change.

Using one split on nineteen previously opened sources, scaled exact greedy retained 11.34% fewer columns than unscaled exact greedy. Mean classification AUC changed by −.0048 and accuracy by −.0057. Regression R² decreased by .249 and scaled MAE increased by .032, exceeding the registered tolerances. Appliances contributed a −1.698 R² change on its chronological holdout. Music lost .051 R². The static singleton-ablation sweep also gained 10.70% compression from fitting the scalar, while average regression R² fell .062. These results failed the cross-task gate and did not trigger a five-seed scaling study on these sources.

Relative to static ablation with the same scalar, scaled greedy retained only 2.62% fewer columns. The authentic TreeSHAP-order control retained 4.38% more columns in the ratio comparing greedy to TreeSHAP. Relative to the unscaled exact path, the largest observed classification failures included an accuracy loss of .027 on Mice and .023 on ISOLET, and AUC losses of .015 on Anuran and Arrhythmia. Individual failures preclude a loss guarantee.

The later classification-only policy, with unscaled regression, was formulated after these development results and is tested on five different sources. Its protocol and forecast lock are in `../quota-scale-confirmation`. Read `scores-pilot.csv` and `contrasts-pilot.csv` here for the development outcomes.
