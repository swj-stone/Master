Each release uses CC BY 4.0. The posture description lists twelve participants; the cleaned source file contains fourteen distinct non-dummy user identifiers. Splits use the fourteen file IDs. Source labels do not establish independent identities beyond these IDs, and repeating measurements does not increase the number of held-out people. In the financial data repeated company identity or time order cannot be recovered. The turbine archive documents the same physical plant as the earlier UCI 294 net-output task and a different collection period and response. The weather task shares a city with the earlier rental-count experiment. These four endpoints supply varied predictor structures; they do not establish deployment performance at four previously unseen sites. Turbine and weather test years are reused across seeds. [Hand motion](https://doi.org/10.24432/C5960R) · [Plant provenance](https://doi.org/10.24432/C5WC95)

The archive version `1291b08` gave a geometric width ratio of .893 on four wide sources when compared with a single impurity-ranked path. Holding the extra path and guard fixed, replacing minimum ranking with pooled ranking changed the ratio to 1.009 (source-resampling interval .967–1.070); both canonical rules had four breaches in twenty jobs. Adding a second candidate path confounded the apparent minimum advantage. Equal-budget same-path pooled and score-free grid searches are consequently necessary in addition to the exhaustive gain sweep. Timing must include voting, all model fits and prediction. A width/search advantage against an unusually expensive exhaustive comparator alone cannot establish superiority to faster feature selectors. [Raw ratio table](../minpi_rework/wide-veto-ablation/width-ratios.csv) · [Score comparison](../minpi_rework/wide-veto-ablation/contrasts.csv)

The exhaustive gain adapter uses the archived settings and scans all nonempty prefixes. It sorts tied gains by decreasing original column index and feeds each learner the chosen columns in original order. The full-width ranking fit is reused at width p. Thus each call makes p fits to rank and validate widths and one final refit for the chosen width. The diagnostic saves the smallest within .005 of the highest validation score without charging any second final model to the primary method. This diagnostic is a width comparison until an independent fit uses it to predict. Source subsampling, variable exclusions and chronological cutoffs are listed in the [frozen protocol](../../../experiments/minpi_replication/protocol.md).
