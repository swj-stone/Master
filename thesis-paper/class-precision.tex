\paragraph{Which four-bit distinctions persist within a predicted class?}
We repeated the five four-bit recodings, restricting code donors to feature vectors of the same multiplicity and the same full-precision predicted class. This preserves the code frequencies within each class. The observer still receives only the code and knows its mapping on the finite dictionary. Of 38,021 outer-row occurrences, 37,336 could receive a different code in their stratum; 14,940--15,054 actually did across the five draws.

The genuine code admitted 338 witnessed reversals with nine unresolved proposals. The class-preserving recodings admitted 470--475 with 6--14 unresolved, compared with 648--656 with at most one unresolved when donors were matched only on multiplicity. On 12 of 14 tasks the smallest class-preserving witness count exceeded the genuine count even after including all genuine unresolved proposals. Thus the grouping of inputs \emph{within} predicted classes also constrained the refit decision on these dictionaries. With both point queries already observed, the corresponding witness counts were nine, five to nine, and three to eight, with every case resolved.
