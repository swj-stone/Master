# Contexts and panels in the linear transfer study

This secondary analysis was specified after inspection of the original six-arm transfer study and before running either new arm. It uses all fifteen original splits, the same ranking, candidates, refits, metrics and tolerances. The comparisons are descriptive.

| Rule | One weighted panel | Strict majority of four panels |
|---|---|---|
| Empty context only | Original point arm | New empty-majority arm |
| Veto in any distinct context | New all-point arm | Original min arm |

An all-point candidate must pass the original weighted panel in every context visited. An empty-majority candidate must pass at least three panels in the empty extension. Report selected-support agreement against the full rule and dataset-level held-out scores. Repeated votes used internally to encode a single weighted-panel decision do not constitute extra independent observations.
