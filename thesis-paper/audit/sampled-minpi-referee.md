# Independent author-side review of feature-level ridge MinPI

## First reading, before viewing confirmation scores

I inspected the conference definition, the feature ranker, the source loaders, the split and scoring code, the fixed protocol and the rational-arithmetic Lean statements. The new paper evaluates a genuine instance of the original per-feature quota game. It changes the learner, the coalition sampling law and the continuous utility. A passing-to-failing vote on adding a column proves a property of a particular empirical game. It gives no implication for the test error of removing the column from the final model.

* **Use of the ternary index.** For a binary-valued game, an exact minimum of (+1) forces every edge adding that column to run from zero to one. Consequently the game equals the indicator that the column is present. Conversely that indicator gives minimum (+1). There can be at most one such column and its presence forces every other exact minimum to be zero. Requiring all three *exact* classes on the same data is mathematically impossible. The statement is independent of the ridge model and quota. As a check I enumerated every binary game for one through four features. Exactly 1, 2, 3 and 4 games respectively contained a positive exact index.
* **Consequences for sampling.** Every observed winning support must contain a possible positive column and every observed losing support must omit it. The intersection of wins minus the union of losses therefore bounds the candidate positive set from above. A witnessed negative edge makes this set empty. This observation could eliminate losing-base work before each column individually receives a zero. It is an implication for the global index; incorporating it might alter sampled positive labels. The baseline sampler and any refined sampler must be named separately.
* **Ablation.** The arithmetic-mean arm changes the transformation of the edge, its aggregation and the stopping rule. The same-schedule comparison tests their combination. For the practical question of whether votes change delivered supports, the full-ridge coefficient order is the matched comparator. Both rankings use identical fitting examples and the same deterministic tie score. Report support agreement, including runs that return every column. An additional fixed-width comparison should be identified as exploratory.
* **Timing.** Ridge-coefficient ranking and an F filter can be inexpensive. Step-one sklearn RFE is one implementation. Block solving has prior art in regularized least-squares feature selection. Limiting a timing result to either the matched cached-refit implementation or the timing of the named selector prevents mistaken conclusions about efficient ridge selectors generally. Greedy RLS uses a different leave-one-out objective and an efficient update scheme. [Pahikkala, Airola and Salakoski](https://staff.cs.utu.fi/~aatapa/publications/inpPaAiSa10b.full.pdf), [RLScore in JMLR](https://www.jmlr.org/papers/v17/16-470.html).
* **Population and independence.** Four source tasks per domain support a point decision for the fixed panel. Five overlapping train/test splits share subjects and jointly vary data assignment and the coalition schedule. They cannot supply 20 independent replications per domain or isolate sampler variability. Percentile intervals from four resampled sources are descriptive, highly discrete and sensitive to individual data sources. Prevent selection leakage by retaining the pre-outcome protocol and reporting each subsequent variant's registration time.
* **Equal treatment.** F and RFE may access the pooled fitting and voting records, while the coefficient and voting arms fit the ranking model on the fitting subset. The methods use the same development rows and final refit, but ranking training sample sizes differ. Describe this design feature visibly and limit causal interpretation of these comparisons.

## Independent exact-game check

For the seven sources with at most ten columns, the exact-game CSV contains 245 feature/split pairs. There are 47 exact negatives, of which the sample found 14. It classified the other 33 as zero. All 193 exact zeros and the 5 exact positives had the same sampled label. All five positives occur on Yacht. There are no exact negatives on Yacht, Airfoil or WiFi. Glass alone has 22 negative feature/split pairs, five observed. These counts describe repeated games on seven data sources. In particular, computational speedups in this panel should distinguish shared linear solves from savings specifically attributable to absorbing a negative vote.

The accompanying `formal/Dictator.lean` gives a human-readable derivation and a standalone Lean 4.35.0 development. The exact minimum is formalized as an attained lower bound over all coalitions. Lean checked the positive-index characterization, uniqueness, other-column zeros, the zero upper bound outside the set of compatible columns, and the elimination of all candidates by a winning support contained in a losing one. The printed dependencies contain only standard Lean axioms. The dictator definition itself is classical. [Gvozdeva and Slinko](https://www.sciencedirect.com/science/article/abs/pii/S0165489610000740).

## Second reading, after the primary and sensitivity score tables became available

Across the 40 confirmation jobs the vote changed the coefficient-based feature ordering eight times and the full selected support six times. All five rankings were identical on each of five sources, including the only 64-column confirmation source. I obtained these counts independently by grouping the vote diagnostics by source. Of 6,780 scheduled feature additions, 66 (0.97%) were skipped because the feature had already reached minus one and 1,278 (18.85%) because a zero-valued feature had a losing base. Reporting the combined count as savings due to early negative discovery would overstate that particular mechanism.

The predeclared width rule met its point criterion against all features on regression (retained geometric fraction 0.504, mean R² difference +0.0066, scaled MAE +0.0033). On classification the geometric retained fraction was 0.689 and the AUC change was −0.0048, but accuracy changed by −0.0129 against a floor of −0.010. The RFE classification width ratio of 0.9982 satisfies the literal threshold below one. A 0.18% difference with a source-resampling interval from 0.870 to 1.112 provides no practical case for improved compression. The regression width ratio of 1.072 also fails the RFE objective. Relative to coefficient ranking, selection took 1.15× as long in classification and 1.51× in regression; regression retained exactly the same geometric fraction. F selected fewer columns on average in both domains.

The preregistered zero-tolerance sensitivity passes the predeclared quality and width point criteria against full features in both domains. It changes the operating point for the common width selector on all arms. It improves the full-feature comparison while leaving unresolved how much voting contributes relative to simpler rankings. Selection timings from the primary rule cannot be transferred to this sensitivity.
