## Essential corrections to the frozen text

1. **Specify access to the randomized codebook at lines 162–169.** The experiment fixes the sampled map from each known feature vector to a code and lets the observer know that map, or equivalently its reproducible construction. A code on a labelled row then restricts precisely which dictionary vectors can occupy it. Merely receiving a code per row and the marginal frequencies without knowing the map would give a larger feasible set. For the combined observer, the randomization preserves the marginal code frequencies and each repeated input's code. It does not preserve the joint frequencies of the code and the two fixed point queries. On the 17 point-ambiguous proposals combined over 2,799 row occurrences, the genuine two-bit code yields 1,834 joint signatures and 1,450 singleton rows. The five randomized codes yield 2,059–2,093 joint signatures and 1,697–1,737 singleton rows. The genuine code permits 155 opposite-label single exchanges, versus 164–263 under the five randomized partitions. The number of possible decision reversals depends on which rows and scores remain exchangeable. The smaller 6–9 count compared with 12 can be reported exactly as observed. It carries no predictive-superiority interpretation. A brief sentence that the codebook is known and the joint frequencies were allowed to vary would settle this.
2. **Correct “restorations … were unchanged” at line 273.** The forest-on-Gain experiment derives the tail after the XGBoost Gain anchor from the ordered split-used features. The ANOVA experiment uses the tail of the fitting-sample ANOVA ordering over input features after the new anchor. Both call the same function for constructing separating restorations, but the actual restored columns and resulting masks depend on the chosen tail. The within-ANOVA comparisons across the three pool draws keep this family fixed. Describe the common construction rule and include the actual restoration family among the jointly changed aspects when comparing original to ANOVA results. That preserves the clean within-draw contrasts and the cross-draw interpretation.
