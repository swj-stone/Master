SLIDE 1
Good afternoon. My name is Wenjie Shi, and my supervisor is Chi Zhao. My research is Min-Marginal Power Indices for Multi-Objective Feature Selection. The central question is when an extra feature can make a model worse. I will explain the core idea through a complete example, then discuss how the experiments will test its value.

SLIDE 2
Consider a spam classifier. Each email has input features, such as word frequencies and punctuation, and a known label indicating spam or legitimate email. The model learns from these labeled examples.

We may want fewer inputs to reduce measurement and model costs. However, adding or removing a feature can change prediction performance, and its effect can depend on the other inputs already present. My research therefore seeks a concrete reason to consider a feature for removal, followed by a separate test of whether removal is worthwhile.

SLIDE 3
The research separates two checks. In the addition check, we compare a model using feature group S with a model trained after adding input i. We ask whether that addition makes the score fall below the requirement.

In the removal check, we compare the full input set with a proposed smaller set on independent data. We examine prediction loss, model size, and cost. A harmful addition in one group does not automatically imply useful removal from the full set, so these two questions require separate evidence.

SLIDE 4
Here are the definitions. D is the full input set being analyzed. S is a group without input i. U of S is the validation score after training with S.

The required score, q, equals alpha times the full-set score. With alpha at zero point nine five, we require ninety-five percent of that reference score, not ninety-five percent accuracy.

The game value v equals one when the requirement is met and zero otherwise. Delta is the value after adding i minus the value before adding it. A pass becoming a fail gives minus one.

MinPPI takes the minimum delta across all groups without i. Let us now expand these definitions for three inputs and compare them with Shapley values.

SLIDE 5
Let us define one complete game with three inputs, x one, x two, and x three. These scores are an illustration, not experimental results. The full-set score is zero point nine zero, giving a threshold of zero point eight five five.

The table lists all eight groups, including the empty group, which uses a constant predictor. Each score becomes either one for passing or zero for failing. This is the Voting Game representation used here. It defines the outcome of each group; it is not a competing feature-ranking method.

This game can be nonmonotone. For example, x one alone passes, but adding x two makes their pair fail. We will use exactly these outcomes for both Shapley and MinPPI.

SLIDE 6
Shapley averages a feature's marginal effects over all possible joining orders. The weights in the formula account for how often each group precedes the feature. With three inputs, the empty and two-input groups each receive weight one third. Each one-input group receives weight one sixth.

Consider x one. Its four marginal effects are plus one, minus one, plus one, and zero. Multiplying by the four weights and adding gives one third. The negative effect is present, but positive effects offset it in the average.

The same calculation gives one third for x two. For x three, only the last context contributes positively, also giving one third. All three inputs therefore have identical positive Shapley values in this game. These are Shapley values of the threshold game, not SHAP explanations of an individual prediction.

SLIDE 7
MinPPI uses the same marginal effects but changes how we combine them. For x one, the minimum of plus one, minus one, plus one, and zero is minus one. The result is also minus one for x two. For x three, the minimum of zero, zero, zero, and plus one is zero.

The comparison shows the distinction. All three inputs have a Shapley value of one third, but only x one and x two have negative threshold crossings. The two summaries answer different questions: average contribution and the existence of a harmful context.

A zero MinPPI does not mean that x three is useless. Adding it to the failing pair of x one and x two makes that group pass. Let us now look more closely at one of the negative crossings.

SLIDE 8
This is one witness from the same three-input game. The model using x one scores zero point eight seven and passes the threshold. Adding x two and retraining lowers the score to zero point eight four, so it fails. The change is zero minus one, or minus one.

This also shows why removal needs another check. Although both x one and x two have harmful contexts, deleting both leaves only x three. Its score is zero point eight zero, below the requirement. Joint deletion would therefore fail in this illustrative game.

SLIDE 9
This diagram brings the research together. The upper row shows the feature audit. We first choose an input i and a group of other inputs, S. We then train and evaluate the models using S and S plus i. If adding i changes a pass into a fail, we record the feature, the group, both scores, and the threshold. We repeat this process within a fixed query budget.

The lower row shows the planned deletion evaluation. Following the arrows from right to left, we use the audit evidence to propose one removal candidate. An independent validation check decides whether to accept it or keep the full input set.

After freezing that decision, we evaluate the chosen model on held-out test data. We measure how many inputs remain, how much prediction performance changes, and the total computational cost. This keeps the discovery of a harmful context separate from the evaluation of a removal decision.

SLIDE 10
These calculations use the language of cooperative game theory. Each input is a player, and each feature group is a coalition. Adding an input creates a marginal contribution.

Shapley summarizes those contributions using a weighted average. MinPPI checks their minimum in the threshold game. Minimum aggregation has predecessors, including MinShap. This project focuses on the fixed performance requirement, the record of an evaluated failure, and the independent evaluation of removal decisions.

SLIDE 11
The previous slides explain how we check whether adding a feature causes harm. The next question is how to find such cases efficiently.

As the number of features grows, checking every combination becomes expensive. We therefore compare two search strategies. Method A selects feature groups randomly. Method B uses information from the training data, including associations with the target and relationships between features, to guide this selection.

Both methods use the same addition check and the same query budget. We then compare how many harmful cases they discover. Guidance is a hypothesis to test, rather than a guaranteed improvement.

A discovered witness provides evidence of harm in that specific context. However, finding no witness does not prove safety, because some combinations remain unchecked. We also measure computational cost separately, since equal query budgets do not necessarily mean equal running times.

SLIDE 12
The datasets were chosen to serve different parts of the research.

Abalone uses physical measurements to predict ring count. It provides a regression task, and its eight inputs allow us to check every possible subset.

Madelon is a labeled synthetic classification dataset. It contains informative variables, redundant combinations, and distractor variables. This structure helps us investigate difficult feature combinations, although a variable's generating role does not automatically determine whether MinPPI finds it harmful.

Spambase uses word and character statistics to predict whether an email is spam. Its inputs make the feature combinations easier to explain.

Credit-card fraud provides a classification task with rare positive cases. Its inputs include anonymized PCA components and transaction amount. PCA describes the input representation. The prediction task still uses known fraud labels and remains supervised.

The current exact-reference study uses these four datasets. Gisette and ISOLET belong to the broader benchmark, but they are not part of the current thirty-five small reference problems.

SLIDE 13
The experiments answer three questions. First, how much does the search miss? We compare it with complete references on small problems. This study is complete.

Second, what makes discovery difficult? Planned synthetic experiments separate signal, redundancy, and interaction.

Third, is removal worthwhile? Planned independent evaluation measures smaller models, prediction loss, and total cost. Evidence of a harmful context cannot replace evidence that deleting features is useful.

SLIDE 14
The first study uses small problems because we need a complete reference. With eight inputs, there are two hundred and fifty-six possible subsets. We can evaluate all of them and determine which inputs have at least one harmful context.

We then let methods A and B search under the same query budget. They cannot see the complete reference or its harmful-feature labels. They can only request the subset evaluations selected by their own search strategy.

After the search, we compare the discovered harmful inputs with the reference. This allows us to measure what was found and what was missed across the query budget.

The completed study contains thirty-five fixed problems across four datasets. Each reference applies to its own eight-input problem, model, split, and threshold. It does not provide a complete answer for the original high-dimensional dataset.

SLIDE 15
The second study is planned to help explain the discovery results. Real datasets contain many overlapping influences, which makes it difficult to identify why a search succeeds or fails.

We therefore use three controlled structures. The first combines useful variables with unrelated distractors. The second adds noisy copies of informative variables, creating correlated redundancy. The third uses an interaction in which the target depends on a combination of variables.

For each structure, we keep the learning and evaluation procedure fixed, construct a complete reference, and compare A and B under the same budget.

The aim is to understand how data structure affects harmful contexts and their discovery. We do not assume that an irrelevant or redundant variable must be harmful. Its MinPPI status still depends on the evaluated model and threshold.

SLIDE 16
The third study addresses practical value. It is planned, because a harmful witness alone does not establish that removal is useful.

First, each strategy proposes one candidate input set using training and selection-validation data. A separate validation set then checks whether the candidate stays within a predefined tolerance for prediction loss. If it fails this check, the strategy keeps the full input set. We do not repeatedly try candidates until one passes.

After fixing the decision, we refit the chosen model and evaluate it on held-out test data. We compare the result with established feature-ranking and elimination methods, using consistent learning and evaluation conditions.

We judge three outcomes together: the number of retained inputs, prediction loss, and total computational cost, including the audit. Classification and regression results are evaluated with their appropriate metrics. A smaller model is valuable only when the reduction justifies its performance trade-off and cost.

SLIDE 17
The small reference audit is complete. It provides checkable witnesses and shows that limited searches can miss harmful cases.

The current guided strategy has no stable advantage over random exploration. Training associations do not consistently lead to failure contexts.

Practical deletion value remains open. The next steps are the controlled mechanism study and independent removal evaluation, which will help establish the method's useful conditions and limitations.
